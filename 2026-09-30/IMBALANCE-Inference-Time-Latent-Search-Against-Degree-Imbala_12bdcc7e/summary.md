# 论文速读：IMBALANCE-Inference-Time-Latent-Search-Against-Degree-Imbala

## 一句话总结
论文系统性地识别出知识图谱嵌入（KGE）模型在链接预测中因测试三元组头尾实体度数不平衡而导致的预测质量骤降问题，并提出 IMBALANCE——一种推理时潜变量搜索优化方法，通过在预训练模型基础上微调锚点与目标实体嵌入，结合训练上下文与外部 Oracle 补充信息，显著改善低度数实体在重度不平衡三元组上的预测表现。

## 研究问题与动机
1. **聚合指标掩盖性能不均衡**：KGE 模型的评估指标（如 MRR、H@N）在整体上表现良好，但实际预测质量在图谱不同区域差异巨大，低度数实体预测尤其脆弱。
2. **度数不平衡是核心驱动因素**：测试三元组中头实体与尾实体的度数差异越大，越高度数实体的预测越准确，而低度数实体的预测越差；这一问题在 FB15k-237、YAGO3-10 等多种数据集及 TransE、DistMult、ComplEx、RotatE、NBFNet 等主流模型中普遍存在。
3. **低度数实体面临双重学习缺陷**：分析训练动态发现，低度数实体要么因邻域信息过少而过拟合（嵌入位置看似稳定但泛化极差），要么因信息不足而始终无法收敛（嵌入持续大幅震荡）。
4. **实际应用中的关键盲区**：在推荐系统等场景中，涉及低度数实体的三元组恰恰是重要的长尾/corner case（如为某艺术家推荐小众音乐类型），现有模型对此类查询几乎不可靠。

## 核心贡献（创新点）
1. **首次系统性刻画度数不平衡问题并与训练动态关联**：通过分箱分析与嵌入更新轨迹追踪，将预测性能差异归因于头尾实体度数差，并揭示低度数实体的过拟合与收敛失败两种故障模式。
2. **提出 IMBALANCE——首个面向 KGE 的推理时潜变量搜索优化方法**：在预训练模型冻结权重的前提下，对指定查询的锚点和少量目标实体嵌入进行推理时梯度优化，无需重新训练即可显著提升不平衡三元组上的排名。
3. **双项无负采样损失设计**：损失函数由训练上下文项和 Oracle 增强项构成，通过冻结关系嵌入与训练上下文目标实体嵌入实现天然正则化，避免了对合成负采样的依赖。
4. **轻量级即插即用且计算高效**：作为后处理模块可叠加于任何传统 KGE 模型，单查询推理延迟仅约 0.9 秒（FB15k-237），远低于重新训练成本。

## 方法详解
- **问题设定**：给定预训练 KGE 模型及其打分函数 $f$、实体嵌入矩阵 $\mathbf{E}$，以及查询 $q=(s,p,?)$（或 $(?,p,o)$）。
- **训练上下文** $\mathcal{C}_q$：与查询共享锚点和关系的已知训练三元组集合，即 $\mathcal{C}_q=\{(s,p,o_i)\mid (s,p,o_i)\in\mathcal{G}\}$。
- **Oracle 三元组** $\varOmega_q$：由外部知识源生成的候选目标三元组，用于补充低度数实体的稀缺信息。
- **目标函数**：
$$\mathcal{L}(q) = \sum_{t^+\in\mathcal{C}_q} f(t^+) + \sum_{t\in\varOmega_q} f(t)$$
- **训练上下文项**：仅对锚点实体 $s$ 的嵌入进行梯度更新，训练上下文中的目标实体嵌入和关系嵌入保持冻结。目的是将锚点嵌入从"通用表示"精细化到"面向当前查询的表示"，同时避免过拟合。
- **Oracle 增强项**：同时对锚点 $s$ 和 Oracle 推荐的候选目标 $o_j$ 的嵌入进行梯度更新。Oracle 使用 LLM（NovaSearch/stella_enc_400M_v5，维度 1024）对实体标签/描述进行编码，通过余弦相似度选取与训练上下文质心最接近的 Top-m 实体构成 $\varOmega_q$。
- **优化过程**：使用 Adam 优化器，迭代 $T=30$ 次（支持早停），学习率 $\lambda\in\{1e^{-2},1e^{-3},1e^{-4}\}$。由于冻结了关系和部分实体嵌入，无需负采样即可稳定优化。

## 实验与结果
- **数据集**：FB15k-237、WN18RR、YAGO3-10，按度数分布四分位划分为 High-Low（高主体+低客体）和 Low-High（低主体+高客体）子集。
- **评估协议**：Filtered setting，对低度数实体进行 corrupt，计算 MRR 和 H@N。
- **主要结果（FB15k-237，RotatE 基线）**：
  - High-Low split：MRR 从 0.02 → 0.13（提升约 6.5 倍），H@10 从 0.05 → 0.36。
  - Low-High split：MRR 从 0.04 → 0.08，H@10 从 0.09 → 0.17。
- **WN18RR 提升较温和**：因度数分布集中、极化程度低，RotatE High-Low MRR 从 0.49 → 0.51。
- **YAGO3-10 仅在 H@10 有改善**：因 Oracle 仅使用实体标签（无额外描述），三元组质量受限。
- **对比基线**：IMBALANCE 在重度不平衡三元组上显著优于 KG-Mixup；与 LLM 增强的 CSProm-KG（整体 MRR=0.36）相比，在不平衡子集上表现相当甚至更优，但计算效率远高于 CSProm-KG。
- **消融实验**：训练上下文项和 Oracle 项各自贡献正向效果，联合使用最优；Oracle 项影响更大，因其间接参与锚点嵌入的优化。
- **时延**：单查询 IMBALANCE 约 0.91 秒（FB15k-237），整测试集 440.7 秒；远低于重新训练 RotatE 的 935.9 秒。

## 相关工作脉络
1. **TransE / DistMult / ComplEx-N3 / RotatE**：传统 KGE 模型，本文在其上验证度数不平衡的普遍性并应用 IMBALANCE 进行推理时增强。
2. **NBFNet**：GNN 类链接预测 SOTA，虽聚合指标更优但仍受度数不平衡影响；但因消息传递架构中实体嵌入高度纠缠，无法直接套用 IMBALANCE。
3. **KG-Mixup [21]**：针对"度数偏差"提出合成嵌入方案，但问题定义模糊，在重度不平衡三元组上的提升远不及 IMBALANCE。
4. **CSProm-KG [5]**：集成 LLM 软提示的 KGE 增强方法，整体指标远超传统模型，但在不平衡子集上 IMBALANCE 与之相当且计算代价低一个数量级。
5. **度数偏差分析 [17,19]**：早期工作指出高度数节点偏差问题，但未提出具体解法；本文首次将问题量化为可操作的推理时优化目标。

## 局限性与未来方向
1. 仅适用于训练上下文非空的查询，需进一步研究如何从全图中选择与查询最相关的三元组作为上下文。
2. 效果依赖数据集度数分布的极化程度和 Oracle 输入质量，在度数分布较均匀的数据集或 Oracle 信息稀疏时提升有限。
3. 当前 Oracle 主要依赖 LLM，未来可扩展至人类反馈、用户交互模式等其他异构知识源。

## 研究启发与可借鉴点
1. **推理时优化作为轻量级增强范式**：在不重新训练的前提下对少量关键嵌入进行后处理优化，可作为通用套路迁移至其他图表示学习任务。
2. **按子群体分箱的评估方法论**：用归一化度数差对测试三元组分箱并绘制性能曲线，能有效揭示被聚合指标掩盖的模型弱点，值得在后续研究中推广。
3. **Oracle 增强思路的可迁移性**：利用外部知识源（LLM、用户行为、领域专家知识）为长尾实体补充"虚拟邻接关系"的设计，可推广至冷启动推荐、少样本关系抽取等场景。
4. **冻结部分参数实现无负采样正则化**：通过冻结关系嵌入和目标实体嵌入避免表示坍塌，省去了复杂的负采样策略设计，为简化训练流程提供了可行路径。

## 关键术语表
**Knowledge Graph Embedding (KGE)**：将知识图谱中的实体和关系映射到低维连续向量空间的技术，通过打分函数评估三元组真实性以完成链接预测。
**Degree Imbalance**：测试三元组中头实体与尾实体的度数差异，差异越大则低度数实体的预测排名显著恶化。
**Normalized Degree Difference**：度数不平衡的量化指标，定义为 $(\delta(s)-\delta(o))/\min\{\delta(s),\delta(o)\}$，用于对测试三元组进行分箱分析。
**Training Context**：与查询共享锚点实体和关系的已知训练三元组集合，用于推理时对锚点嵌入进行针对性微调。
**Oracle**：外部知识源（本工作使用 LLM 编码实体描述），用于生成与查询语义相近的候选三元组以补充低度数实体的信息缺失。
**Inference-Time Latent Search**：在推理阶段对实体嵌入进行梯度优化搜索，而非在训练阶段学习固定表示，以实现查询级别的个性化调整。
**High-Low / Low-High Split**：按度数不平衡划分的测试子集，分别指高度数主体+低度数客体 和 低度数主体+高度数客体的三元组组合。
**Filtered Setting**：链接预测标准评估协议，从所有实体候选中过滤掉训练/验证/测试集中已存在的真实三元组后再进行排名评估。
