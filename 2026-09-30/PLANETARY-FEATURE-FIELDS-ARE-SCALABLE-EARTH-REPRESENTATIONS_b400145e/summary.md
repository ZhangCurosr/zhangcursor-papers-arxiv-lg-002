# 论文速读：PLANETARY-FEATURE-FIELDS-ARE-SCALABLE-EARTH-REPRESENTATIONS

## 一句话总结
提出行星特征场（Planetary Feature Fields, PFFs），一种空间局部的显式‑隐式混合神经场，通过跨产品共享因子化特征体积，以约 1800× 压缩率联合建模 14 类异构地球观测数据；在保持原始下游任务性能约 90% 的前提下，支持仅更新 0.2% 参数的新增年份与新增产品持续学习，且特征物化速度较 Earth Engine API 快约 10 倍。

## 研究问题与动机
- 原始观测、预计算嵌入与地图产品以独立 PB 级数组存储，随时间轴扩展导致存储、传输与版本管理成本线性增长。
- 纯隐式地理位置编码器（如 SatCLIP、GeoCLIP）虽紧凑，但缺乏重建源数据所需的高频空间细节；预计算嵌入保留细节却带来高昂的在线读取开销。
- 现有单产品神经场无法利用多源 EO 数据间的结构冗余，且面对新时间步/新产品时需全量重训，易引发灾难性遗忘或历史输出漂移。

## 核心贡献（创新点）
1. **提出 PFFs 混合架构**：将共享的显式因子化特征体积与产品专属轻量 MLP 解码器结合，区别于传统多产品独立拟合或简单特征拼接的表征方式。
2. **高压缩比下的高保真重建**：在约 1800× 压缩率下，PFF 重建特征在像素级分割、变化检测与分类任务中普遍保留原始特征 90% 以上的下游性能（部分任务甚至超越原始特征）。
3. **免遗忘持续学习机制**：新增时间步仅训练 0.2% 的时序因子切片，新增产品仅训练约 2% 的专属解码器，所有已训练历史输出保持位精确（bit‑exact）不变。
4. **特征物化效率突破**：相比 Earth Engine API 与全量 COG 下载管线，PFF 推理速度提升 15–18 倍；单张 H100 GPU 可达 9.7M AlphaEarth 嵌入/秒的峰值吞吐。

## 方法详解
- **区域路由与坐标归一化**：将全球地理域划分为独立瓦片，查询点路由至对应区域后映射至局部笛卡尔坐标系 $[0,1]^2$，使各区域字段结构统一且专注局部细节。
- **共享因子化特征体积（Explicit）**：采用 TensoRF(VM) 或 K‑Planes 分解，将稠密时空网格解耦为空间平面、时间平面与向量因子，独立设置空间分辨率（VM：$S=955$，$R=65$）与稀疏时间切片（9 年），生成共享隐变量 $\mathbf{h}(\mathbf{x},t)$。
- **产品专属隐式解码器（Implicit）**：每个产品 $m$ 配置两隐层 ReLU MLP $g_m$，将共享特征映射回该产品原生空间：$\hat{\mathbf{y}}_m(\mathbf{x},t)=g_m(\mathbf{h}(\mathbf{x},t))$。
- **联合训练与缺失掩码**：多产品数据集联合优化；粗分辨率产品通过最近邻重采样对齐至 10m 网格，避免插值伪影；对缺失位置/时间/通道独立掩码，损失按观测目标均摊后等权相加。欧氏特征使用逐通道标准化 MSE，归一化嵌入使用余弦失真 $1-\cos(\hat{\mathbf{y}},\mathbf{y})$。
- **持续学习策略**：新增年份时冻结全部现有参数，仅从最近时间步初始化并训练新增时序切片（VM 增 124K 参数，K‑Planes 增 141K）；新增产品时仅训练对应 $g_{\text{new}}$（约 1.25M 参数），数学上保证历史查询输出 bit‑exact 保留。

## 实验与结果
- **数据集与基线**：在 100 块全球 PFFBENCH 瓦片（约 67 亿空间位置、16TB 源数据）上评估；基线为参数预算严格匹配的单一产品 TensoRF(VM)、K‑Planes、Instant‑NGP 及 ReLU/SIREN 坐标网络，容量分配采用均匀分配。
- **重建指标**：欧氏特征报告逐通道平均 $R^2$，AlphaEarth 报告 angular skill；PFF‑VM 与 PFF‑K‑Planes 在 14 个产品平均重建分上分别达 90.5 与 91.1，较最优单产品基线提升约 20% 归一化畸变收益。
- **下游任务保持率**：PASTIS 作物分割、FTW 田块 delineation、SwissCrop25 与 EuroMineNet 变化检测中，PFF 保持率普遍在 90%–105%；Sentinel‑2 在 PASTIS 上保持率达 136%，超出原始特征表现。
- **Patch 级分类**：BEN‑v2 与 So2Sat 上 PFF‑VM 保持率稳定在 99%–103%，与源码性能持平或小幅超越，验证了平滑效应未破坏粗粒度判别信息。
- **推理速度**：100 万枚 AE/TE 嵌入物化耗时较 Earth Engine API 快 17.9×/15.5×；H100 峰值吞吐 9.7M embeds/s，L4 GPU 单次查询可达 0.91s。

## 相关工作脉络
- **隐式/显式神经场（NeRF/NGP/K‑Planes/TensoRF）**：本文继承连续坐标建模思想，但针对 EO 时空各向异性（密集空间/稀疏时间）引入因子化显式体积，并首次在 14 类异构产品间共享该表示，而不仅是单场景重建。
- **地理位置编码器（SatCLIP/GeoCLIP/MIND/RANGE）**：全局隐式编码器主要作为下游任务的先验；PFF 直接替代原始产品成为可查询的特征实体，保留像素级空间细节与跨产品互补结构。
- **多模态/多产品 EO 表征（AlphaEarth/TESSERA/Galileo）**：既有工作多依赖特征级拼接或对比蒸馏；PFF 在隐变量层面实现跨产品共享，证明“共享编码+独立解码”优于“共享编码+并联共享解码器”。
- **神经压缩与地球数据压缩（TerraCodec/气候网格压缩）**：TerraCodec 针对单产品压缩需独立重训与重解码；PFF 支持增量扩展且历史输出 bit‑exact，更适合动态演化的地球观测数据管线。

## 局限性与未来方向
- 压缩比为固定存储预算下的定长表示，不支持可变速率压缩；引入高冗余嵌入（如 Galileo）会虚高整体压缩率数值，需谨慎解读绝对倍数。
- 重建具有损损性，平滑效应可能削弱高分辨率 mapping 所需的细粒度结构，但其降噪增益与跨产品监督增益在实验中未做因果分离。
- 当前为固定容量分配，未针对静态地图、动态观测与深度学习嵌入三类数据设计非对称容量调度；全局千级瓦片的协同训练与边缘部署尚未验证。
- 未来可探索与物理约束（如水文/能量守恒）联合正则，或将时间因子扩展至月/周尺度以支撑高频动态地球数字孪生。

## 研究启发与可借鉴点
- **因子化显式‑隐式混合范式**：TensoRF/K‑Planes 的时空分解结构可直接迁移至多源异构数据（如多模态医学影像、遥感多光谱/雷达融合）的联合压缩表征。
- **持续性几何表示设计**：“冻结共享表示+仅训练新增因子切片/专属解码器”的实现极简且具备严格的 bit‑exact 保留保证，适用于任何需不断吸纳新时间片的连续建模管线。
- **以任务保持率为核心评估指标**：采用“下游任务 Retainment %”替代 PSNR/SSIM 评估压缩特征可用性，对遥感/AI for Science 的表征论文具有强参考价值。
- **神经场替代传统特征服务层**：将训练好的 PFF 导出为 ONNX 并置于低延迟推理栈，可证明神经表示能直接替换云 API/对象存储成为下一代地理空间特征分发组件。

## 关键术语表
- **Planetary Feature Fields (PFFs)**：行星特征场，本文提出的空间局部显式‑隐式混合神经场，用于紧凑联合表示多源地球观测时空数据。
- **Factored Feature Volume**：因子化特征体积，将高维时空网格解耦为小尺寸空间平面、时间平面与向量因子的显式存储结构。
- **Bit‑exact Retention**：位精确保留，指持续学习过程中冻结现有参数使历史查询输出数值完全不变的特性。
- **Downstream Retention**：下游保持率，重构特征在标准下游任务中的指标相对于原始特征指标的百分比，量化压缩表示的信息保真度。
- **Continual Learning via Factor Extension**：通过扩展因子实现持续学习，PFF 中特指仅追加时序切片或专属解码器参数而零重训共享表示。
- **PFFBENCH**：本文构建的含 1000 块全球瓦片的基准数据集，主实验采用其中 100 块覆盖多样气候与地形。
