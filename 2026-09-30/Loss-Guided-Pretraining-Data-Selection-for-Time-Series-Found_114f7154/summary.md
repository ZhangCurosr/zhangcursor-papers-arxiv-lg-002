# 论文速读：Loss-Guided-Pretraining-Data-Selection-for-Time-Series-Found

## 一句话总结
本文提出了首个面向时间序列基础模型（TSFM）预训练的**基于参考损失（RFL）的静态数据选择框架**，通过冻结参考预测器为每个上下文-未来窗口打分，并在每个源数据集内保留中间难度区间的样本；实验表明该方法在三种不同TSFM架构上均优于随机选择，且在80%保留率下可超越全数据预训练。

## 研究问题与动机
1. **TSFM预训练数据冗余且低质**：当前TSFM（如TimesFM、Chronos、Moirai）使用含数十亿观测值的异构语料库预训练，但训练窗口通常无差别采样，未评估每个窗口是否提供有效学习信号。
2. **简单窗口与极端困难窗口缺乏价值**：图1显示，大量窗口仅是季节性/缓慢变化的重复（易样本），而部分窗口未来突变无法学习（难样本），两者均无法提供稳定的学习信号。
3. **现有数据选择方法不适用于预训练场景**：现有时间序列选择方法主要针对任务特定训练或基础模型微调（如TimeInf、TSRating、AdaRho），计算复杂度高，无法扩展至TSFM预训练规模；而LLM/CV领域的基于损失的数据选择方法因目标函数和数据结构差异，不能直接迁移。
4. **缺乏系统化窗口级预训练数据选择研究**：据作者称，这是首个针对从零预训练TSFM进行系统窗口级基于损失的数据选择的Study。

## 核心贡献（创新点）
1. **首次系统性研究TSFM预训练的基于损失窗口级数据选择**：与现有任务级/微调级方法不同，本工作采用离线一次性选择策略，不修改目标模型训练过程。
2. **形式化参考损失（RFL）作为难度分数，并建立其与优化难度的理论联系**：证明了在局部Jacobian条件下，归一化MSE控制单样本梯度范数（Theorem 3.1），使RFL成为cheap且 principled的难度坐标。
3. **引入数据集分层选择策略以保留源覆盖与多样性**：通过在每个源数据集内独立计算百分位排名并保留中间α区间，避免了全局选择导致的某些源被严重低估或移除的问题。
4. **跨尺度与跨架构的RFL可迁移性分析**：同架构内小模型参考可近似大模型排序（Spearman ρ≈0.98）；跨架构迁移成功与否取决于参考与目标的损失函数兼容性（如TimesFM与Chronos-Bolt兼容，与Moirai不兼容）。

## 方法详解
1. **问题设定**：预训练语料划分为K个源数据集$\mathcal{D}=\bigcup_{k=1}^K\mathcal{D}_k$，每个样本为$(x_i,y_i,m_i)$，其中$x_i$为长度C的上下文，$y_i$为长度H的未来窗口，$m_i$为缺失位置掩码。目标是选择子集$S\subset\mathcal{D}$，$|S|\approx\alpha|\mathcal{D}|$。
2. **参考损失（RFL）定义**：用冻结的参考预测器$f_\phi$计算每个窗口的掩码MSE：$s_i^{\text{RFL}}=\ell_i(\phi)=\frac{1}{2M_i}\|r_i\|_2^2$，其中$r_i$为残差向量。高RFL表示参考模型难以解释该窗口。
3. **梯度-损失理论联系（Theorem 3.1）**：对MSE损失，单样本梯度$\|g_i\|_2^2=\frac{1}{M_i^2}r_i^\top J_iJ_i^\top r_i$，其中$J_i$为预测关于参数的Jacobian。在局部Jacobian条件（特征值$\lambda_i^-, \lambda_i^+$有界且相近）下，$\frac{2\lambda_i^-}{M_i}\ell_i^{\text{MSE}}\leq\|g_i\|_2^2\leq\frac{2\lambda_i^+}{M_i}\ell_i^{\text{MSE}}$，即归一化MSE控制梯度范数上限。
4. **中间区间选择动机**：低RFL窗口已被参考模型很好地预测，冗余；高RFL窗口可能包含噪声、分布偏移或不可学突变；中间RFL窗口保留非平凡残差同时与已学时间结构相近，梯度可与总体梯度对齐，提供稳定学习信号。
5. **数据集分层选择**：对源$k$，计算源内经验CDF$\widehat{F}_k(t)=\frac{1}{n_k}\sum_{j:g_j=k}\mathbb{I}[s_j^{\text{RFL}}\leq t]$和百分位排名$r_i=\widehat{F}_{g_i}(s_i^{\text{RFL}})$。保留$r_i\in[\frac{1-\alpha}{2},\frac{1+\alpha}{2}]$的窗口，每源保留$\alpha n_k$个，保证源比例$p_k^S=p_k$不变。
6. **计算成本**：仅需一次参考模型前向传播（离线），每窗口存储一个标量，排序复杂度$\sum_k O(n_k\log n_k)$，可与多个目标模型复用。

## 实验与结果
1. **数据**：来自Chronos和LOTSA，超100个源数据集、464万条单变量序列，涵盖气候、交通、健康、工业、合成数据等。GIFT-Eval包含91个任务配置，另用ETTh1/2、ETTm1/2、Weather做消融。
2. **目标模型**：Chronos-Bolt Base（编解码）、Moirai-Base（编码器）、TimesFM 2.5（解码器）。
3. **主要结果（Table 1，GIFT-Eval几何平均）**：
   - **80%保留率**：Chronos-Bolt MASE 0.777 vs 全数据0.796、随机0.799；CRPS 0.542 vs 0.555/0.549。**超越全数据预训练**。
   - **Moirai-Base 80%**：MASE 1.005 vs 全数据1.017、随机1.022；CRPS 0.680 vs 0.698/0.701。
   - **TimesFM 2.5 80%**：MASE 0.804 vs 全数据0.813、随机0.835；CRPS 0.554 vs 0.558/0.576。
   - 所有架构在全部保留率（40%/60%/80%）下均优于随机选择，绝对提升显著。
4. **参考模型分析（Table 2）**：同架构小模型参考（Chronos-Bolt Mini/Small）效果接近Base；TimesFM参考对Chronos-Bolt目标有效（MASE 0.786，CRPS 0.541），但对Moirai-Base目标无效（MASE 1.022退化至随机水平）。原因：TimesFM与Chronos-Bolt Mini的Spearman ρ=0.828（强），但与Moirai-Small仅ρ=0.254（弱），因损失函数不同（点/分位数误差vs分布负对数似然）。
5. **消融——RFL区间（Table 3）**：Central（中间区间）在40%和80%保留率下全面优于Bottom（最低RFL尾）、Top（最高RFL尾）和分层随机。图3验证轨迹显示Central在训练早期即分离最优。
6. **消融——分层vs全局（Figure 3c）**：分层选择在40%和80%保留率下均优于全局选择，证明源级别多样性保护的关键作用。

## 相关工作脉络
1. **LLM基于损失的数据选择**：Marion et al. (2023) 用冻结LM的cross-entropy/perplexity对文档打分排序筛选；本文借鉴此思路但将目标从离散token转移至连续时间序列，并引入分层策略解决多源多样性问题。
2. **CV梯度范数重要性采样**：EL2N (Paul et al., 2021) 用预测误差范数代理梯度重要性；本文给出显式Jacobian条件下的梯度-损失上/下界（Theorem 3.1），为时间序列场景提供严格理论支撑。
3. **DoReMi（Xie et al., 2023）**：用代理模型超额损失优化域混合权重；本文是样本级选择而非域级加权，且面向TSFM预训练。
4. **时间序列选择方法（Task-specific/Fine-tuning）**：TimeInf (Zhang et al., 2025) 用影响函数归因时间戳贡献；TSRating (Wu et al., 2026) 蒸馏LLM判断为跨域质量评分器；AdaRho (Taga et al., 2025) 在线过滤；三者均需重复适配/影响计算，无法扩展至预训练规模，本文是首个面向预训练的静态窗口级方法。
5. **时间序列基础模型**：TimesFM、Chronos、Moirai、Timer-XL、Time-MoE、Sundial；本文不改进架构，聚焦于这些模型的预训练数据选择这一被忽视的设计轴。

## 局限性与未来方向
1. **跨架构迁移的条件性**：参考模型与目标模型需共享兼容的难度排序（如损失函数一致），TimesFM→Moirai失败说明跨架构迁移并非普适；未来可探索架构无关的统一难度度量。
2. **仅评估单变量时序**：预训练语料为464万条单变量序列，多变量协同模式的窗口选择策略尚未探索。
3. **静态离线选择**：一次预计算RFL后固定，无法利用训练过程中的动态信息；未来可探索与在线数据选择结合。
4. **未讨论分布外/极端场景**：高RFL尾可能包含罕见但重要的分布偏移样本，完全丢弃可能影响鲁棒性；未来可研究软选择或重采样策略。
5. **计算资源虽减少但仍有前向成本**：对数十亿窗口的一次参考模型前向传播仍具开销，尤其对大参考模型；可探索更高效代理或蒸馏方案。

## 研究启发与可借鉴点
1. **"中间难度"假设的普适性**：本文对时间序列验证了LLM/CV中已观察到的"中等 perplexity/loss 样本最有价值"现象，但该原则在结构化数据（图数据、文本、音频）中的适用性值得系统检验。
2. **分层选择的多样性保护机制**：在每个源内独立做百分位截断而非全局截断，是一种轻量且有效的多样性正则化技术，可迁移至任何多源预训练场景（如多语言LLM、多模态预训练）。
3. **梯度-损失理论桥接**：Theorem 3.1 提供的"归一化损失控制梯度范数"的思路可推广至其他损失函数（如MAE、Huber、分位数损失），为不同TSFM架构的数据选择提供统一理论视角。
4. **参考模型跨尺度可迁移性**：同架构小模型可替代大模型做数据打分，这一发现大幅降低数据选择成本，对资源受限团队极具实用价值。
5. **与团队方向结合机会**：若团队关注TSFM预训练效率、数据混合策略、或少样本/零样本泛化，可将RFL框架与AdaRho的在线思想融合，或将其扩展至多变量/图时序基础模型的数据选择。

## 关键术语表
**TSFM（Time-Series Foundation Model）**：在大规模异构时序语料上预训练、可零样本迁移至未见预测任务的基础模型，如TimesFM、Chronos、Moirai。
**RFL（Reference Loss）**：用冻结参考预测器对每个上下文-未来窗口计算的预测损失值，作为该窗口"难度"的代理分数。
**Dataset-stratified Selection（数据集分层选择）**：在每个源数据集内独立按RFL百分位排名并保留中间α区间，而非在全局池上截断，以保持源级别多样性。
**GIFT-Eval**：通用时间序列预测模型评估基准（Aksu et al., 2024），包含91个任务配置，通过季节性朴素预测器归一化MASE和CRPS并取几何平均进行排名。
**MASE（Mean Absolute Scaled Error）**：缩放平均绝对误差，将预测误差除以身 seasonality-naive 预测器的误差，便于跨序列/跨量纲比较。
**CRPS（Continuous Ranked Probability Score）**：连续排序概率得分，评估概率预测的校准度与锐度，是对全分布的严格评分规则。
**局部Jacobian条件**：预测函数关于参数的Jacobian矩阵$J_iJ_i^\top$的特征值在有界范围内变化，使归一化损失能稳定控制梯度范数。
**窗口（Window）**：由滑动上下文-未来对构成的基本训练样本，$(x_i, y_i, m_i)$，其中$x_i$为历史上下文，$y_i$为待预测未来。

## 可复现要素
- **数据集**：Chronos数据集合集 + LOTSA，超100个源数据集、464万条单变量序列；论文未声明自定义数据处理脚本，但提到使用公开基准（ETTh1/2、ETTm1/2、Weather）及GIFT-Eval。
- **代码/权重**：论文未明确声明开源仓库链接；目标模型（Chronos-Bolt Base、Moirai-Base、TimesFM 2.5）均为已有开源模型，参考模型为同架构冻结版本。
- **关键超参**：训练步数（TimesFM 40k，其余100k）、初始学习率（TimesFM $3\times10^{-4}$，其余$1\times10^{-3}$）、warm-up步数（TimesFM 5k，其余2k）、batch size 512、最大上下文长度2048、预测长度（Chronos 64、Moirai 96、TimesFM 128）、AdamW + cosine decay + gradient clipping。
- **保留率**：40%、60%、80%三档。
