# 论文速读：Predictive-Geometry-of-Hidden-Trajectories-in-Transformers

## 一句话总结
本文从终端下一词预测损失出发，形式化了解码器型 Transformer 中间隐藏状态的局部预测几何：在低损失轨迹附近，逐层 loss-to-go 函数的主导曲率由输出分布的 pullback Fisher 算子决定。该算子自然分离输出敏感方向与预测空方向，并导出具有严格因果支撑的 token 级曲率分数 κ，为低秩压缩、结构化剪枝与几何感知蒸馏提供了可计算的损失导向信号。

## 研究问题与动机
- **核心问题**：预训练解码器 Transformer 仅在末端施加 next-token prediction 损失，该损失如何隐式约束各中间层的隐藏状态轨迹？哪些残差流方向对最终预测敏感，哪些近似不可见？
- **现有工作不足**：
  1. 隐藏表示的紧凑性多被经验刻画（如内蕴维度的层间扩张-收缩轮廓），未从终端预测目标本身推导相关方向与因果重要性。
  2. 激活空间压缩与低秩适配（LoRA/SVD 等）通常采用均匀或启发式秩分配，缺乏基于损失曲率的定向理论保证。
  3. Token 剪枝主要依赖注意力强度等浅层指标，缺少与终端预测分布直接挂钩且满足因果支撑的替代度量。
  4. 低秩蒸馏多聚焦输出分布匹配，未显式利用中间层误差在预测几何下的加权惩罚，导致学生模型在敏感方向恢复不足。

## 核心贡献（创新点）
1. **定义逐层 loss-to-go 并证明其局部 Hessian 主导项为 pullback Fisher 算子**。该结论将终端损失对中间状态的隐式约束严格形式化为可度量的椭球管状低损失几何。*与已有工作的本质区别*：先验研究仅经验统计表示结构，本文从优化目标出发导出曲率主干项并提供理论误差界。
2. **揭示算子谱结构可自然分离输出敏感方向与一阶预测空方向（ker J̄_ℓ）**。在此基础上给出局部可观察商空间的刻画，并证明截断尾部带来的二次损失增量受 λ_{k+1} 控制。*与已有工作的本质区别*：不同于仅报告维度或熵的方法，本文提供基于终端 Fisher 度量的可检验方向分解与可证明的保留上界。
3. **推导 token 级几何显著性分数 κ_{ℓ,s} = ||F^{*1/2} H_{ℓ,s}||_F^2**。证明其在标准因果掩码下仅支撑于目标 token 的祖先集，并由层间 Jacobian 耦合路径乘积控制上界。*与已有工作的本质区别*：将全局曲率投影至 token 纤维，得到兼具因果刚性、损失感知与可微性的新指标，可直接替代或增强注意力强度信号。
