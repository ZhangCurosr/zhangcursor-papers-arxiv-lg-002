# 论文速读：HyDI-A-hybrid-Deep-Learning-Inductive-Logic-Programming-ense

## 一句话总结
论文提出一种名为 HyDI 的混合集成架构，将深度神经网络（DL）与基于归纳逻辑编程（ILP）的规则分类器相结合，用于层次化多标签分类任务；在 ChEBI 化学本体案例中，HyDI 在仅损失 0.6% macro-F1 的情况下，为 314 个叶子类别提供了可自然语言解释并可视化的分类结果。

## 研究问题与动机
1. 深度学习模型虽然性能优异，但本质上是黑盒，缺乏可解释性。
2. 层次化多标签分类（HMLC）面临严重的类别不平衡问题，层级越深类别越稀疏。
3. 现有符号分类方法（如手动编写规则或 MSOL 公式）依赖专家知识，难以扩展。
4. 已有 DL+ILP 结合工作多为事后解释（post-hoc），而非直接从原始数据中学习可解释规则。

## 核心贡献（创新点）
1. **提出 HyDI 混合集成架构**：将全局多标签 DL 分类器与针对叶子类别的 ILP 二值相关性分类器融合，在保持 DL 性能的同时提升可解释性。
2. **设计可扩展的 ILP 代价函数**：通过调节假负/假正权重（α, β）生成不同倾向（高召回或高精确）的规则集，丰富候选解空间。
3. **基于验证 F1 的自动模型选择机制**：对每个叶子类别，根据验证集 F1 分数在 DL 模型与多个 ILP 规则中择优，实现性能与可解释性的平衡。
4. **构建端到端解释生成管线**：将 ILP 规则自动翻译为自然语言全局解释，并通过变量绑定在分子图上高亮相关原子，生成局部解释。

## 方法详解
- **ILP 规则学习**：使用 Popper 系统，代价函数为 `cost(h) = size(h) + α·FN(h) + β·FP(h)`，设置三种配置：ILP-FP（α=1, β=3）、ILP-FN（α=3, β=1）、ILP-REG（α=1, β=1）。每个叶子类别独立构建一个 ILP 问题，正样本随机选 200 个，负样本通过标签分类树的 BFS 选取结构相近的负例（最多 200 个）。
- **分子逻辑表示**：将分子图转换为 Prolog 事实，谓词包括 `has_atom/2`、`bSINGLE/2`、`charge0/1`、`cip_code_R/1`、`steroid_n/1` 等。
- **集成决策机制**：非叶子类别均由 DL 模型预测；叶子类别根据验证 F1 分在 DL 与各 ILP 规则中选优，F1 计算时 ILP 规则的性能需考虑其直接 superclass 的 DL 预测正确性（TP 需满足所有 superclass 也被正确预测）。
- **解释生成**：
  - **全局解释**：将 ILP 规则中的谓词替换为自然语言，并补全隐式 superclass 条件，形成可读的规则描述。
  - **局部解释**：使用 xclingo 对具体样本进行变量绑定，将规则中的原子变量映射到分子图中的实际原子，并高亮显示。

## 实验与结果
- **数据集**：ChEBI25-3STAR，825 个叶子类别，51,670 个分子样本，80/10/10 划分。
- **基线**：augmented GAT 深度学习模型。
- **ILP 规则性能**：ILP-FN 生成 666 条规则，macro F1 0.680；ILP-FP 生成 520 条规则，macro F1 0.640；ILP-REG 生成 636 条规则，macro F1 0.681。
- **集成性能**：HyDI 与 DL 基线相比，micro F1 仅下降 0.003（0.731 vs 0.734），macro F1 下降 0.008（0.729 vs 0.737）。在 314 个叶子类别中，260 个由 ILP-FN 规则预测，511 个由 DL 预测。
- **最强结果**：ILP-FN 在共享类别（508 个）上取得最高 macro F1（0.730），HyDI 集成在保持 DL 性能的同时显著提升了可解释性。

## 相关工作脉络
1. **Chebifier 2**：将预定义的 MSOL 逻辑规则与多个 DL 模型加权集成，而 HyDI 使用 ILP 自动从数据学习规则，且采用单分类器切换而非加权平均。
2. **LIME+ILP 事后解释**：先用 CNN 分类，再用 ILP 解释其预测；HyDI 的 ILP 规则直接从原始分子数据学习，提供更直接的因果解释。
3. **Chemical Classifier Programs (CCPs)**：利用 LLM 从自然语言定义生成 Python 代码进行分类；HyDI 直接从分子样本学习逻辑规则，不依赖文本定义。
4. **基于注意力机制的可解释 DL**：通过 attention 权重可视化解释 Transformer 分类；HyDI 提供的是基于逻辑规则的明确符号解释与分子图高亮。

## 局限性与未来方向
- **局限性**：
  1. 部分叶子类别因结构定义模糊或缺乏合适谓词而无法生成有效规则。
  2. 叶子类别样本稀少导致验证集 F1 波动较大，可能影响模型选择稳定性。
  3. 当前谓词无法表达某些复杂化学概念（如 α/β 立体构型）。
- **未来方向**：
  1. 引入预定义官能团和环结构谓词以增强表达能力。
  2. 探索谓词发明（predicate invention）与否定推理。
  3. 与领域专家协作，利用全局/局部解释进行规则迭代优化。

## 研究启发与可借鉴点
1. **扩展代价函数调节规则倾向**：通过调整假正/假负权重，可在 ILP 任务中生成多样化的规则集，供后续集成筛选。
2. **基于验证性能的集成决策**：针对层次化结构的叶子类别，利用验证 F1 在多个候选分类器间选择，兼顾性能与可解释性。
3. **结构数据到逻辑程序的转换范式**：将分子图编码为 Prolog 事实的方法可迁移至其他具有图结构的领域（如材料科学、蛋白质相互作用）。
4. **全局+局部解释的组合**：自然语言规则翻译与可视化高亮相结合，为领域专家提供多粒度理解途径。

## 关键术语表
- **HyDI**：Hybrid Deep Learning-Inductive Logic Programming ensemble，即本文提出的混合集成架构。
- **Inductive Logic Programming (ILP)**：归纳逻辑编程，一种利用背景知识和示例学习一阶逻辑规则的机器学习方法。
- **ChEBI25-3STAR**：基于 ChEBI 本体的化学分子分类数据集，包含 825 个叶子类别和 51,670 个样本。
- **augmented GAT**：增强型图注意力网络，作为本文的深度学习分类器骨干。
- **Popper**：一个基于“学习自失败”范式的 ILP 系统，支持噪声数据和可扩展代价函数。
- **Macro F1**：对所有类别的 F1 分数取平均，对少数类更敏感。
- **局部解释**：针对单个样本，展示 ILP 规则中哪些原子被绑定以满足规则条件。
- **全局解释**：将 ILP 规则翻译为自然语言，描述整个类别的定义条件。
