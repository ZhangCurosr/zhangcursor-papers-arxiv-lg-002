# 论文速读：PLANETARY-FEATURE-FIELDS-ARE-SCALABLE-EARTH-REPRESENTATIONS

## 一句话总结
论文提出了行星特征场（Planetary Feature Fields, PFFs），一种全局、空间局部的显式-隐式混合神经场表示方法，能够以极高压缩比（约 1800×）联合存储与重建多种地球观测产品（原始观测、预计算嵌入、地图产品），并在下游像素级分割、变化检测和分类任务上保留约 90% 以上的原始特征性能，同时支持高效地持续学习新时间步与新产品而不破坏已有表示。

## 研究问题与动机
- **数据爆炸与存储压力**：卫星观测、预计算嵌入和地图产品等地球观测数据以独立、拍字节规模增长，单独存储与维护成本随时间线性上升。
- **已有表示难以兼顾紧凑性、细节保留与可扩展性**：预训练模型提取特征需大量计算与原始数据访问；纯隐式地理编码器（如全球位置编码）能给出紧凑表示但丢失空间细节；预计算嵌入保留了特征但存储与传输开销巨大。
- **缺乏跨产品共享的紧凑连续表示**：不同分辨率、维度、语义的产品通常独立生产与更新，未利用它们在时空上的冗余，导致表示效率低下且难以持续扩展。
- **下游任务对高保真时空特征的需求**：精细的空间制图与年际变化检测要求特征既高度压缩，又能在恢复后保留足够的预测信息。

## 核心贡献（创新点）
- **提出 PFFs 框架**：构建了一种全球尺度的空间局部显式-隐式混合神经场，通过共享的因式分解特征体联合建模多种异质 EO 产品，实现了远超传统存储方式的压缩率。
- **设计了灵活的因式分解体结构与多产物联合训练机制**：采用 TensoRF(VM) 或 K-Planes 对时空网格进行因子分解，并通过产品特定的轻量解码器映射到各自特征空间，支持不同维度与分辨率的产品共享同一紧凑表示。
- **验证了高压缩下的下游性能保留与加速推理**：在约 1800× 压缩率下，重建特征在分割、变化检测等任务上仍能保留约 90% 甚至更高比例的原特征性能，并将特征获取延迟降低一个数量级。
- **实现了可持续扩展的新时间步与新产品学习**：新增时间步只需扩展少量时序因子、冻结原有参数即可保持历史输出精确不变；新增产品仅需训练一个轻量解码器，实现了高效的持续学习。

## 方法详解
- **空间局部领域划分**：将地理域划分为多个有界区域，每个区域独立学习一个局部函数，查询时通过路由将坐标映射到对应区域，并将空间范围重缩放至 $[0,1]^2$，从而避免全局坐标模型的容量瓶颈。
- **显式因式分解特征体**：用一个坐标索引的共享数组集合表示时空特征，替代直接存储稠密 $N_x N_y N_t d_h$ 网格；分别采用两种因子分解形式：
  - TensoRF(VM)：对每个空间/时间轴 $a$，结合标量平面因子 $M_r^{bc}$ 与线因子 $v_r^a$，以及共享 basis 向量 $\mathbf{b}_r^a$，构造 $\mathbf{h}(\mathbf{x},t)=\sum_r v_r^x(x)M_r^{yt}(y,t)\mathbf{b}_r^x+\cdots$。
  - K-Planes：存储向量值平面因子 $\mathbf{P}^{xy}, \mathbf{P}^{xt}, \mathbf{P}^{yt}$，通过逐元素乘法组合：$\mathbf{h}(\mathbf{x},t)=\mathbf{P}^{xy}\odot\mathbf{P}^{xt}\odot\mathbf{P}^{yt}$；K-Planes 使用多尺度（147、294、588、1176）拼接得到 $d_h=128$。
- **隐式产品特定解码器**：对每个产品 $m$，使用小型 MLP 解码器 $g_m$ 将共享特征映射为该产品的原生特征空间：$\hat{\mathbf{y}}_m(\mathbf{x},t)=g_m(\mathbf{h}(\mathbf{x},t))$；对 AlphaEarth 等嵌入使用余弦损失，其余使用标准化均方误差，缺失值通过掩码处理。
- **持续学习机制**：
  - 新增时间步：在时序因子末尾追加新的参数切片（VM 增加约 0.19%，K-Planes 约 0.22%），冻结原有参数与新切片一同训练，保证历史年份输出比特级精确保持不变。
  - 新增产品：冻结共享场与所有现有解码器，仅训练新产品的解码器（约 1.25M 参数，占整体约 2%），用少量目标像素即可适配，原有产品输出同样比特级保留。

## 实验与结果
- **数据集**：使用 14 种 EO 产品（含 Sentinel-1/2、Landsat、AlphaEarth、TESSERA、DEM、Canopy Height 等），覆盖 2017–2025 年；重建评估基于 100 个全球分布的 PFFBENCH tile，总计约 67 亿空间位置与 16TB 源数据；下游任务涵盖 PASTIS、FTW、SwissCrop25、EuroMineNet、BigEarthNet-v2 与 So2Sat-LCZ42。
- **基线**：单产品神经网络场（ReLU/ Fourier、SIREN、iNGP、K-Planes、TensoRF(VM)），在相同参数预算下进行均匀分配或按位长比例分配。
- **重建质量**：在匹配存储条件下，共享因式分解特征体的 PFF 相比单产品场将平均归一化失真降低约 20%；PFF-VM 在 AlphaEarth、Sentinel-2 等产品上获得最高均值分数（例如表 5 中 PFF-VM 均值 90.5，单产品 Solo VM 均值 88.8）。
- **下游性能保留**：
  - PASTIS 作物分割：PFF-VM 对 AlphaEarth、TESSERA、Sentinel-2 分别保留 90%、90%、136% 性能。
  - FTW 巴西/南非田块分割：PFF-VM/K-Planes 保留约 90%–103%。
  - SwissCrop25：OA 与作物类型 mIoU 普遍达到 98%–111%。
  - EuroMineNet 年度变化检测：PFF-VM 对 AE/TE 的 AUPRC 与 F1@r 达到 97%–103% 保留。
- **推理速度**：在八核 CPU+L4 GPU 环境下，PFF 获取 AlphaEarth 嵌入比 Earth Engine API 快 17.9×，获取 TESSERA 嵌入比全瓦片下载快 15.5×；在 H100 GPU 上可实现每秒 970 万 AlphaEarth 嵌入的材料化吞吐。
- **持续学习**：新增 2025 年时间步时，PFF-Append 仅需 2% 的训练时间即可达到联合从头训练的 92% 重建得分，且历史年份完全比特级保留；若微调整个 PFF 或仅微调解码器，则出现灾难性遗忘。

## 相关工作脉络
- **神经字段（Neural Fields）**：PFFs 继承显式-隐式混合与局部编码思想，与 Instant-NGP、K-Planes、TensoRF 等同源，但将其拓展到多产品、长时序 EO 联合表示，而非单一场景或图像重建。
- **地理位置编码器（Geographic Location Encoders）**：此类方法给出全局隐式空间先验，适合宏观分布预测，但无法高保真恢复源数据；PFFs 以局部神经场直接替代稠密时空阵列，提供高细节的可重建表示。
- **预计算嵌入与存储压缩（Precomputed Embeddings / TerraCodec）**：前者将计算移至离线但仍需大量存储与带宽，后者针对单产品进行编码；PFFs 通过共享因子体同时压缩多种产品，并以参数化形式支持持续学习，而不需重新拟合历史数据。
- **特征场蒸馏（DFF、N3F、LERF、FeatureNeRF 等）**：将预训练 2D 特征蒸馏为可查询 3D 表示；PFFs 与之类似地共享隐式特征，但应用于地球观测的异构多源产品，强调时空连续性与跨产品复用。
- **持续学习神经场（CLNeRF、CD-NGP）**：采用回放或参数隔离更新既有表示；PFFs 通过冻结共享场并仅训练新增因子切片/解码器，实现严格比特级保留的历史一致性。

## 局限性与未来方向
- **压缩比比较的基准差异**：由于共享场可随冗余嵌入的加入而显著提高压缩比（如加入 Galileo 使压缩比从 1800× 升至 2800×），与针对单产品的传统压缩方法难以直接对比。
- **固定存储预算与有损重建**：当前 PFF 为固定参数量设计，不支持变率压缩；重建为有损表示，可能抹除高分辨率制图所需的高频细节，同时轻微平滑也可能带来去噪增益，两者尚未分离。
- **新时间步删除难以保持比特精确**：仅支持在时序末尾追加新切片以保持历史输出精确不变；若删除已有时间切片，插值锚点改变，无法维持相同精度。
- **持续学习的产品解码器容量限制**：新增产品虽仅需训练轻量解码器，但在极端信息量下可能受限；未来可探索自适应解码结构或更高效的跨产品特征路由机制。
- **全局一致性与边界效应**：按区域分片学习可能导致相邻瓦片在边界处出现轻微不连续；未来可引入跨瓦片的平滑约束或统一拓扑编码。

## 研究启发与可借鉴点
- **显式-隐式混合表示在连续时空数据上的可扩展性**：将 TensoRF/ K-Planes 因子分解引入多产品 EO 联合建模，为大规模遥感数据的连续压缩与重建提供了可复用的架构范式。
- **参数冻结的持续学习策略**：通过冻结共享表示仅训练新增时序切片或产品解码器，能够在保持历史输出精确的前提下实现低成本增量学习，适用于长期监测类任务。
- **跨产品共享特征体的容量分配设计**：证明共享因式分解体优于简单多分辨率哈希网格或共享编码+独立解码的组合，为多模态/多产品联合表征提供了结构选择依据。
- **基于标准化与掩码的异构数据训练策略**：针对不同数值类型（欧氏向量 vs. 单位嵌入）分别使用 MSE 与余弦失真，并通过掩码忽略缺失产品/时间/区域，提升了训练鲁棒性。
- **高吞吐推理的工程化路径**：将 PFF 导出为 ONNX、按区域独立推理会话、多硬件适配（CPU/GPU）的评估方式，为后续研究部署大规模地球模型提供了参考流程。

## 关键术语表
- **Planetary Feature Fields (PFFs)**：一种用于地球观测数据的空间局部显式-隐式混合神经场表示，通过共享因式分解特征体联合存储多种产品。
- **Factored Feature Volume**：将高维时空特征网格分解为若干低维因子（如向量-矩阵或三平面）的显式参数结构，用于高效存储与插值查询。
- **TensoRF(VM)**：基于向量-矩阵分解的显式特征体构造，结合标量平面因子与线因子及共享 basis 向量重建特征。
- **K-Planes**：使用多个向量值平面因子并通过逐元素乘法组合的显式特征体，支持多尺度拼接以增强表达能力。
- **Continual Learning (in PFFs)**：在已训练 PFF 基础上仅扩展新增时序因子或新增产品解码器并冻结其余参数，以实现低成本的增量学习与历史一致性保留。
- **Angular Skill / Cosine Distortion**：用于评估单位嵌入向量重建质量的指标，衡量相对于均值方向预测器的余弦失真减少比例。
- **PFFBENCH**：论文构建的全球地球观测基准数据集，包含 1000 个瓦片，按气候与地域均衡抽样并优先选取高熵区域。
- **Retention %**：下游任务中使用重建特征的性能相对于使用原始特征性能的百分比，用于量化表示压缩对任务影响的保留率。
