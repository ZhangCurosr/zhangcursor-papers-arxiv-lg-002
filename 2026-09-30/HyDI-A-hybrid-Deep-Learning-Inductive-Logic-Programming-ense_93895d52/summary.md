# 论文速读：HyDI: A hybrid Deep Learning-Inductive Logic Programming ensemble for multi-label classification

## 一句话总结
本文提出 HyDI 神经符号集成架构，面向层次化多标签分类（HMLC）任务，将深度学习模型与归纳逻辑编程（ILP）生成的规则分类器动态组合；在几乎不损失整体分类性能的前提下，为层级底层的叶子类别提供可追溯的规则与图文联合解释。

## 研究问题与动机
- **深度学习的可解释性缺失**：DL 模型在图像、文本和生物信息学等领域表现优异，但其预测结果本质上是黑盒，难以向领域专家提供直观、可验证的分类依据。
- **HMLC 的层级误差累积与样本不均衡**：高层类别样本丰富，适合 DL；底层叶子类别样本稀少且层级越深误差累积越严重（如深度为 10 的独立分类器组合，理论召回率仅约 0.60）。
- **现有符号方法的构建成本高**：传统化学分类依赖专家手工编写逻辑规则（如 MSOL 或 CCP），缺乏自动化学习能力，且难以直接利用数据驱动的特征。
- **后验解释方法的局限性**：LIME 等 post-hoc 解释只能近似黑盒决策边界，无法直接提供类别判定的因果性规则；本文希望 ILP 规则直接从输入数据中学习，而非事后拟合 DL 预测。

## 核心贡献（创新点）
1. **提出 HyDI 分层路由集成架构**：非叶子类别由原生多标签 DL 模型统一预测，叶子类别在 DL 与 ILP 二元相关分类器之间择优选择，实现性能与可解释性的结构化解耦。
2. **引入依赖上层预测的 ILP 评估机制**：ILP 规则的验证 F1 计算显式考虑了父类 DL 预测的正确性，避免将层级误差累积路径纳入单一规则的评分，更贴合真实分类链路。
3. **设计带偏置的 ILP 假设采样策略**：通过调节代价函数中假负（FN）与假正（FP）的权重（ILP-FN / ILP-FP / ILP-REG），生成风格迥异的规则池，为集成选择提供更丰富的候选。
4. **构建面向化学领域的全局+局部解释流水线**：将 ILP 子句自动翻译为自然语言规则，并通过变量实例化将关键原子高亮映射回分子图，实现逻辑规则与化学直觉的直接对齐。

## 方法详解
- **ILP 假设学习**：采用 Popper 系统，以“从失败中学习”迭代剪枝假设空间。扩展经典最小描述长度（MDL）代价函数：
  `cost(h) = size(h) + α·FN(h) + β·FP(h)`
  设置三种配置：ILP-FN（α=3, β=1，偏向高召回）、ILP-FP（α=1, β=3，偏向高精度）、ILP-REG（α=1, β=1，标准 MDL）。
- **分子逻辑化表示**：将 SMILES/结构信息转化为 Prolog 谓词知识库（BK），包含原子类型（`c/n/o`）、电荷（`charge0/charge_p/charge_n`）、氢原子数（`has_0_hs…has_at_least_N_hs`）、键类型（`bSINGLE/bDOUBLE`）、立体构型（`cip_code_S/R`）、甾体位置（`steroid_n`）等。
- **负样本采样策略**：对每个叶子类别，随机选 200 个阳性样本；阴性样本通过标签树广度优先搜索选取兄弟类或近亲类分子，确保负例在结构上尽可能贴近正例以提升规则区分度。
- **集成路由决策**：
  - 非叶子类别统一由增强型图注意力网络（augmented GAT）预测。
  - 叶子类别计算 DL 与各 ILP 规则的验证 F1：
    `F1(c) = 2·TP(c) / [2·TP(c) + FP(c) + FN(c)]`
  - ILP 规则的 TP/FN/FP 定义中，要求样本在所有直接父类上的 DL 预测正确；若规则数相同则优先保留 ILP；同分情况下以配置的宏观 F1（macro F1）作为 tie-breaker。
- **损失函数**：DL 部分采用二进制交叉熵（binary cross-entropy）损失，训练 200 轮，lr=10⁻³，batch_size=512。
- **解释生成**：
  - 全局解释：算法将 ILP 子句重排序并替换谓词为自然语言，结合隐式父类条件输出可读规则。
  - 局部解释：使用 xclingo 将规则变量接地到具体原子，在分子图上高亮参与判定的结构片段。

## 实验与结果
- **数据集**：ChEBI25-3STAR（825 个叶子类别、1808 个标签类、51,670 个分子样本，按 80/10/10 划分）。
- **基线**：相同的 augmented GAT 多标签 DL 模型（纯 DL 基线）。
- **ILP 规则产出**：ILP-FN 生成 666 条规则（macro F1=0.730，Recall=0.877）；ILP-FP 生成 520 条（macro F1=0.642）；ILP-REG 生成 636 条（macro F1=0.716）。149 个叶子类别在 60s 超时内未能生成任何规则。
- **集成性能**：HyDI 用 ILP 替换了 314/825 个叶子类别的预测，宏观 F1 从 DL 的 0.737 降至 0.731（下降 0.6%），微观 F1 从 0.920 降至 0.914（下降 0.6%），召回率基本持平。
- **最强结果与提升点**：ILP-FN 在共享 508 类别上表现最优（macro F1=0.730），且 ILP-FP 在 51 个类别上优于其他配置，证明多偏置配置能覆盖不同结构特征的类别；集成整体在保持 DL 基准性能的同时，为 314 个稀有叶子类别提供了可直接验证的规则解释。

## 相关工作脉络
1. **LIME+Aleph/ILASP 后验解释路线**（[22][6][21]）：先训练 CNN/SVM，再用 ILP 拟合其预测分布以生成局部/全局解释。本文与之本质区别在于 ILP 直接从原始分子数据学习规则，而非事后逼近黑盒，解释更具因果性。
2. **Chebifier 2 加权集成**（[7]）：对每类别将多个 DL 与手工逻辑定义按性能加权融合。本文不依赖加权投票，而是为每个叶子类别选定单一最优分类器（DL 或 ILP），使最终预测可明确溯源至单一模型。
3. **手工规则本体分类**（[15][9]）：专家用一阶逻辑/MSOL 手工定义 14~51 个化学类别。本文通过 ILP 自动化挖掘规则，并将规模扩展至 314 个叶子类别。
4. **LLM 生成化学分类程序**（CCPs，[19]）：基于 ChEBI 自然语言定义提示大模型生成 Python 程序。本文数据源为分子样本图结构而非文本定义，规则直接反映化学子结构特征。
5. **分子图 DL 分类**（[10][11]）：Transformer/GNN 在 ChEBI 上实现高性能分类，但解释依赖注意力可视化或隐空间 box embedding。本文在相同任务上补充了可形式化验证的逻辑规则与原子级高亮。

## 局限性与未来方向
- **谓词表达能力受限**：当前知识库无法精确计数原子数（如二萜需 20 个碳），也无法直接表达 α/β 空间构型，仅能近似使用 CIP 编码。
- **稀有类别的验证-测试泛化鸿沟**：叶子类别验证集可能仅含 2~3 个正样本，导致 ILP-REG 配置的验证 F1 与测试 F1 偏差较大，路由决策不稳定。
- **超时未生成规则的类别**：149 个叶子类别在 60 秒内未能产出任何 ILP 规则，说明部分类别缺乏明显的结构判别特征或当前 BK 覆盖不足。
- **未来方向**：引入预定义官能团与环系谓词；探索谓词发明（predicate invention）与否定推理；建立专家人机协同迭代修正流程，利用生成解释反馈自动验证规则修订。

## 研究启发与可借鉴点
1. **层级感知的模型路由设计**：对深度层级分类任务，可将“泛化能力强的高层类别留给 DL，判别性强的底层类别交给符号规则”，既缓解样本不均衡，又降低误差累积路径。
2. **多偏置代价函数生成候选池**：通过调节 FN/FP 权重差异化的训练目标，能有效扩充假设空间多样性，为后续集成选择提供更优的 trade-off 覆盖。
3. **依赖链显式建模的评估方式**：在评估底层分类器时，将上层预测正确性作为前置条件写入 TP/FN/FP 计算，比独立评估更符合真实级联分类场景。
4. **符号规则到视觉/文本的双通道解释**：变量接地（grounding）技术可将抽象逻辑条款直接映射回输入图的局部结构，适用于需要领域专家快速验证的科研场景。

## 关键术语表
- **HyDI**：一种混合深度学习与归纳逻辑编程的神经符号集成架构，用于层次化多标签分类。
- **ILP（Inductive Logic Programming）**：基于一阶逻辑与背景知识库，从正负示例中自动归纳假设规则的机器学习范式。
- **Popper**：采用“从失败中学习”策略的元级 ILP 系统，支持噪声数据与大域搜索剪枝。
- **ChEBI25-3STAR**：从 ChEBI 本体中筛选出的、含至少 25 个分子子类且经人工审校的 3-STAR 高质量子集。
- **augmented GAT**：本文采用的增强型图注意力网络，包含原子层、 motifs 层与全局节点三层消息传递结构。
- **Macro F1 / Micro F1**：Macro 为各类别 F1 的算术平均，对少数类更敏感；Micro 为全局 TP/FP/FN 汇总后计算的 F1。
- **Binary Relevance**：将多标签分类拆分为多个独立二分类问题的建模范式，本文 ILP 规则即按此方式针对每个叶子类别训练。
- **Predicate Invention**：ILP 中自动学习新谓词（如组合已有原子特征形成新的结构性概念）的技术，可突破现有背景知识表达能力瓶颈。

## 可复现要素
- **数据集**：ChEBI25-3STAR 及对应 ILP 问题已公开于 Hugging Face（`chebai/ChEBI25-3STAR`、`chebai/ChEBI25-3STAR-ILP`）。
- **代码**：数据集构建、ILP 运行与集成脚本开源至 GitHub（`ChEB-AI/chebILP`、`ChEB-AI/python-chebai-graph`）。
- **权重**：DL 模型权重公开于 Hugging Face（`chebai/gat-aug-chebi25-3star_v248`）。
- **关键超参**：GAT 训练 200 epoch，lr=1e-3，batch_size=512，BCE loss；ILP 超时 60s，最大变量 6，最多 2 子句，每子句最多 8 body literals；Popper 启用 NuWLS anytime solver。
