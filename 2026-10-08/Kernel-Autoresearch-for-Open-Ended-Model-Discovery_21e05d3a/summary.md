# 论文速读：Kernel-Autoresearch-for-Open-Ended-Model-Discovery

## 一句话总结
本文提出 **KERNAUT** 框架，将核函数的“语义提议”与“数学合法性”解耦，通过四种构造契约与三层数值验证保证生成核严格对称正定（PSD），并借助 MAP-Elites 档案实现开放式核进化搜索；在 BBO、酶动力学、温室气体时间与血糖预测四项基准上验证了开放搜索的优越性与跨 profile 迁移能力。

## 研究问题与动机
1. **自动化核设计的有效性-表达力两难**：固定基核+运算符语法能保证数学有效性但搜索空间受限；无限制程序可突破语法却难以保证 PSD。
2. **LLM 生成核的数值鲁棒性不足**：压力测试显示仅 22–58% 的 LLM 生成核能通过随机输入数值检查，且在不同尺度/维度下极易失效。
3. **缺乏可复用、可迁移的归纳偏置库**：现有工作多依赖特定基准或固定架构，难以将发现的核泛化至未见任务，且无法系统化积累高质量核资产。

## 核心贡献（创新点）
1. **提出 KERNAUT 框架，实现提议与验证解耦**：将 LLM 的自由程序合成与可信解释器的数学校验分离，避免传统闭包语法对搜索空间的硬性限制。
2. **设计四种构造契约保证 PSD**：从特征映射、谱表示、拉回与闭包四个数学层面定义合法核算子，从源头杜绝无效核生成。
3. **引入 MAP-Elites 质量-多样性档案与 Gram 指纹新颖性筛选**：以 niche×特征增长×新颖度带管理核库，用软惩罚阈值 $\tau_{nov}$ 平衡探索与利用，避免陷入局部重复。
4. **跨多领域验证开放式核发现的价值**：在 BBO、ChemBench、NOAA 与 GlucoseBench 上均显著优于固定语法基线与主流元学习方法，证明发现的核编码了可复用的归纳偏置。

## 方法详解
1. **三阶段验证流水线**：编码代理（LLM）用 Python 生成核组件 → 可信解释器按构造契约组装 Gram 矩阵 → 三层接受检查（T0 语法/类型检查 → T1 随机输入数值稳定性 → T2 严格 PSD 投影检验），仅 T2 通过者进入档案。
2. **构造契约（Construction Contracts）**：
   - **特征映射**：$\kappa(x,y)=\varphi_\theta(x)^\top\varphi_\theta(y)$
   - **谱表示**：$\sum_j w_j\cos(\omega_j^\top(x-y))$，其中 $w_j=r_j^2/M\ge0$
   - **拉回**：$k_0(T_\theta(x),T_\theta(y))$，$k_0$ 取自受信任库（RBF/Matérn/有理二次）
   - **闭包**：树结构组合，叶子为库核或前三类，通过和/积/非负标量乘法构建（Proposition 1 保证对称 PSD）
3. **档案管理与搜索策略**：采用 MAP-Elites 算法按 niche×特征增长×新颖度带分格，每格保留最优精英；引入 Gram 矩阵指纹距离 $d_{nov}$ 识别重复，配合软惩罚 $\tau_{nov}$ 鼓励探索。
4. **搜索配置**：新生成概率 $p_{new}=0.35$，$k_{top}=k_{insp}=3$；BBO/预测任务批次 $B=12$，化学任务 $B=8$；超参调优最多使用 64 次 Halton 序列试验。

## 实验与结果
1. **BBO（黑盒优化）**：开放搜索相较闭包搜索使 test CRPS 降低约 **8%**（11/12 配对获胜），对 6/7 核家族优于 Matérn-5/2（平均提升 **3%** CRPS）；GPT-6 Astra 单代理核实现 **8.3%**±2.0% 的 CRPS 增益（$p=0.003$ vs 集成），人类优化 DWF 核后 CRPS 再降 **5.7%**、后悔值降 **7.8%**，整体优于 FSBO。
2. **酶动力学（ChemBench）**：验证误差可有效预测跨机制迁移能力；GPT-6 Astra 选核在未见机制上误差较优化 ARD **降低近一半**，集成选出核较 Matérn-5/2 降低约 **25%**。
3. **时间序列（NOAA 温室气体）**：残差周期银行核在 CFC-12/CFC-11 外推任务中，从 58 个候选中排名第一。
4. **葡萄糖动态（GlucoseBench）**：低样本 regime 收益最大，2 条训练 episode 几何均值 MSE **降低 38–67%**；6 episode + 45min prefix 下降低 **0–23%**。跨 profile 一致性方面，青春期验证误差预测成人测试误差的 Spearman $\rho = 0.94$（$p=10^{-11}$）。
5. **最强结果**：BBO 任务中 GPT-6 Astra 单代理核平均 CRPS 增益 **8.3%**±2.0%，显著优于所有固定语法与元学习基线。
