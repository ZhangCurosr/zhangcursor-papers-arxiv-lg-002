# 论文速读：ORTHOGEN: A GENERATIVE ORTHOGONAL LEARNER FOR TIME-VARYING TREATMENTS

## 一句话总结
本文提出ORTHOGEN，首个用于时间依赖治疗下条件分布潜在结果（CDPO）估计的Neyman正交、双稳健生成学习器，通过生成递归g计算与倾向得分调整结合，在合成、半合成及真实世界数据上显著优于基于IPTW的现有方法。

## 研究问题与动机
1. **时间依赖治疗下CDPO估计的临床重要性**：在肿瘤化疗、糖尿病胰岛素剂量调整等场景中，临床医生需要理解不同治疗序列对患者未来结局（如肿瘤大小、低血糖风险）的完整概率分布影响。
2. **时间依赖混杂导致简单历史调整有偏**：患者特征随时间变化且受早期治疗影响，进而影响后续治疗决策和最终结局，仅 conditioning on prediction origin 的历史会遗漏关键混杂。
3. **现有调整策略（IPTW）在高 horizonte 下不稳定**：基于逆概率处理权重的方法在重叠有限时权重方差大，尤其治疗序列较长时性能显著下降。
4. **现有生成方法存在三个维度空白**：静态治疗 vs 时间依赖治疗、均值结局 vs 完整分布、单一IPTW调整 vs 更稳定的g计算调整，缺乏结合生成模型与双稳健性质的学习时间依赖CDPO的方法。

## 核心贡献（创新点）
1. **提出生成递归g计算调整策略**：将传统递归g计算从条件均值扩展到全条件分布，通过向后递归传播条件结局分布而非模拟完整协变量轨迹，提高效率。
2. **开发PI与RA生成学习器作为基线**：基于生成递归g计算构建插件式（PI）和回归调整式（RA）学习器，但二者对 nuisance 估计误差一阶敏感。
3. **设计ORTHOGEN正交学习器**：结合生成递归g计算与倾向得分调整，构造Neyman正交风险函数，使目标估计对 nuisance 函数的一阶误差不敏感。
4. **证明ORTHOGEN的理论性质**：证明其Neyman正交性（定理1）、准Oracle效率及速率双稳健性（定理2），即一个nuisance收敛较慢时可用另一个更快收敛补偿。
5. **提供灵活生成骨干实例化**：方法模型无关，可实例化为归一化流（NFs）和扩散模型（DMs），在多种实验设置中验证有效性。

## 方法详解
1. **问题设定**：观察纵向轨迹，预测原点为 $t$，治疗 horizon $\tau$，目标为学习 $P(Y_{t+\tau}[\bar{a}_{t:t+\tau-1}] | \bar{H}_t = \bar{h}_t)$，即给定治疗序列 $\bar{a}$ 和观测历史 $\bar{H}_t$ 的潜在结局条件分布。
2. **生成递归g计算核心递归**：
   - **终端阶段**：$\xi_{t+\tau-1}^{\bar{a}}(y|\bar{h}_{t+\tau-1}) = P(Y_{t+\tau}=y|\bar{H}_{t+\tau-1}=\bar{h}_{t+\tau-1}, A_{t+\tau-1}=a_{t+\tau-1})$，直接由观测结局拟合。
   - **向后递归**：对 $\delta = \tau-2,...,0$，$\xi_{t+\delta}^{\bar{a}}(y|\bar{h}_{t+\delta}) = \mathbb{E}[\xi_{t+\delta+1}^{\bar{a}}(y|\bar{H}_{t+\delta+1}) | \bar{H}_{t+\delta}=\bar{h}_{t+\delta}, A_{t+\delta}=a_{t+\delta}]$。
   - **伪样本拟合**：每个阶段从已拟合的后继密度采样伪结局，用于拟合前一阶段的连续性密度。
3. **ORTHOGEN风险函数**：
   $$\widehat{\mathcal{L}}_{\text{OrthoGen}}^{\bar{a}}(g_{\bar{a}}) = \mathbb{P}_n\left[\widehat{R}_{t:t+\tau-1}^{\bar{a}}\ell_{g_{\bar{a}}}(Y_{t+\tau},\bar{H}_t) + \sum_{\delta=0}^{\tau-1}\widehat{R}_{t:t+\delta-1}^{\bar{a}}(1-\widehat{r}_{t+\delta}^{\bar{a}})\widehat{m}_{t+\delta}^{g_{\bar{a}},\bar{a}}(\bar{H}_{t+\delta})\right]$$
   其中 $\widehat{r}$ 为单步逆倾向比，$\widehat{R}$ 为累积积，$\widehat{m}$ 为基于连续性密度的生成分数期望。
4. **两阶段估计**：先估计倾向得分 $\widehat{\pi}$ 和连续性密度 $\widehat{\xi}$（nuisance），再用上述风险拟合目标生成模型 $g_{\bar{a}}$。支持NFs（条件最大似然）和DMs（去噪分数匹配）。

## 实验与结果
1. **数据集**：
   - **完全合成数据**：纵向DGP，3维连续结局，高斯/非对称拉普拉斯混合。
   - **半合成MIMIC-III**：真实ICU患者协变量轨迹+模拟治疗与结局。
   - **真实MIMIC-III**：保留实际机械通气治疗与舒张压结局。
   各数据集3000训练/1000验证/1000测试轨迹。
2. **评估基线**：IPTW（唯一现有CDPO方法）、PI、RA；使用归一化流（NFs）和扩散模型（DMs）两种骨干。
3. **主要结果**（平方2-Wasserstein代价，越低越好）：
   - **合成数据**：$\tau=5$ 时，DM版ORTHOGEN（0.383）比IPTW（0.522）降低26.8%。
   - **半合成数据**：所有 $\tau$ 下ORTHOGEN consistently最优，$\tau=5$ 时NF版0.73 vs IPTW 2.06（降64.6%）。
   - **真实数据**（CRPS）：$\tau=5$ 时NF版ORTHOGEN（0.442）比IPTW（0.472）降6.4%，DM版0.475 vs IPTW 0.472（基本持平）。
4. **关键结论**：ORTHOGEN在更长治疗 horizonte 下优势更显著，验证了其双稳健性对 nuisance 误差的容忍度；DM通常优于NF，但计算成本更高。

## 相关工作脉络
1. **静态治疗CDPO生成方法**：Yoon等（2018）GANITE、Ma等（2024）DiffPO等仅针对单次静态治疗，无法处理时间依赖混杂。
2. **时间依赖治疗均值估计方法**：Bica等（2020）、Melnychuk等（2022）、Frauen等（2025）等聚焦条件平均潜在结果（CAPO），丢失分布信息。
3. **全轨迹模拟方法**：Li等（2021）G-net、Xiong等（2024）G-transformer模拟完整DGP，但目标为轨迹生成而非直接学习CDPO。
4. **现有时间依赖CDPO唯一方法**：Mu等（2025）结合IPTW与扩散模型，但IPTW权重不稳定且无双稳健性。
5. **正交学习器静态扩展**：Melnychuk & Feuerriegel（2026）GDR-learners实现静态CDPO的Neyman正交，本文将其推广至时间依赖设置。

## 局限性与未来方向
1. **计算成本较高**：扩散模型训练耗时（平均176分钟 vs NF 110分钟），递归g计算需多阶段伪样本采样，可能限制超 horizon 应用。
2. **正定性假设依赖**：理论要求估计倾向得分严格大于零，实际中极端协变量组合可能导致权重裁剪，影响稳定性。
3. **仅验证二元治疗**：实验设定为二值治疗，连续或多元治疗的处理未讨论。
4. **未来方向**：探索更高效的主函数估计（如神经微分方程）、扩展到连续时间治疗、结合强化学习进行动态治疗策略优化。

## 研究启发与可借鉴点
1. **生成递归g计算的设计范式**：将传统因果推断的g计算与生成模型结合，通过伪样本向后传播分布信息，避免完整轨迹模拟，可迁移至其他分布估计任务。
2. **正交学习器与生成骨干的融合**：证明Neyman正交性在扩散模型、归一化流等不可微密度估计中同样成立，为鲁棒生成建模提供新思路。
3. **双稳健性的速率保障**：定理2揭示 nuisance 误差以乘积形式进入界，允许一个组件收敛慢而另一组件快，指导实际中资源分配（如用简单模型估计倾向得分，复杂模型估计连续性密度）。
4. **实验设计借鉴**：使用合成/半合成/真实三阶段验证，Wasserstein距离与CRPS互补评估，为医疗因果预测研究提供 benchmark 标准。
5. **长 horizonte 下的优势凸显**：随着治疗序列增长，ORTHOGEN相对IPTW的优势扩大，提示双稳健方法在复杂动态决策场景中价值更大。

## 关键术语表
**CDPO（条件分布潜在结果）**：给定患者历史和固定治疗序列，潜在结局的条件概率分布，比均值估计提供更丰富信息。
**生成递归g计算**：从终端结局向后递归拟合连续性密度，每步用伪样本替代未观测结局，实现分布级调整。
**Neyman正交性**：目标风险对 nuisance 函数的小扰动一阶不敏感，提升估计稳健性。
**双稳健性**：倾向得分或连续性密度任一正确指定即可得无偏估计，两者均错时仍保持乘积收敛。
**倾向得分**：给定历史下接受某治疗的概率，用于权衡观察数据中的选择偏差。
**连续性密度**：递归g计算中表示剩余治疗序列对终端结局分布影响的中间条件密度。
**平方2-Wasserstein代价**：衡量两个概率分布差异的 Optimal Transport 距离，用于分布估计评估。
**CRPS（连续排序概率分数）**：评估单变量预测分布准确性的严格评分规则，仅需观测事实值。
