# 论文速读：Kuration-SDK-Addressing-the-Virtual2Real-Gap-via-Data-Curati

## 一句话总结
本文通过严格控制变量的对照实验首次实证了动作条件世界模型的**Virtual2Real Gap**：同格式/同分布的CS:GO与CS2游戏语料训练出相同架构模型后，FVD/LPIPS/JEDi等定量指标相近甚至更优，但交互式可玩性显著分化。为此团队开源了**Kuration SDK**数据诊断工具，并证明基于“动作-状态一致性（pixel-shift幅值）”的策展策略能有效提升模型控制响应与物理合理性，而传统视频指标在达到阈值后无法可靠表征数据质量。

## 研究问题与动机
- **评估基准缺失**：当前动作条件世界模型的SOTA评测要么依赖下游任务训练与Agent性能，要么仅提供有限的视觉相似性信号，缺乏通用、域无关的质量诊断标准。
- **指标与可玩性脱节**：DIAMOND等扩散世界模型在Rollout中频繁出现地图瞬移、几何裁剪、违反物理的连续跳跃等问题，但这些长期交互缺陷无法被单帧或短片段指标（FVD、LPIPS）捕获。
- **数据归因不明**：即便严格匹配地图、分辨率、帧率与动作编码，不同来源的虚拟环境数据仍会导致模型在交互响应上产生本质差异，但缺乏可量化的数据级诊断手段来定位根因。
- **策展盲目性**：现有工作多依赖“收集更多数据”或基于直觉的物理相关特征筛选，未验证哪些数据轴真正驱动可玩性，数据预处理缺乏系统化的评估闭环。

## 核心贡献（创新点）
- **首次实证Virtual2Real Gap**：在格式、分布、地图完全对齐的CS:GO与CS2语料上训练相同架构模型，证明定量指标的提升并不等价于定性可玩性的改善，将性能退化明确归因于数据分布差异而非架构噪声。
- **开源Kuration SDK通用策展工具链**：提供一套可pip安装的游戏/序列数据清洗与诊断框架，内置`pixel_shift`、`action_state_consistency`、`collision`、`slam_reconstruct`等算子及覆盖率/稀有事件/聚类多样性等采样配方，填补了世界模型数据预处理工具的空白。
- **定位动作-状态一致性为核心诊断信号**：通过SDK量化发现CS:GO与CS2在单次按键引发的屏幕像素位移幅值上存在1.4–2.1倍差异，该差异是FVD/LPIPS/JEDi均无法捕捉的，且与模型控制响应灵敏度直接相关。
- **系统性验证策展策略的有效性边界**：对比四类策略后表明，基于直觉的覆盖率采样、稀有轨迹加权、碰撞感知筛选均未改善可玩性，唯有用根因诊断驱动的“动作-状态一致性”策略产生定性提升，强调“数据诊断先行于训练”的范式价值。

## 方法详解
- **对照实验设计**：以DIAMOND（两阶段扩散世界模型，denoiser在$30\times56$低分辨率运行，upsampler输出$150\times280$，20类离散键盘/鼠标动作）为基线。首先在CS:GO官方数据集复现训练（lr=1e-4, weight decay=1e-2, 600 epoch），验证管线忠实复现论文数值与已知定性缺陷。随后获取合作方CS2服务端捕获语料，严格匹配de_dust2地图、16 fps、相同动作编码与语料规模，训练无策展基线`baseline_v1`，控制变量仅保留数据源本身。
- **Kuration SDK核心算子**：
  - `pixel_shift`：对每次无中断按键/鼠标操作计算其后光流位移，并投影至控制轴，量化动作到视觉变化的映射强度。
  - `action_state_consistency`：聚合单键按压的响应曲线，按按键时长分箱输出每控制维度的动作-状态一致性评分，识别异常衰减/对称性偏离。
  - `collision`：基于预期无遮挡运动曲线检测穿墙/碰撞事件，支持对低频物理交互片段进行可控过采样。
  - `slam_reconstruct` / `slam_quality` / `slam_motion_diversity`：从无位置元数据的视频中恢复相机3D轨迹，评估时空空洞、不可能运动与路径多样性，将空间覆盖度转化为可策展维度。
- **四类策展策略**：
  1. **Coverage-based Sampling**：按瞄准速度、输入熵、移动速度分位数均匀覆盖采样（120 epoch从头训练，7,530 episodes）。
  2. **Rare-trajectory Up-weighting**：过采样移动速度尾部片段（均值43.9 vs 语料均值27.2），从`baseline_v1` epoch 300微调（60 epoch）。
  3. **Collision-aware Selection**：对碰撞标记片段加权（冲击力权重2×移动速度、4×瞄准速度），从epoch 300微调（55 epoch）。
  4. **Action-state-consistency Selection**：按单键pixel-shift幅值加权，将训练分布向CS:GO的高响应特性靠拢。
- **评估协议**：定量采用FVD、LPIPS、JEDi在独立CS2测试集（1,090 episodes）评估；定性采用作者交互式rollout检查判定可玩性（地图瞬移、几何裁剪、控制迟滞、物理违规），因缺乏公开基准而依赖人工研判。

## 实验与结果
- **复现基线**：本文DIAMOND在CS:GO测试集上epoch 300达FVD 1,571,046（较论文报告1,643,391降4.4%），epoch 420达LPIPS 0.5634，训练损失单调下降且指标收敛行为与原文一致，确认管线可靠性。
- **CS2未策展基线对比**：`baseline_v1`在CS2测试集上LPIPS提升至0.4785（较DIAMOND原生CS:GO测试提升20.9%），FVD在epoch 60达最优2,898,653后持续震荡，JEDi单调改善至2.39。尽管定量指标全面持平或反超，交互式rollout显示其几何裁剪、空间不连续与控制迟滞问题比CS:GO模型更严重。
- **策展策略效果**：覆盖率采样、稀有轨迹加权、碰撞感知策略均未带来定性可玩性提升；仅**动作-状态一致性**策略在定性评估中显示“improved”。表2中其余策略的定量指标因共享GPU限制尚未全部完成，但定性结论明确。
- **根因量化**：CS:GO单次按键峰值pixel-shift为CS2的**1.4–2.1倍**；CS2释放按键后减速保留76–78%幅值（符合物理预期），CS:GO释放后仍加速至112–126%且动量衰减耗时2–3倍；CS2的S键响应对称性（80% W键）优于CS:GO（26%）。作者将pixel-shift幅值列为最强假设，但尚未做控制变量消融。

## 相关工作脉络
- **世界模型与游戏生成**：Genie、GameNGen、DIAMOND聚焦数据规模与实时扩散生成，但均未在格式匹配的独立语料上系统对比数据对长期可玩性的影响；本文以严格对照实验填补了这一空白。
- **Sim2Real vs Virtual2Real**：Sim2Real聚焦动力学保真度与域随机化；本文定义的Virtual2Real强调数据分布缺陷（如良性玩家回避碰撞、双跳利用被当作正常转移）会直接继承至模型，与仿真器精度无关。
- **视频生成评估指标**：FVD/LPIPS依赖I3D/感知特征，JEDi引入V-JEPA预测未来隐状态；ACT-Bench、ARR、Atari 100K等针对动作语义或任务性能，但均非通用/域无关；本文证明这些指标在模型达到能力阈值后无法区分数据质量差异。
- **数据策展**：FineWeb、SemDeDup、DataComp-LM侧重文本/图文的语义去重与覆盖率筛选；现有方法不暴露物理交互、动作-状态映射、空间轨迹等关键特征，本文SDK将其扩展至游戏/序列数据场景。
- **长程一致性诊断**：Long-horizon drift metric通过正向-反向动作序列检查返回起点，但属于自指闭环，单步无法验证；本文从单动作-单帧位移切入，提供更细粒度的可策展信号。

## 局限性与未来方向
- 可玩性评估依赖作者主观交互式rollout，未采用盲评或独立标注者，存在期望偏差；当前领域缺乏标准化的可玩性基准。
- 实验仅涉及单一地图（de_dust2）、单一架构（DIAMOND）、单一游戏系列（Counter-Strike），域泛化性尚未验证。
- CS:GO（Source）与CS2（Source 2）引擎代差可能部分解释动作-状态一致性差异，尚未完全剥离引擎级属性与可策展数据选择的贡献。
- 部分策展策略的定量指标因算力限制未完成；动作-状态一致性策略的训练日程、统计置信区间及反向控制实验尚未公布。
- 未来将开发基于几何穿模与轨迹不连续性的物理合规性指标
