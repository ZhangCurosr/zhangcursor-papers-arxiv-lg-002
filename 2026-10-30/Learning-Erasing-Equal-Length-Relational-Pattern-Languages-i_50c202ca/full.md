## Abstract

Relational pattern languages generalize Angluin’s pattern languages by requiring the strings substituted for repeated occurrences of a variable to stand in a given relation, rather than to be identical. We study erasing pattern languages under the equal-length relation, where all occurrences of a variable must be replaced by strings of the same length. Over alphabets with at least three letters, this class is known to be learnable in the limit from positive data. We show that over a binary alphabet it is not, which resolves an open question from earlier work. Our proof reveals that non-learnability already holds for the restricted subclass of languages generated by patterns that have exactly three maximal substrings of variables. We then show that patterns with at most two maximal substrings of variables are learnable in the limit from positive data for every alphabet of size at least two. If the target pattern is known to have at most one maximal substring of variables, this can even be achieved by an iterative learner, which updates its hypothesis using only the current example and its previous hypothesis.

## 1 Introduction

Pattern languages, introduced by Angluin [1], have been an object of study in algorithmic learning theory for decades. A pattern is a finite string of terminal symbols and variables. Its language consists of all words obtained by replacing each variable with a string over the terminal alphabet, where all occurrences of the same variable are replaced by the same string. The literature distinguishes non-erasing pattern languages [1], in which variables cannot be replaced with the empty string, from erasing pattern languages, where empty substitutions are allowed [2]. Both variants have been studied extensively in Gold’s model of learning in the limit from positive data [3], where a learner is gradually presented with a sequence of all strings in an unknown target language L and must eventually settle on a correct description for L. The class of non-erasing pattern languages is learnable in this model [1], even by an iterative learner, which updates its hypothesis based only on the previous hypothesis and the current example [4]. By contrast, erasing pattern languages are not learnable in the limit from positive data, when the underlying alphabet has size 2, 3, or 4 [5, 6].

Relational pattern languages [7] are a generalization of the notion of pattern language, in which repeated variables need not be replaced by the same string, but instead by strings that are in a specified relation. Natural choices for this relation are, for example, equality, reversal, equal length, or abelian equivalence [8–10]; the equality relation here recovers the original notion of pattern language.

The equal-length relation is arguably the simplest of the relations considered in the literature [8, 9]. All occurrences of a variable must be replaced by strings of the same length, but the strings themselves can be chosen independently. As a result, the language generated by a pattern under this relation depends only on its terminal symbols and on the admissible lengths of the strings between them. Non-erasing equal length relational pattern languages are trivially learnable in the limit from positive data; moreover it is known that they can be distinguished by small sets of short strings when the alphabet size is at least three [8]. In the erasing case, it was observed that the positive learnability result for alphabets with at least three letters carries over from the non-erasing case [9]. However, binary alphabets posed a challenge. It was shown that many specific forms of patterns generate erasing equal-length relational languages that have so-called telltales even for binary alphabets [9]. A telltale of a language L with respect to a family L of languages is a finite subset of L that is not contained in any language $L ^ { \prime } \in { \mathcal { L } }$ with $L ^ { \prime } \subset L$ . The uniform enumerability of a system of telltales is a necessary and suficient condition for the learnability of a family $\mathcal { L }$ with uniformly decidable membership [11]. Despite numerous results on the existence of telltales for subclasses of erasing equal-length relational pattern languages, it was left open whether the full class $\varepsilon \mathcal { L } _ { l e n }$ of erasing equal-length relational pattern languages has telltales and thus whether it is learnable in the limit from positive data, given a binary alphabet.

We resolve this open question by presenting a pattern $p ^ { * }$ whose erasing equallength relational language $\varepsilon L _ { l e n } ( p ^ { * } )$ over a binary alphabet does not have a telltale with respect $\mathrm { t o } \ \varepsilon { \mathcal L } _ { l e n } .$ . Consequently, for alphabets of only two letters, the class $\varepsilon \mathcal { L } _ { l e n }$ is not learnable in the limit from positive data. We complement this result with positive learnability results for languages generated by patterns with a small number of maximal substrings of variables.

The first technical ingredient is to represent every language $\varepsilon L _ { l e n } ( p ) \in \varepsilon \mathcal { L } _ { \mathrm { l e n } }$ by the sequence of terminals in the underlying pattern p and by a finitely generated monoid of gap vectors.<sup>1</sup> Roughly speaking, a word belongs to $\varepsilon L _ { l e n } ( p )$ if it can be cut around the terminals of p so that the lengths of the pieces form a vector of the monoid. Suppose a learning algorithm is presented with positive examples only, $\mathrm { i . e . , }$ words in the language $\varepsilon L _ { l e n } ( p )$ , and has to identify p. Any single positive example shows a word, but not where it has to be cut. The question we study is how much of the monoid can nevertheless be recovered from the examples. Over an alphabet of three or more letters, every gap vector has a word that can be cut in only one way, so that positive examples reveal the monoid and we obtain learnability in the limit from positive examples. Our focus is the binary alphabet case. The main results of our paper are:

• Over a binary alphabet, a word can sometimes be cut diferently, when shifting two equal adjacent terminals by one position. This allows one variable of a pattern to be “imitated” by other variables, and learning from positive data becomes impossible (Section 3). We prove this by providing a pattern p such that $\varepsilon L _ { l e n } ( p )$ does not possess a telltale with respect to the class $\varepsilon \mathcal { L } _ { \mathrm { l e n } }$

• The pattern $p ,$ as well as all the patterns that witness the fact that p does not have a telltale, have exactly three variable blocks, i.e., they can be factored into substrings of only terminal symbols and substrings of only variable symbols, such that exactly three substrings of variable symbols are used. We therefore obtain the corollary that the patterns with exactly three variable blocks generate a class of erasing equallength relational pattern languages that is not learnable in the limit from positive data, when the alphabet size is 2.

• We contrast this by showing that the corresponding class is learnable in the limit from positive data, when the underlying patterns contain at most two variable blocks, regardless of the alphabet size (Section 4).

• If it is known that the underlying pattern p has at most one variable block, we obtain an even stronger positive learnability result, again regardless of the alphabet size. Learning in the limit from positive data can then even be achieved by an iterative learner, which updates its hypothesis based only on the previous hypothesis and the most recently seen word, ignoring all previously collected data (Section 5).

From now on, we consider exclusively the equal-length relation and focus on (erasing) equal-length relational pattern languages.

## 2.2 Learning in the Limit and Telltales

The focus of this paper is on learning equal-length relational pattern languages in Gold’s model of learning in the limit from positive data [3].

A text for L is an infinite sequence $t _ { 0 } , t _ { 1 } , \ldots$ . with $\{ t _ { i } \mid i \in \mathbb { N } \} = L$

Angluin’s characterization of learnability in the limit from positive data [11] concerns computable learners for indexed families $( L _ { i } ) _ { i \in \mathbb { N } } ;$ these are families for which a recursive procedure exists that, given $( i , w ) \in \mathbb { N } \times \Sigma ^ { * }$ , decides whether $w \in L _ { i }$ Clearly, the class of all equal-length relational pattern languages is an indexed family, since its membership problem is uniformly decidable. The central notion in Angluin’s characterization is that of a telltale: A telltale of a language L in a class $\mathcal { L }$ is a finite set $T \subseteq L$ such that no $L ^ { \prime } \in { \mathcal { L } }$ satisfies $T \subseteq L ^ { \prime } \subseteq L$

Angluin’s result states that an indexed family $( L _ { i } ) _ { i \in \mathbb { N } }$ of languages is learnable in the limit from positive data if and only if there is an efective procedure that, given an index $i ,$ enumerates a telltale for $L _ { i }$ with respect to $\{ L _ { i } \mid i \in \mathbb { N } \}$ . Note that Angluin’s characterization builds on the same idea as the locking sequences of Blum and Blum [12]. For our negative result we need only the necessity part of the characterization, and we do not require computable learners or the recursive enumerability of telltales, i.e., the following statement sufices for our purposes:

Theorem 5 ([11, 12]). If some (computable or non-computable) learner learns an indexed family L of languages in the limit from positive data, then every $L \in { \mathcal { L } }$ has a telltale in $\mathcal { L }$

In the context of this paper, we focus on learning equal-length relational pattern languages in the limit from positive data. Hypotheses output by the learner are (indices of) relational patterns in a fixed enumeration.

## 5 Iterative Learning of Patterns with at Most One Variable Block

An iterative learner computes each hypothesis from its previous hypothesis and the current example only, ignoring the examples seen in previous steps [13]. Lange and Wiehagen [4] showed that Angluin’s pattern languages can be learned iteratively in the limit from positive data. We now show that the equal-length pattern languages with at most one variable block can be learned iteratively as well, without any memory beyond the hypothesis, and that this holds even over a binary alphabet.

Definition 18 ([13]). A learner A is iterative if, for any input $\left( t _ { 0 } , t _ { 1 } , \ldots , t _ { n } \right)$ with $n > 0$ , the output $A ( t _ { 0 } , t _ { 1 } , \dots , t _ { n } )$ depends only on $t _ { n }$ and $A ( t _ { 0 } , t _ { 1 } , \dots , t _ { n - 1 } )$

Let $\varepsilon \mathcal { L } _ { \mathrm { l e n } } ^ { 1 }$ be the class of the languages $\varepsilon L _ { \mathrm { l e n } } ( p )$ of patterns of the form $p = \omega \vec { x } \overline { { \omega } }$ with $\omega , \overline { { \omega } } \in \Sigma ^ { * } , \vec { x } \in X ^ { * }$ , and $p \neq \varepsilon$ , i.e., patterns with at most one variable block. If the variables in p occur with multiplicities $g _ { 1 } , \ldots , g _ { k }$ and $M = \left. g _ { 1 } , \ldots , g _ { k } \right. \subseteq \mathbb { N }$ is the numerical monoid they generate, Observation 2 gives

$$
\varepsilon L _ { \mathrm { l e n } } ( p ) = \{ \omega u \overline { { \omega } } | u \in \Sigma ^ { * } , | u | \in M \} = : \omega \Sigma ^ { M } \overline { { \omega } } .\tag{3}
$$

Every finite set of positive integers occurs as the set of variable multiplicities of such a pattern. Note that, within this section, M is always a submonoid of N.

Given an unknown target pattern p of this form, a learner has to identify three items: the prefix $\omega .$ , the sufix ${ \overline { { \omega } } } ,$ and the monoid M. The prefix and the sufix are the longest common prefix and sufix of all examples, and these can be updated one example at a time. Once they are correct, the length of every example minus |ωω| is an element of $M ,$ and the learner collects these elements, keeping only the minimal generators. All of this information can be stored in the hypothesis itself, which can then be updated as needed, so that the learner is iterative.

## 6 Conclusions

This paper resolved an open question on the learnability of erasing equal-length relational pattern languages in the limit. In particular, it was shown that, over a binary alphabet, $\varepsilon \mathcal { L } _ { \mathrm { l e n } }$ is not learnable from positive data: the language of the relational pattern $p : = x _ { 1 } a a x _ { 1 } x _ { 2 } x _ { 2 } b x _ { 3 }$ is the union of a strictly increasing chain of languages of the class and thus has no telltale (Theorem 11). Since p as well as all the underlying patterns in this chain have exactly three variable blocks, our non-learnability result already holds for the subclass of languages generated by patterns with exactly three variable blocks.

This result was contrasted with two positive learnability results for structurally much simpler subclasses:

• The subclass of languages generated by patterns with at most two variable blocks is learnable in the limit from positive data, for every alphabet with at least two letters (Theorem 13).

• The subclass of languages generated by patterns with at most one variable block is learnable in the limit from positive data by an iterative learner, for every alphabet with at least two letters (Theorem 20).

Given that (i) for alphabets of size at least three, the whole class of erasing equallength relational pattern languages is learnable in the limit from positive data [9], and (ii) a wide variety of erasing equal-length relational pattern languages are known for which telltales exist even in case of binary alphabets [9], a natural next step is to characterize those patterns whose equal-length languages over binary alphabets have telltales.
