# 论文速读：HO-FL: HYBRID-ORDER FEDERATED LEARNING FOR HETEROGENEOUS EDGE DEVICES

## 一句话总结
针对边缘设备内存受限与纯零阶优化收敛缓慢的矛盾，提出HO-FL混合阶联邦学习框架，将模型底部参数用零阶优化、顶部参数用一阶优化分段训练，支持异构客户端自适应选择优化边界，并结合维度感知采样策略加速全局收敛。

## 研究问题与动机
- 边缘设备部署大语言模型时，标准FL的反向传播需缓存中间激活值，对于现代LLM可超出消费级硬件的物理内存限制。
- 纯零阶优化虽将客户端内存降至推理级别，但其梯度估计方差随可训练参数维度d成比例放大，导致收敛速度比一阶方法慢数个数量级。
- 现有混合阶方法（HOSL、HO-SFL、HERON-SFL）均依赖分割学习架构，要求客户端间传输激活、强制统一边界，无法适配真实边缘设备的异构内存约束。
- 核心问题：能否设计一个完全分布式的混合阶优化范式，既支持客户端自适应边界，又保留一阶训练的收敛优势？

## 核心贡献（创新点）
- **首个完全联邦混合阶框架**：HO-FL在每台客户端本地完成底部ZO和顶部FO训练，支持个性化边界配置与紧凑的种子编码上载，区别于依赖跨节点激活传输的分割学习方法。
- **统一非凸收敛理论**：建立包含优化项与采样偏差项的双重收敛界，揭示局部更新质量与全局数据表征之间的根本权衡，无缝还原纯FO、纯ZO及已有混合阶方法为特例。
- **维度感知客户端采样策略**：基于收敛界 formulate 采样优化问题，通过依赖舍入实现低方差的FO主导客户端优先选择，理论及实证均证明优于均匀采样。
- **AdamW兼容的种子重放机制**：设计确定性轨迹重建方案，使状态自适应优化器在联邦场景下仍能保持零维度上载通信。

## 方法详解
- **客户端自适应边界**：客户端i按内存预算将参数划分为w_i = [w_i^ZO, w_i^FO]，底部段w_i^ZO ∈ ℝ^{d_i^ZO}、顶部段w_i^FO ∈ ℝ^{d_i^FO}，满足d_i^ZO + d_i^FO = d；资源受限设备扩展ZO段，高性能设备保留更大FO段。
- **混合阶局部更新**：前端计算边界激活z_i = f_{i,ZO}(x; w_i^ZO)（不缓存中间激活），馈入顶部段得预测ŷ_i并计算损失ℓ(ŷ_i, y)；反向传播得到FO梯度g_i^FO = ∇_{w_i^FO}ℓ和边界激活梯度δ_i = ∇_{z_i}ℓ。
- **代理目标与ZO估计**：构造局部代理目标ℒ_i(v) = ⟨δ_i, f_{i,ZO}(x; v)⟩，该目标使链式法则下ZO梯度精确还原原始损失的一阶梯度；通过SPSA生成q个伪随机扰动u_{i,j}~N(0, I_{d_i^ZO})，估算ZO梯度ĝ_i^ZO = (1/q)∑_{j=1}^q s_{i,j}u_{i,j}，其中s_{i,j} = (ℒ_i(w_i^ZO + μu_{i,j}) - ℒ_i(w_i^ZO))/μ。
- **紧凑上载与服务器重构**：客户端仅上传方向标量序列{s_{i,t,j}^e}和FO参数差分Δ_{i,t}^FO = w_{i,t}^{FO,E} - w_{i,t}^{FO,0}；服务器利用已知种子重放恢复ZO更新Δ_{i,t}^ZO = -(η/q)∑_e∑_j s_{i,t,j}^e u_{i,t,j}^e，拼接为全参数更新后直接坐标级平均。
- **AdamW种子重放**：每轮选定客户端后重置优化器状态（m=0, v=0），服务器使用同步种子序列确定性重放每一步AdamW更新，精确重建底部段参数轨迹，无需传输历史动量缓冲。
- **维度感知采样**：设定偏好得分r_i = (1/K)·1{i∈R}（R为d_i^ZO/q最小的K个客户端），采样概率p_i = (1-β)/N + β·r_i，通过DepRound(Kp)抽取K个参与客户端；β=0为均匀采样，β→1偏向FO主导客户端。

## 实验与结果
- **数据集与模型**：SST-2、BoolQ、SciQ、AG News（含IID与Dir(α)非IID）、SQuAD 1.1；模型OPT-125M（12层）、Qwen2.5-1.5B（28层）、SmolLM3-3B（36层），LoRA适配器注入W_q和W_v（rank=8, α=16, FP32）。
- **基线**：FedAvg、FedProx、DeComFL（纯ZO SOTA）、HO-FL(β=0)（均匀混合阶）。
- **性能结果**：HO-FL(β=0.75)在多数任务上接近FedAvg，如OPT/SST-2达86.54%（FedAvg 87.04%），较DeComFL提升34.59个百分点（86.54% vs 51.95%）；AG News非IID下HO-FL比均匀HO-FL提升1.17–1.18个百分点。SQuAD 1.1上HO-FL将DeComFL的8.54% F1恢复至52.43%。
- **内存节省**：Qwen2.5-1.5B在序列长度1024时，FedAvg峰值内存40.26 GiB，HO-FL边界设在第24层降至9.08 GiB，减少77.4%，适配12 GiB消费级设备。
- **系统内存**：HO-FL(β=0.75)每轮平均集群内存163.78 GiB，显著低于FedAvg的241.57 GiB；较高β会适度提升集群利用率但加速收敛。
- **最强结果**：SmolLM3-3B/SST-2达94.04%（接近FedAvg 94.04%）；OPT-125M/SQuAD F1达52.43%（较DeComFL提升43.89个百分点）。

## 相关工作脉络
- **DeComFL / HiSo（纯ZO FL）**：通过种子同步或Hessian引导降低通信，但仍受全参维度方差惩罚；HO-FL将ZO严格限制于内存关键的底部段，规避全参方差。
- **HOSL / HO-SFL / HERON-SFL（混合阶分割学习）**：均需逐轮激活传输并强制统一边界；HO-FL改为全本地执行、支持异构边界、无激活上载。
- **FedProx（异构数据FL）**：通过近端正则缓解客户端漂移，处理数据异构；HO-FL额外处理硬件异构（内存容量差异）并通过维度感知采样缓解。
- **SCAFFOLD / FedAvg（经典FL）**：理论框架中的非凸收敛假设与有界梯度异质性条件与之对齐；HO-FL在统一界中恢复FedAvg的O(1/√T)率（当d^ZO=0）和纯ZO-FL的O(√((1+d/q)/T))率（当d^ZO=d）。
- **LoRA微调（LLM适配）**：论文冻结骨干、仅训练LoRA适配器，使ZO扰动作用于低秩矩阵，降低有效参数量并提升数值稳定性。

## 局限性与未来方向
- 客户端边界b_i在训练前静态预设，未支持运行时根据波动资源动态调整。
- 采样偏好β需离线设置或通过短跑验证选择，缺乏在线自适应调度机制。
- 理论分析基于非凸光滑假设，对更深层次的非平稳训练动态刻画有限。
- 实验仅覆盖语言理解与生成任务，视觉或多模态场景未验证。
- 服务端种子重放AdamW虽消除了历史状态传输，但每轮重置动量可能影响长程优化轨迹。

## 研究启发与可借鉴点
- **零阶优化的边界限定策略**：将ZO严格限制于激活内存瓶颈的底部段，利用代理目标函数消除端到端前向传播需求，是可复用的低方差ZO设计范式。
- **维度感知采样的理论-算法映射**：从收敛界中提取优化项与偏差项的显式分解，将采样偏好转化为可计算的静态得分，再经依赖舍入实现，为异构FL的客户端调度提供了系统化的设计思路。
- **种子重放替代状态传输**：通过确定性种子序列在服务器端重建客户端局部轨迹，使自适应优化器的联邦化无需传输高维动量，该技巧可迁移至其他零阶/低通信场景。
- **异构边界的统一聚合**：不同客户端采用不同边界，但更新均映射至共享参数空间后直接坐标平均，实现了异构性与标准聚合算子的兼容。
- **可结合本团队方向**：若在边缘视觉或多模态场景开展研究，该边界自适应+维度感知采样框架可直接迁移至对应模态的LoRA/适配器微调联邦场景。

## 关键术语表
- **混合阶优化（Hybrid-Order Optimization）**：将网络分段，底部用无反向传播的零阶扰动更新、顶部用标准一阶反向传播更新，平衡内存与梯度精度。
- **零阶优化（ZO）**：仅通过随机扰动的前向评估估计梯度，不构建反向计算图，将内存消耗降至推理级别。
- **一阶优化（FO）**：标准反向传播优化，需缓存中间激活值，精度高但内存开销大。
- **代理目标函数（Surrogate Objective）**：ℒ_i(v) = ⟨δ_i, f_{i,ZO}(x; v)⟩，利用边界激活梯度构建线性内积目标，使ZO扰动仅在底部段求值。
- **同时扰动随机近似（SPSA）**：用少量随机方向同时估计多维梯度，方差随方向数q而非维度d缩放。
- **依赖舍入（Dependent Rounding）**：保持边际概率期望不变的整数抽样技术，确保恰好K个客户端参与且负相关降低方差。
- **维度感知采样（Dimension-Aware Sampling）**：按客户端ZO参数维度/方向数比 prioritizing FO-dominant客户端的采样策略。
- **种子重放（Seed Replay）**：服务器用预分发伪随机种子重新生成扰动方向，无需客户端传输高维向量即可重构ZO更新。
