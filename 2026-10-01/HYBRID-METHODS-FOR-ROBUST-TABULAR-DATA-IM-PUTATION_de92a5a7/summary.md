# 论文速读：HYBRID-METHODS-FOR-ROBUST-TABULAR-DATA-IM-PUTATION

## 一句话总结
本文提出 NuclearForest 与 SoftForest 两种混合插补方法，将低秩矩阵补全（带列均值预热与自适应步长改进的 SVT 或 SoftImpute）作为结构化热启动，仅用单次非迭代随机森林进行残差修正，在将计算成本较 MissForest 降低 5.8–9.5 倍的同时，在代谢组学与房价数据集上实现了更高且更稳健的插补精度。

## 研究问题与动机
1. **计算效率瓶颈**：现有最优插补方法（如 MissForest）需反复迭代拟合随机森林直至收敛，计算开销极高，难以满足需要大量重复实验的真实科研与工程场景。
2. **数据内在结构未被充分利用**：真实世界表格数据（尤其是 omics 数据）近似具有低秩结构，全局协方差模式可由低秩矩阵补全高效捕获；而随机森林擅长捕捉局部非线性依赖，两者存在天然互补性。
3. **高缺失率下的稳定性不足**：传统迭代方法或纯线性/深度方法在缺失率较高（80%–90%）时插补精度与下游预测性能易出现显著退化。
4. **优化求解器选型缺乏系统对比**：核范数最小化（SVT）中全 SVD 与部分 SVD 在实际插补质量与运行速度上的对比缺乏实证，易导致实现次优。

## 核心贡献（创新点）
1. **提出“低秩热启动 + 单次 RF 精炼”的混合范式**：以低秩结构提供全局先验，将随机森林从全迭代优化降级为单次残差修正器，与 MissForest 等全迭代方法本质不同，避免过度拟合与冗余计算。
2. **改进 SVT 并给出理论收敛保证**：引入列均值预热替代零初始化，设计基于相对重建误差的自适应步长规则；Proposition 1 与 Corollary 1 严格证明步长有界性及 $O(T^{-1})$ 收敛速率，弥补了该变体的理论空白。
3. **实证全 SVD 优于部分 SVD**：在 SVT 求解器层面系统对比，证明 full SVD 在数值质量与运行速度上均显著优于 partial SVD，为核范数优化提供了明确的工程选型依据。
4. **构建多维度稳健评估体系**：除 NRMSE 外，联合 PFC、Gower 距离、PCA/PLS Procrustes 距离、Pearson log-p 相关度与下游 R² 退化等 7 项指标，全面刻画不同缺失机制与缺失率下的插补保真度。
