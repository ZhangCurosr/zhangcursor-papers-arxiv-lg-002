# 论文速读：WAVE-Reversing-the-Guidance-Hierarchy-for-Coarse-to-Fine-Gui

## 一句话总结
本文提出 WAVE，通过多级离散小波变换（ML-DWT）将 RGB 引导图显式分解为多尺度频带，并结合冻结的 DINOv3 语义令牌以逆序（最粗→最细）消费，从源头过滤误导性纹理/色彩干扰，实现由粗到细的结构优先重建，在极端放大倍率（32×）下显著降低深度超分辨率伪影与边界模糊。

## 研究问题与动机
1. **隐式细到粗偏置**：现有 CNN-based GDSR 管道沿袭卷积层的自然层次特性，低频局部线索（边缘、纹理）在浅层率先涌现，全局结构在深层才形成，导致误导性 RGB cues 被早期注入，后期需被动学习抑制，易产生伪深度跳变与边界 bleeding。
2. **语义方法未扭转消费顺序**：SPFNet、NAIMA 等虽然蒸馏了 DINO 等基础模型的层级 token，但仍保留细到粗的信息流序（全局 token 仅在后期引入），未能从结构上纠正引导信号的摄入时序。
3. **频率先验未作用于引导源**：既往频域方法多作用于深度特征侧或梯度频率图，而非对 RGB 引导信号本身进行源头分解与显式分层控制。
4. **跨模态融合易坍缩**：传统拼接+卷积融合或单流可逆块无法从数学结构上保证双模态信息的双向可恢复性，容易退化为单模态主导。

## 核心贡献（创新点）
1. **首次将 ML-DWT 作为显式引导控制机制**：将 RGB 引导分解为多层近似与细节子带，并以逆序消费配合层级 DINOv3 token，强制实现粗到细重建。与已有工作的本质区别在于：从源头控制 RGB 内容准入尺度，而非依赖端到端网络隐式纠正。
2. **提出 HUMMA 模块统一三类交互建模**：在同一框架内显式建模小波子带内部交互、子带-语义跨模态交互、以及频率特异性引导与深度流的交互。与已有工作的本质区别在于：用可解释的频域隔离+语义门控替代黑盒抑制策略。
3. **复用 IRN 可逆耦合实现双射跨模态融合**：将原本用于单流空间-频率桥接的可逆块改造为双向保留的融合器。与已有工作的本质区别在于：从雅可比行列式非零的数学结构上杜绝单模态信息坍缩。
4. **提出 SToRA 轻量语义适配**：基于 DiReFT 思想对冻结 DINOv3 输出 token 施加低秩残差更新，无需微调主干或引入额外语义损失即可获得任务特定语义。与已有工作的本质区别在于：在保持预训练语义完整性的同时实现极低参数开销的下游适配。

## 方法详解
