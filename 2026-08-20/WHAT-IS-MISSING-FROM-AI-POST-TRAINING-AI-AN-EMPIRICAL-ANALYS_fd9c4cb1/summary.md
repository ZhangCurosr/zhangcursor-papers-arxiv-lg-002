# 论文速读：WHAT-IS-MISSING-FROM-AI-POST-TRAINING-AI-AN-EMPIRICAL-ANALYS

## 一句话总结
本文通过对 PostTrainBench 大规模轨迹的实证分析，区分了 LLM Agent 的“执行级”与“策略级”能力，发现前沿 Agent 虽能高效执行后训练流水线，但训练策略在首次运行前即被锁定且几乎不随实验证据动态调整；进一步递进干预表明，补充经验、人工指导或增加推理算力均无法打破该锁定，真正缺失的是执行过程中自发重评估并切换高层策略的机制。

## 研究问题与动机
- 核心问题：当前 AI-for-AI 讨论常将“按既定策略迭代调试”与“根据实验证据修订高层训练计划”混为一谈，后者在现实中是否存在且如何提升？
- 现有不足 1：轨迹级分析显示 Agent 在启动前迅速锚定默认策略，后续预算几乎全用于局内局部搜索，跨 3,557 对相邻实验仅 2.1% 发生策略变更。
- 现有不足 2：即使提供持久化实验日志、技能库与诊断式评测 Agent，执行性能显著提升，但 Agent 对明确的策略级建议（如从 SFT 切换至 RL）采纳率始终为 0。
- 现有不足 3：人工在规划阶段介入可成功重定向初始策略，但一旦训练开始 Agent 仍会回落到局部调整循环，表明策略可塑性仅存在于极短的预执行窗口。

## 核心贡献（创新点）
- 提出“执行级 / 策略级”双层能力分析框架，系统解构 LLM 后训练 Agent 的行为边界，澄清了 AI R&D 中执行与决策被混淆的概念误区。
- 在 PostTrainBench 上进行大规模轨迹级实证（1,338 条轨迹、7 基准、20 种配置），首次量化揭示 Agent 训练策略的“启动期锁定”现象及其跨任务/跨模型的强稳定性。
- 设计并实施三类递进干预（经验脚手架、人工策略指导、推理算力扩展），明确排除“缺失经验、指导、推理算力”三种直觉假设，将瓶颈精确定位为“自发策略重评估机制”。
- 指出当前自动 AI R&D 闭环仅在“执行层”闭合、在“策略层”开放，为后续 Agent 训练信号设计与交互协议改进提供明确的理论锚点。

## 方法详解
- **双层能力框架定义**：
  - 执行级能力（Execution-Level）：保持训练策略 $s$ 固定，进行数据构建/清洗、超参调优、奖励塑形、Checkpoint 选择与代码调试。
  - 策略级能力（Strategy-Level）：动态修订策略三元组 $s=(k, d, g)$，包括切换训练范式 $k$、变更数据源类型 $d$ 或调整阶段结构 $g$。
- **轨迹提取与标注规则**：仅当执行命令触发模型参数更新时计为有效实验；相邻实验间若 $k$、$d$、$g$ 任一维度变化则记为策略变更，否则记为执行变更。标注由 LLM 初审、作者人工复核，策略标签涵盖 Full SFT、PEFT、RL/GRPO、Preference Optimization、Distillation。
- **经验驱动脚手架（Experience-Driven Framework）**：
  - 实验日志（Experiment Journal）：追加式结构化记录，保存计划、观察、教训与评估结果，缓解长程上下文遗忘。
  - 技能库（Skill Library）：从 verl、TRL、OpenRLHF、NeMo-RL、slime 等开源文档与 Issue 中蒸馏的轻量可复用知识（约 60 页 wiki、~1.2K 词/文件）。
  - 评测 Agent（Evaluator Agent）：独立于主 Agent，分析 checkpoint 分数与模型输出，返回包含执行级建议与策略级建议的紧凑诊断。
- **递进干预协议**：控制变量下以 Qwen3-1.7B-Base 为起点，在 GSM8K / HumanEval / AIME 2025 各跑 3 次独立 10 小时实验（4× NVIDIA A800），依次叠加经验脚手架、规划期人工审核、额外推理 Token，严格隔离各变量对执行与策略的影响。

## 实验与结果
- **数据集与基线**：PostTrainBench 公开轨迹（1,338 条，7 基准，4 基础模型 1.7B–4B，20 种配置）；受控实验基线为 Claude Code (Opus 4.6 / GLM-5.2) 与 Codex CLI (GPT-5.2)，预算 10 小时 / 4× A800。
- **轨迹分析结果**：Claude Code 默认 Full SFT 占比 80.7%，Codex CLI 默认 PEFT 占比 89.6%；跨任务策略高度同质化，差异主要源于 Agent 先验而非任务特性。
- **经验干预结果**：全面提效，GSM8K 从 64.70% 升至 77.30%（+12.6），HumanEval 从 22.00% 升至 62.80%（+40.8），AIME 2025 仅 5.56%；消融显示实验日志与技能库贡献最大，但策略级建议采纳率仍为 0，Agent 持续在局内 SFT 变体上迭代。
- **人工指导结果**：成功将 AIME 初始策略从 SFT 重定向为 GRPO，初期表现优于经验框架，但训练启动后迅速回落到熵系数/学习率等局内微调，未再产生显著增益。
- **算力扩展结果**：经验框架消耗基线 2–8× 推理 Token；在 GSM8K / HumanEval 带来高收益，但在 AIME 2025 消耗 7.9× Token 仅多解 1 题（处于评估方差内），证明算力只能放大局内搜索密度，无法突破策略天花板。
- **核心结论数字**：策略仅在首次训练前极短窗口内可塑；窗口关闭后，经验、指导与算力三大机制 uniformly fail。

## 相关工作脉络
- **AI for Research / Automated AI R&D**：本文聚焦 LLM 后训练场景的策略决策剖切，区别于 AI Scientist（Lu et al., 2024/2026）、AutoResearchAI（Tie et al., 2026）等泛科学工作流系统，强调在“训练范式选择”这一具体决策点上的行为解剖。
- **ML Agent 基准与评测**：直接建立在 Rank et al. (2026) 的 PostTrainBench 之上，区别于 MLE-Bench（Chan et al., 2025, 侧重工程管线）与 Agent^2RL-Bench（Chen et al., 2026d, 侧重 Agentic RL），本文提供首个跨 20 种配置的大规模轨迹归因分析。
- **经验驱动 Agent 与技能学习**：与 Expel（Zhao et al., 2024）、Reflexion（Shinn et al., 2023）、NanoResearch（Xu et al., 2026a）等同属“记忆/技能增强”范式，但本文反向验证：仅靠经验积累不足以触发策略跃迁。
- **RLHF/后训练自动化框架**：对比 Nemo RL、OpenRLHF、verl 等框架的自动化探索，本文指出这些系统默认预设了训练策略，而 Agent 层面缺乏动态切换机制。
- **Test-time Scaling / 推理增强**：与 Llms Improving Llms（Zheng et al., 2026）等测试时计算扩展工作形成对照，证明单纯堆叠推理 Token 在策略锁定场景下存在明确收益天花板。

## 局限性与未来方向
- 轨迹分析为观测性数据（Observational），无法完全剥离基础模型、Prompt、界面与 Scaffold 的混杂效应，因果推断受限。
- 策略切换本身存在真实计算成本，审计显示频繁切换并非总是有益，未来需研究“切换阈值”与“证据累积判据”的量化标准。
- 人工指导仅在训练前介入一次，未测试持续性 human-in-the-loop 干预，长期引导的有效性未知。
- 未来方向：设计显式的“策略重评估决策点”交互协议；开发奖励重启/放弃既定策略的训练信号；探索无需外部指令即可由负反馈自动触发范式切换的机制。

## 研究启发与可借鉴点
- **分层能力评测范式**：将 Agent 任务拆解为“执行熟练度”与“策略灵活性”两个正交维度，可迁移至代码生成、自动化实验、科研 Agent 等复杂长程决策场景的归因分析。
- **经验脚手架的“双刃剑”设计**：实验日志与技能库能显著提升执行效率
