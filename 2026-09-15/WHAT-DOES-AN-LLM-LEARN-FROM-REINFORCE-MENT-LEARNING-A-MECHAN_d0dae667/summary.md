# 论文速读：WHAT-DOES-AN-LLM-LEARN-FROM-REINFORCE-MENT-LEARNING-A-MECHAN

## 一句话总结
本文提出 Fixed-SAE Track 框架，通过机制可解释性视角追踪 RL 训练对 LLM 内部表示的影响，发现 RL 主要增强的是格式/推理脚手架特征（算术运算符、换行符、LaTeX 分隔符等）而非重塑问题内容；将这些特征注入 base model 可恢复约 80% 的 RL 性能增益，表明 RL 主要"引出"模型已有的潜在能力而非创造全新能力。

## 研究问题与动机
1. **核心问题**：RL 广泛用于 LLM 后训练（RLHF/RLVR）以提升数学推理等能力，但 RL 究竟如何重塑模型内部表示尚不清楚，现有解释几乎全部停留在行为层面（评估输出），缺乏表示层面的机制证据。
2. **现有方法不足**：独立训练的 SAE 对每个 checkpoint 赋予任意特征索引，导致跨 checkpoint 不可比；SAE Track（顺序微调 SAE）依赖精细的逐 checkpoint 训练，且因字典继承而不适合检测新涌现的特征。
3. **关键科学问题**：RL 是否能创造真正新颖的特征？还是仅增强/抑制已有特征的激活？这直接关系到"RL 扩展了推理边界还是仅提高了采样效率"的争议。
4. **动机**：需要一种能严格定义表示漂移、且能检测新特征的表示追踪方法，为 RL 对 LLM 内部表示的影响提供机制证据。

## 核心贡献（创新点）
1. **提出 Fixed-SAE Track 框架**——在 base model 和所有 RL checkpoints 的激活值池上训练单一共享 TopK SAE，保持特征方向在整个训练轨迹中固定，实现严格可比的表示漂移追踪；与 SAE Track 的本质区别：不继承上一 checkpoint 的字典，允许检测全新涌现特征。
2. **从表示层面揭示 RL 的机制效应**——发现 RL 引发的漂移是小幅、渐进、概念特异且集中于晚期层的，主要增强的是格式脚手架特征（段落边界、换行符、LaTeX 分隔符），而非重塑问题内容；与行为层面解释的本质区别：首次提供表示层面的因果证据。
3. **通过因果干预验证"引出"假说**——将放大特征方向注入 base model 可恢复约 80% 的 RL 性能增益，证明 RL 主要"引出"模型已有能力；与此前工作的本质区别：提供了超越相关性的因果充分性证据（相关性 ≠ 因果性）。
4. **构建合成基准验证 RL 创造新特征的能力**——设计已知特征的合成基准测试 RL 能否产生真正新颖的表示特征，为机制解释提供可控实验环境。

## 方法详解
**Representation Pooling**：从 base model（LLM₀）和所有 RL checkpoints（LLM₁…LLMₜ）提取残差流激活向量 **x** ∈ ℝᴰ（取 layer 27 的最终非 padding prompt token），拼接成统一数据集，按全局训练统计进行标准化：x̃ = (x − μ) / s，其中 μ 为 pooled mean，s 为 pooled RMS scale。

**Fixed-SAE Training**：在池化激活上训练单一 TopK SAE（k=32，扩展因子 8，m=12288 个特征），编码/解码公式为：z = TopK_k(W_enc x̃ + b_enc)，x̂ = W_dec z + b_dec。训练完成后冻结字典，对每个 checkpoint 的激活值重新编码，确保特征索引 f 在所有 checkpoint 中对应相同的方向 W_dec[:, f]。

**漂移量化**：特征 f 在 checkpoint t 的平均激活 ã_f(t) = (1/N) Σ_i z_{i,f}^(t)，漂移定义为 Δ_f = ã_f(T) − ã_f(0)。Δ_f > 0 表示 RL 放大，Δ_f < 0 表示抑制。同时监控 firing rate（特征活跃样本比例）。

**特征解释**：计算 token-level strong-fire rate ρ_f = (1/T_gen) Σ_tok 1[z_f > 0.5]，判断特征是格式脚手架还是问题内容；计算 ã_f(t) 与训练奖励的 Spearman 相关系数，筛选单调相关特征。

**因果干预**：充分性测试（Steering）——在 base model layer 27 残差流中均匀叠加放大特征集 S 的方向：x' = x + α Σ_{f∈S} W_dec[:, f]，扫描 α 评估严格准确率、宽松准确率和 tag-rate；必要性测试（Ablation）——在 RL-final model 中，在特征自然触发的 token 处减去其重建贡献 Σ_{f∈S} z_f W_dec[:, f]·s。

## 实验与结果
**实验设置**：主模型 Qwen2.5-1.5B-Instruct（D=1536，28层），额外验证 3B/7B 规模；RL 算法覆盖 GRPO、REINFORCE、RLOO、strong-GRPO；数据集 GSM8K 和 MATH-hard；13 个 checkpoints（steps 0–600，每 50 步保存）。

**主要结果**：
- **漂移特征**：约 10 个特征发生显著变化，最大漂移随层深增加（layer 6: 0.013 → layer 27: 0.060）。
- **特征语义**：放大特征主要为算术运算符（f4974）、LaTeX 数学块边缘（f9724）、段落/步骤边界（f4762、f11240）；抑制特征多与问题实体/单位（f924）、中间连接文本（f7384）相关。
- **格式 vs 推理分解**：短期 RL 大幅提升严格准确率和 tag-rate，但宽松准确率变化很小；GSM8K 训练的 GRPO 在 MATH-500 上严格准确率提升 +0.13，宽松仅 +0.03，表明可迁移成分主要是格式。
- **Steering 因果验证**：α=10 时严格准确率从 0.050 升至 0.192，tag-rate 从 0.092 升至 0.600，接近 RL-final（0.175/0.533），可恢复约 80% 增益；随机方向无此峰值。
- **持续训练效果**：从 plateau 继续 2000 步（恒定 LR），宽松准确率从 0.300 升至 0.408，说明持续训练可带来真实推理增益。
- **Base model 可解性**：29 道 RL 修正的 GSM8K 题目，base 模型在 k=64 次采样中 100% 可解（pass@64=1.00），支持"引出"假说。
- **推理特征 R 的因果必要性**：消融 R 使 GSM8K 准确率从 0.358 降至 0.242（−0.116），MATH-500 从 0.208 降至 0.117（−0.091）；但直接注入 R 到 base model 仅恢复约 +0.06 而非 RL 的 +0.34，说明推理特征是动态维持的计算态而非静态方向。
- **跨算法一致性**：四种 RL 算法间漂移向量平均 off-diagonal Spearman 相关为 0.42，抑制比放大更可复现。

**最强结果**：α=10 steering 在 GSM8K 上严格准确率 0.192，tag-rate 0.600；持续训练 2000 步后严格准确率 0.408，tag-rate 0.983。

## 相关工作脉络
1. **SAE 静态分析（Bricken et al., 2023; Cunningham et al., 2023）**——SAE 已用于解析 LLM 静态表示中的单语义特征，但本文将其扩展至训练轨迹的动态追踪，解决跨 checkpoint 可比性问题。
2. **SAE Track（Xu et al., 2025）**——顺序微调 SAE 追踪特征动态，但因字典继承设计不适合检测新涌现特征；本文 Fixed-SAE Track 通过单次共享字典训练实现跨训练步严格可比。
3. **RL 行为解释（Yue et al., 2025; Shao et al., 2026; Liu et al., 2025）**——部分工作认为 RL 仅 sharpen 采样分布而不扩展推理边界，另一部分认为 RL 可扩展推理边界；本文从表示层面提供机制证据，调和两种观点：短期 RL 主要引出已有能力，持续训练可带来小幅真实推理增益。
4. **High-entropy token 分析（Wang et al., 2025）**——发现 RL 效应集中在少数高熵分支 token；本文从表示角度确认效应集中在晚期层格式特征，二者互补。
5. **Cross-coders（Jiralerspong & Bricken, 2026）**——跨架构模型 diffing 方法，可用于跨模型比较；本文聚焦单模型跨训练步骤，方法上更简洁。
6. **RLVR 机制分析（Wen et al., 2025; DeepSeek-R1, Guo et al., 2025）**——讨论 RLVR 隐式激励正确推理；本文通过因果干预验证推理特征的必要性，同时揭示其不可注入性。

## 局限性与未来方向
1. **模型规模有限**：因果消融仅在 1.5B 模型上干净验证，3B/7B 结果不一致，尚不清楚结论在更大模型上是否成立。
2. **训练时长限制**：主实验仅 600 步 RL，推理能力增益需持续训练 2000 步才显现，未能完整刻画长程 RL 的表示演化。
3. **推理特征的不可注入性**：推理特征集 R 因果必要但无法通过静态方向注入恢复，表明推理涉及动态计算过程，机制尚不完全清楚。
4. **特征解释依赖人工**：SAE 特征语义依赖人工标注，可扩展性存疑。
5. **合成基准的设计挑战**：已知特征的合成测试可验证新特征涌现，但人工设计的特征可能无法完全模拟真实训练动态。

## 研究启发与可借鉴点
1. **Fixed-SAE Track 方法可复用于其他训练阶段**：该框架不仅适用于 RL，还可追踪 SFT、pretraining、domain adaptation 等训练过程中的表示漂移，为训练动力学提供统一分析工具。
2. **严格定义表示漂移的量化方法**：Δ_f = ã_f(T) − ã_f(0) 的漂移定义简洁且可解释，结合 firing rate 和 Spearman 相关性可系统刻画特征演化，值得借鉴到表征学习、微调等领域的机制分析中。
3. **Steering + Ablation 双向因果验证范式**：同时检验特征的充分性（注入 base model）和必要性（消融 RL model），为机制解释提供强因果证据，可推广到干预分析的其他场景。
4. **"引出"假说的实验范式**：pass@k 可解性测试（验证 RL 修正题目在 base model 下是否可解）和 steering 剂量响应曲线，为"模型已具备但未展示的能力"提供实证方法。
5. **格式脚手架 vs 问题内容的分离评估**：two-grader protocol（严格 vs 宽松准确率）有效区分格式改进和真实推理改进，可借鉴到 RL 实验评估设计中。

## 关键术语表
**Fixed-SAE Track**：一种表示追踪框架，通过在 base model 和所有 RL checkpoints 的池化激活上训练单一共享 SAE，保持特征方向固定，实现跨训练步骤的严格可比表示漂移分析。

**Sparse Autoencoder (SAE)**：稀疏字典学习方法，将 LLM 的多语义激活分解为稀疏的、单语义的、人类可解释的特征字典，是当前机制可解释性的核心技术。

**TopK SAE**：SAE 的一种变体，通过保留 pre-activation 中最大的 k 个值来实现稀疏编码，本文使用 k=32。

**Representation Drift (Δ_f)**：特征 f 在训练过程中平均激活的变化量，Δ_f = ã_f(T) − ã_f(0)，正值表示 RL 放大该特征，负值表示抑制。

**Strict vs Lenient Accuracy**：两种评估指标——严格准确率要求答案正确且格式符合规范（匹配 RL 奖励），宽松准确率忽略格式仅测量答案正确性。

**Feature Steering**：将 SAE 解码方向的线性组合叠加到模型残差流中，用于因果干预测试特征是否驱动模型行为。

**Feature Ablation**：在特征自然触发的 token 处减去其重建贡献，用于测试特征的因果必要性。

**Elicitation Hypothesis**：本文提出的核心假说——RL 主要"引出"模型已有的潜在能力（通过增强格式脚手架），而非创造全新能力。
