# 论文速读：When-Single-Dataset-Conclusions-Fail-A-45-Task-Study-of-Thre

## 一句话总结
本文在严格无泄漏的嵌套交叉验证协议下，证明基于 Kaggle 信用卡欺诈数据集得出的“已校准集成模型无需类别不平衡干预”结论会在 45 个二分类任务上发生方向性逆转，并刻画了阈值调优收益与倾斜率的倒 U 型关系，同时证伪了“校准误差可预测阈值调优收益”的直觉假设。

## 研究问题与动机
- 不平衡分类文献广泛以单一 benchmark（尤以信用卡欺诈集为代表）对比 SMOTE、类别加权与阈值移动等策略，并将该数据集上的策略排名直接外推为普适结论。
- 即便采用无泄漏协议，单数据集结论仍存在严重的**外部效度**风险：特定分布（如极端倾斜 1:577）上的“干净”发现可能在其他任务上完全反转。
- 实践中缺乏低成本诊断工具来判断“何时值得调优阈值/是否需用重采样”，研究者常依赖校准误差等指标作启发式猜测，但缺乏实证检验。

## 核心贡献（创新点）
1. **单数据集结论的可证伪性实证**：在清洗协议的信用卡欺诈集上得出 RF 默认阈值即最优的结论，并证明该结论在 45 任务集上被逆转（RF 实际是阈值调优获益最大的模型族）。  
   与已有工作（如 GHOST、Balancing the Scales）仅论证“阈值调优普遍有效”不同，本文聚焦结论的跨数据集迁移性，并给出直接的反转证据。
2. **阈值调优收益的非单调性刻画**：发现调优收益与类别倾斜率呈倒 U 型，峰值位于 1:15–1:40（ΔF1 = +0.120），极端倾斜（>1:100）时收益回落至 +0.045。  
   区别于传统“倾斜越严重调优收益越高”的单调直觉，本文解释了为何 1:577 的欺诈集属于不具代表性的反常研究载体。
3. **否定校准误差的预测价值**：系统检验验证集 Expected Calibration Error 与 Brier score 与 ΔF1 的相关性，证明二者均无法作为是否调优的 cheap diagnostic（r = -0.087 / +0.137，解释方差 <2%）。  
   与多数工作假设“校准偏差大则阈值移动收益大”不同，本文提供明确的 negative result，避免 practitioner 走弯路。
4. **开源可复用的多任务评测基础设施**：发布完整嵌套 CV 协议、45 任务 harness 及 2,025 条逐轮指标文件，支持下游直接扩展。  
   超越理论层面的方法论讨论，将外部效度检验工程化为可一键运行的基准流程。

## 方法详解
- **嵌套交叉验证协议**：外层按 k 折划分数据集（欺诈集 k=5，45 任务集 k=3）；内层将外层训练集切为训练/验证集（80/20 或 75/25）。阈值仅在验证集上搜索，测试集全程不参与拟合或选择。
- **数据预处理隔离**：`StandardScaler` 仅在内层训练集上拟合；SMOTE 仅应用于缩放后的内层训练集，验证集与测试集绝不重采样。
- **策略对比**：`plain`（阈值固定 0.5）、`tuned_threshold`（网格 {0.01,…,0.99} 上以验证集 F1 最大化选阈值）、`class_balanced_tuned`（逆频率类别权重 + 阈值调优）、`smote_tuned`（SMOTE + 阈值调优）。MLP 因 sklearn 不支持 class_weight 而省略第三策略。
- **核心统计量**：配对 F1 差值 $\Delta F1 = F1(t^*) - F1(0.5)$，在同一测试折、同一 fitted model 上计算，消除折间与模型间方差。
- **模型族**：Logistic Regression（L-BFGS, max_iter 500–1000）、Random Forest（100 trees, max_depth=16）、Histogram Gradient Boosting（max_iter 100–200, lr=0.1）、MLP（64-32 ReLU, Adam, early stopping）；欺诈集额外含 Autoencoder 异常检测。
- **数据集构成**：Study A 为 Kaggle 信用卡欺诈（284,807 样本，正负比 1:577）；Study B 含 14 个真实任务（digits one-vs-rest 等）、1 个重采样变体（breast cancer 1:21）与 30 个 `make_classification` 合成任务（sweep 倾斜率、类间距、维度）。

## 实验与结果
- **Study A（欺诈集）**：Plain RF 达 F1 = 0.861 ± 0.021；阈值调优 ΔF1 = -0.002；SMOTE 使 RF F1 下降 2.3 点，类别加权下降 1.7 点。表面上支持“无需干预”结论。
- **Study B（45 任务）**：阈值调优整体平均 ΔF1 = +0.059（138 wins / 31 losses, Wilcoxon p = 4.1e-20）；SMOTE + tuned 平均 ΔF1 = +0.076（138 wins / 39 losses, p = 2.7e-17）。
- **关键逆转**：RF 在欺诈集上调优无效，但在 45 任务集上 ΔF1 = +0.101 ± 0.134，居首且比第二名高 44 个点；LogReg、HGB、MLP 两阶段行为一致。SMOTE 收益高度依赖模型：MLP +0.170，LogReg 仅 +0.005。
- **倾斜率分段收益**：<1:5 时 ΔF1 ≈ -0.009；1:5–1:15 时 +0.045；1:15–1:40 峰值 +0.120；>1:100 回落至 +0.045。
- **校准诊断失效**：ECE 与调优收益 r = -0.087（p=0.044），Brier score r = +0.137（p=1.5e-3）但解释方差不足 2%，无法用于 go/no-go 决策。
- **最强结果**：45 任务集上 `smote_tuned` 整体增益最高（+0.076），但模型依赖性极强；阈值调优本身是最稳健的通用提升手段。

## 相关工作脉络
- **GHOST (Esposito et al., 2021)**：在 138 个药物发现数据集验证自动化阈值选择。**差异**：本文不重复“调优有用”的结论，而是证明单数据集结论可能反向，并将异常定位到 RF 在极端倾斜下的特例行为。
- **Balancing the Scales (2024)**：对比 SMOTE、类别加权与阈值校准，称阈值最稳定有效。**差异**：本文为多数据集对比提供外部效度检验视角，指出该结论在 1:577 极端倾斜上会失效。
- **Hayat & Magnier (2025) / Kabane (2024)**：聚焦数据泄漏、时间切分不当等内部效度问题。**差异**：本文采纳其清洗协议，进一步追问外部效度——即便内部效度干净，单数据集结论仍可反转。
