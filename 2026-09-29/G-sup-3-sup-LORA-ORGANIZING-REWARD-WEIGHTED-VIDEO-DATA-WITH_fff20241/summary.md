# 论文速读：G³-LoRA: Organizing Reward-Weighted Video Data with Gradient-Guided Grouped LoRA

## 一句话总结
本文提出 G³-LoRA，通过计算奖励加权视频数据在各 VBench2.0 维度上的残差梯度并聚类，将异构训练桶划分为优化兼容组，分别训练 LoRA 专家后稠密合并，并以在线策略蒸馏（OPD）回收合并损耗，有效缓解了多尺度奖励微调中的梯度干扰与能力平均化问题。

## 研究问题与动机
- **异构奖励微调的兼容性假设脆弱**：当前后训练管线默认将所有奖励加权数据混合训练单一适配器，但该假设在多技能、多域或多评估维度场景下并不成立。
- **共享 MSE 回归引发能力平均化**：不同 VBench2.0 维度可能偏好重叠噪声潜区中不同的去噪速度场方向，共享 LoRA 被迫拟合条件均值，导致部分维度性能被稀释。
- **语义或随机划分无法捕捉真实冲突**：基于指标名称分组或随机分区难以揭示类别间隐藏的梯度相消关系，甚至可能将强冲突维度强行合并。
- **缺乏可诊断的组织先验**：现有工作多聚焦奖励过滤或偏好目标设计，未系统回答“哪些奖励加权类别应共享更新方向”这一数据组织问题。

## 核心贡献（创新点）
- **将异构视频后训练形式化为数据组织问题**：主张按优化兼容性而非语义标签对类别分组，与已有工作仅依赖提示分布或人工规则划分的本质区别在于首次将梯度兼容性作为分桶先验。
- **建立奖励加权 Flow SFT 与速度场回归的理论联系**：从局部机制解释共享 LoRA 导致能力平均化的成因，与以往仅经验性使用 MSE 目标的本质区别在于为梯度冲突提供了可测量的动力学依据。
- **提出残差梯度兼容性度量与聚类分组流程**：通过投影去除全局混合方向后再计算类别余弦相似度，与直接用原始梯度或仅按语义/随机划分的本质区别在于能暴露被公共适应项掩盖的负冲突对。
- **构建“分组训练-稠密 Delta-SVD 合并-OPD 蒸馏”完整流水线**：兼顾多专家特异性与单 adapter 部署需求，与 CRAFT 的奖励过滤或 MaineCoon 的偏好优化合并的本质区别在于不修改训练目标，仅通过预训练梯度诊断与后训练知识蒸馏实现能力整合。

## 方法详解
- **奖励加权类别梯度探测**：对每个类别 i，在固定探针集（固定 diffusion timestep 与噪声种子）上计算奖励加权 LoRA 梯度 $g_i = \frac{1}{|B_i|}\sum_{x\in B_i}\nabla_\phi \mathcal{L}(\phi;x)$，其中 $\mathcal{L} = \frac{w}{\bar{w}}\|\hat{u}_\phi(z_t,p,t)-u\|_2^2$ 为 reward-weighted flow-matching MSE。
- **去除共享更新方向**：在混合探针集上计算全局梯度 $g_{\mathrm{global}}$，对每个类别残差 $r_i = g_i - \frac{\langle g_i, g_{\mathrm{global}}\rangle}{\|g_{\mathrm{global}}\|^2+\epsilon}g_{\mathrm{global}}$，消除分辨率、提示分布等公共适应分量，凸显类别特异性压力。
