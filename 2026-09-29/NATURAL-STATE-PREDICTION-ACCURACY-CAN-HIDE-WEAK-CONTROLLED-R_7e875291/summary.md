# 论文速读：NATURAL STATE-PREDICTION ACCURACY CAN HIDE WEAK CONTROLLED RESPONSIVENESS IN VLA READOUTS

## 一句话总结
本文指出，在自然轨迹上从 VLA 表征中解码物体状态的高准确率，并不能证明该读头对目标物理坐标的受控变化具有忠实响应；通过构建物理验证的交叉对照评估框架，分离了预测准确率、目标状态响应性与上下文稳定性，并证明将受控诊断指标加入事前预测器可显著改善机器人策略失败预测的校准度。

## 研究问题与动机
1. **解码能力 ≠ 响应忠实度**：现有工作多关注能否从 VLA 隐藏特征中恢复物体状态、动作或任务进度，但仅凭自然轨迹上的低预测误差，无法断定固定表征-读头对目标物理变量的受控扰动是否真正响应。
2. **上下文线索的混淆作用**：在自然观察中，物体状态、机器人构型、遮挡、任务进度等变量共同演化，上下文线索可辅助预测；这导致“可解码”不等于“可被策略真正利用”。
3. **单一评估维度的盲区**：缺乏系统方法区分自然预测准确率与受控响应性，难以诊断读头是捕获了目标物理因果，还是拟合了时间/构型等代理变量。
4. **下游行为关联未经验证**：这些诊断指标与策略实际 rollout 成败之间的定量关系尚未被检验，限制了其在失败预警、表征干预或训练正则化中的可信应用。

## 核心贡献（创新点）
1. **提出三维度正交评估框架**：将状态读出的特性严格拆分为预测准确率、目标状态响应性（endpoint gain）与上下文稳定性（prediction range），并用物理与视觉双重验证的交叉对照实验分离三者。*与已有探针工作仅报告自然轨迹解码精度的本质区别在于引入了固定上下文下的受控扰动一致性检验。*
2. **实证揭示“高准确率-弱响应”共存现象**：在 Meta-World 的 Drawer 与 Faucet 任务中，SmolVLA 与 OpenVLA 的自然 MAE 极低，但受控 MAE 高达 64~76 mm/rad，端点增益 G 仅为 0.15~0.18（Drawer）和 0.02~0.05（Faucet），且所有 12 个确认场景均满足 $G_s < 1$。*直接反驳了“低自然误差即代表有效物理表征”的隐含假设。*
3. **证明受控诊断指标对失败预测的增量价值**：将增益误差 $E_G$ 与上下文敏感度 $R$ 加入仅含初始状态误差与物理变量的失败预测基线 $M_0$，Brier score 与 log loss 均显著下降；同快照受控 MAE 亦提供额外信息，但 $E_G/R$ 相对于直接 MAE 的优势区间包含零点。*区别于事后轨迹级误差统计，本文证明事前受控快照的诊断摘要具有独立于初始误差的结果预测力。*
4. **系统化消融与跨架构外推**：对比 Ridge/RBF/MLP 读头、不同特征池化路径、训练数据混合比例及外观干预，并扩展至 π0 base、GR00T N1.6 及 SigLIP 2、VC-1、R3M、DINOv3 等非 VLA 编码器，证明该分离现象并非单一架构或读头容量所致，而是视觉-具身表征中普遍存在的上下文依赖问题。

## 方法详解
1. **评估核心定义**：冻结 VLA 特征提取器 $z = f(o)$，在训练集上拟合状态读出函数 $\hat{q} = h(z)$（Ridge / RBF / MLP）。同一冻结对 $(h \circ f)$ 同时应用于自然观察与交叉对照观察，读头输出不反馈给策略。
2. **交叉实验设计**：每个场景 $s$ 为独立 simulator 初始化。设定 $P$ 个机器人上下文（context anchors）与 $K$ 个目标坐标值。固定 $p$ 变化 $k$ 评估响应性；固定 $k$ 变化 $p$ 评估稳定性。所有观察需通过物理检查（坐标容差、速度 ≤$10^{-3}$、无意外接触、重复状态差异 ≤$10^{-8}$）与视觉检查（目标可见像素 ≥64、端点质心位移 ≥4 px、5 次渲染 bit-identical）验证。
3. **三大诊断指标**：
   - **预测准确率**：自然 MAE（按轨迹等权、轨迹内观察等权平均）与受控 MAE（按交叉网格等权平均）。
   - **目标状态响应性**：端点增益 $g_{sp} = (\hat{q}_{spK} - \hat{q}_{sp1}) / (q_{spK} - q_{sp1})$，场景均值 $G_s$；增益误差 $E_{G,s} = \frac{1}{P}\sum_p |g_{sp} - 1|$。$G=1$ 且 $E_G=0$ 表示完美响应；负增益表示反向响应。
   - **上下文敏感性/稳定性**：$R_s = \frac{1}{K}\sum_k (\max_p \hat{q}_{spk} - \min_p \hat{q}_{spk})$。$R$ 小说明同状态跨构型预测一致；常数预测器亦有 $R=G=0$，故需联合解读。
4. **训练与统计协议**：对比全自然训练、匹配样本量与真实坐标的受控训练、联合训练；采用 20,000 次配对 scene-bootstrap
