# 论文速读：FROM-PERCEPTION-TO-INTEGRATION-REVISITING-THE-INTERNAL-DYNAM

## 一句话总结
本文系统研究了视觉语言模型（VLM）在复合视觉推理中的内部动态，发现复合答案可在模型自然停止前提前从隐藏状态中解码；基于此设计了一个轻量级就绪度检测器，在 MMStar 和 RealWorldQA 上将平均推理 token 减少约 75-79%，同时平均准确率提升 3+ 个百分点。

## 研究问题与动机
- **核心差距**：VLM 能在简单单步视觉判断上达到 87-91% 的准确率，但在需要组合多个视觉判断的复合问题上准确率降至 58-67%（双选题猜测率为 50%）。
- **缺少时间维度分析**：现有工作只关注最终答案正确性，无法回答"模型在推理过程中何时首次获得正确答案"这一问题。
- **推理代价高昂**：在 MMStar 上平均推理 token 约 1,650，且 16.6% 的推理运行会触发生成上限而未给出答案。
- **机制黑盒**：缺乏对视觉信息如何在推理进程中逐步整合为答案的可解释分析。

## 核心贡献（创新点）
1. **系统揭示了组件判断与复合推理的性能鸿沟**：通过四个受控基本任务（Feature Binding / Numerosity / Spatial Relations / Amodal Completion）证明模型可在无推理时独立完成各子判断，但组合能力显著下降，揭示了"部分能力≠组合能力"的本质差距。
2. **提出了"答案就绪度"（Answer Readiness）的时间轨迹度量**：定义并量化了在推理过程中，复合答案何时从隐藏状态中可解码、何时可从截断推理轨迹中使用的早期临界点。
3. **设计了基于就绪度检测器的自适应早停方法**：用一个轻量线性检测器预测当前状态是否已具备正确回答能力，阈值由验证集确定，在不需要训练 VLM 本身的前提下实现高效推理。
4. **在真实基准上验证了加速与增效的双重收益**：在 MMStar 和 RealWorldQA 上将平均推理成本降低 79.1% / 74.5%，平均准确率分别提升 3.13 / 3.30 个百分点，部分归因于避免了因超长推理导致的答案缺失。

## 方法详解
- **受控数据集设计**：每个基本任务隔离一个决定答案的变量，保持场景其余部分恒定；Amodal Completion 和 Composite 使用配对数据集（counterfactual pairs），保证因果分析的有效性。
- **隐藏状态读取出法（Linear Readout）**：冻结 VLM，在每层对图像 token 的隐藏状态取均值 $v_i^{(\ell)} = \frac{1}{|\mathcal{T}_i|}\sum_{t \in \mathcal{T}_i} h_{i,t}^{(\ell)}$，经标准化后拟合岭回归读出面 $\boldsymbol{W}_\ell^*$，测试标签（颜色/方向/数量/形状）的可解码准确率。
- **状态干预（State Intervention / Patching）**：将配对图像中的接收者在其选定解码层的图像 token 状态替换为捐赠者状态，测量评分变化 $\Delta_{\text{patch}} = 100[\text{Pr}(m_{\text{target}}>m_{\text{base}}) - \text{Pr}(m_{\text{random}}>m_{\text{base}})]$，验证被解码信息是否实际影响最终答案。
- **答案就绪度轨迹追踪**：在五个检查点（PRE / EARLY / MIDDLE / LATE / ANSWER）评估隐藏状态可读性，以及从截断推理轨迹强制回答的准确率 $U(t)$。
- **就绪度检测器**：输入为当前隐藏状态 $h_{i,t}^{(\ell)}$、与上一检查点的变化量 $d_{i,t}^{(\ell)}$、以及已生成 token 比例 $t/B$，通过 sigmoid 输出就绪概率 $f_{\text{ready}}$，损失函数为类别平衡加权交叉熵；每隔 $\Delta=256$ 个 token 检查一次，达到阈值 $\eta$ 时关闭推理通道并输出答案。
- **阈值选择**：在验证集上以"平均推理长度最小化且准确率不低于全推理超过 0.5 个百分点"为目标选取 $\eta$。

## 实验与结果
- **数据集**：合成任务每类 1,000 张图像；真实基准为 MMStar（1,500 题）和 RealWorldQA（765 题），采用两折交叉验证。
- **模型**：Qwen3.5-4B、Qwen3.5-9B、Gemma-4-E4B、Gemma-4-12B。
- **基本任务无推理准确率**：Feature Binding 最高（98-100%），Spatial Relations 次之（89-100%），Numerosity（72-86%）和 Amodal Completion（73-81%）较低；平均值 87.2-91.4%。
- **复合任务推理增益**：推理使 pair-consistent accuracy 平均提升 40.8 个百分点（从 21.0% 到 61.8%）。
- **早停效果（MMStar）**：平均推理 token 从 1,650 降至 345（↓79.1%），平均准确率从 61.69% 升至 64.82%（↑3.13 pp）；Gemma-4-12B 增益最大（+8.87 pp）。
- **早停效果（RealWorldQA）**：平均推理 token 从 1,151 降至 293（↓74.5%），平均准确率从 66.01% 升至 69.31%（↑3.30 pp）。
- **原因分析**：准确率提升主要来自两个来源：一是将原本因超长推理而未完成答案的问题转化为有效输出（missing answer 显著减少）；二是在开放推理轨迹的问题上提前停止获得了额外正确答案。

## 相关工作脉络
- **多模态推理与视觉评估**（Johnson et al., 2017; Huang et al., 2025; Zhang et al., 2023）：聚焦最终答案正确性，本文在此基础上引入"答案何时可用"的时间维度。
- **VLM 内部视觉表征解析**（Neo et al., 2024; Zhang et al., 2025b; Yu and Lee, 2025）：侧重单次前向传播中的信息位置，本文扩展到推理生成过程中的动态追踪。
- **因果追踪与状态干预**（Meng et al., 2022; Basu et al., 2024; Heimersheim and Nanda, 2024）：本文借鉴 activation patching 思路但将其应用于多步推理轨迹中。
- **高效推理与早退**（Afzal et al., 2025; Yang et al., 2026; Xiang et al., 2026; Bi et al., 2026）：现有方法依赖答案置信度或充分性评估，本文首次直接度量视觉答案在推理中的可用时间点。
- **人类感知决策模型**（O'Connell et al., 2012）：本文的检测器设计类比感知决策中的证据累积到阈值机制。

## 局限性与未来方向
- **任务范围受限**：复合任务和合成数据集覆盖的视觉判断类型较有限，尚未在更复杂的开放域视觉推理中验证就绪度的泛化性。
- **层选择依赖验证集**：不同模型的最优分析层差异较大（L1-L20），且每模型需独立验证集选择阈值，限制了跨架构的通用性。
- **检测器训练依赖正确答案**：离线训练时需要强制回答标签，在线部署时虽无需真实答案但仍需预设阈值。
- **Gemma-4-E4B 增益不明显**：该模型在 RealWorldQA 上准确率反而下降 1.05 pp，说明对小模型或特定架构的适配仍需优化。
- **未来方向**：可探索端到端训练就绪度检测器、扩展至更多视觉推理类型、研究不同推理长度预算下的自适应策略。

## 研究启发与可借鉴点
- **"答案就绪度"度量框架可迁移**：将推理轨迹分割为检查点、评估截断轨迹上的可用性与隐藏状态可读性，这一分析范式可复用于其他模型和任务的效率-准确性权衡研究。
- **状态干预验证信息利用因果性**：仅靠线性读出不足以证明模型使用了某层信息，搭配配对干预可建立更严谨的因果证据链，值得在后续可解释性工作中沿用。
- **早停机制可与其他优化结合**：本文的固定间隔检查（256 token）可推广为动态检查策略，与 Token Pruning 或 Adaptive Computation 等技术联合。
- **合成配对数据集的构建方法**：counterfactual pair 保持场景其余部分不变仅改变决策变量，是构造干净因果实验的可靠方案。
- **性能分解视角**：将准确率变化拆分为"开放轨迹增益"和"封闭轨迹损失"两部分，有助于精准定位优化方向，而非仅报告聚合指标。

## 关键术语表
- **Feature Binding**：将物体颜色等属性与其对应形状正确关联的视觉判断能力，模型在此任务上准确率较高（98-100%）。
- **Numerosity**：比较两侧点数量多少的数量感知判断，需区分点数量与总面积以避免面积偏差。
- **Amodal Completion**：根据部分可见轮廓推断被遮挡物体完整形状的能力，是复合任务的关键组件。
- **Composite Task**：需同时完成特征绑定、数量比较、空间定位和非完整完成四种判断的组合任务，测试多步视觉推理整合能力。
- **Counterfactual Pair**：一对仅在决定答案的变量上不同、其余场景内容完全相同的图像，用于隔离因果影响。
- **State Intervention / Patching**：用 donor 图像的隐藏状态替换 receiver 图像的对应状态，测量状态变化对答案的影响程度。
- **Answer Readiness**：推理过程中模型首次具备正确回答复合问题的能力时刻，可通过截断轨迹准确率或隐藏状态可读性度量。
- **Answer-Readiness-Guided Early Stopping**：基于就绪度检测器预测答案可用性并提前终止推理的自适应计算分配方法。

## 可复现要素
- **数据集**：合成任务（Feature Binding / Numerosity / Spatial Relations / Amodal Completion / Composite）均有明确构建规则，但论文未声明公开；MMStar 和 RealWorldQA 为公开基准。
- **代码/权重**：论文未提及代码开源声明，VLM 模型权重为标准开源版本（Qwen3.5 / Gemma-4 系列）。
- **关键超参**：检测器检查间隔 $\Delta=256$ token，生成预算 $B=6144$，岭回归正则化参数 $\lambda=100$（Table 7），阈值 $\eta$ 在验证集上以"准确率损失 ≤ 0.5 pp 下最小化推理长度"为目标选取。
