# 论文速读：MECHBENCH-CAN-AI-SCIENTIFIC-AGENTS-DISCOVER-MECHANISMS-BEYON

## 一句话总结
论文提出了 MECHBENCH 基准测试，将 AI 科学发现中"恢复可观察现象律"与"重建内在机制"两个能力明确分离并独立评估，揭示了当前主流科学代理存在显著的现象-机制恢复鸿沟，即使能正确恢复现象律，机制恢复成功率仍严重不足。

## 研究问题与动机
1. **现象律恢复不等于机制发现**：现有符号回归与科学代理基准主要评估数学规律的事实验收（observational adequacy），但未测试 AI 能否重建产生该规律的内在因果结构（内部量与关系）。
2. **难以区分重构与记忆**：规范科学知识（如牛顿力学、酶动力学）已在预训练数据中存在，成功恢复难以证明是真正的机制推理还是文本回忆。
3. **机制不可区分性难题**：不同但均合理的科学机制可能产生相同的现象律，若无筛选机制会导致基准任务内在模糊。
4. **缺乏对"溯因推理跳跃"的客观评测**：Zahavy (2026) 指出 LLM 的核心缺失能力是从观察跳到解释前提的溯因推理，现有基准未直接测试此能力。

## 核心贡献（创新点）
1. **形式化机制发现任务并设计机制探针**：将机制定义为隐含现象律的结构化科学关系集合，通过机制探针（query 内部科学量且无法从现象律单独推断）客观评估机制恢复，与现象律恢复解耦评测。
2. **构建 MECHBENCH 基准并引入可控突变**：从物理、化学、生物、材料 16 个规范机制出发，应用五类科学可解释突变（本构修改、附加通道、源/汇项等）组合生成 512 个变体任务，平衡科学 grounding 与机制陌生度。
3. **设计机制不可区分性筛选流程**：构造候选竞争机制并检查是否满足可比结构复杂度与科学可接受性，排除 admit 可比竞争机制的实例，确保机制探针的判定有效性。
4. **系统性揭示现象-机制恢复鸿沟**：在 Codex + GPT-5.6-sol 上现象律准确率 35.00%，机制准确率仅 13.75%，且 64.29% 的现象律正确案例中机制恢复失败；提供正确现象律的黄金控制下机制准确率仍低于 50%，突变越多差距越显著。

## 方法详解
1. **机制的形式化定义**：令 x 为可观输入变量，y 为目标变量。现象律 $\mathcal{P}: F_{\mathcal{P}}(\mathbf{x}, y) = 0$ 描述可观测关系；机制 $\mathcal{M} = \{m_1, \ldots, m_J\}$ 包含涉及可观变量与内部量 h 的科学关系，满足 $\mathcal{M}(\mathbf{x}, y, \mathbf{h}) \Longrightarrow \mathcal{P}(\mathbf{x}, y)$，通过消去 h 得到现象律。
2. **机制探针（Mechanism Probes）**：选取一组科学定义的内部量 $\mathcal{Z} = \{z_k\}$，满足参考机制能推导 $z_k = g_{\mathcal{M}}(\mathbf{x})$ 但现象律与上下文不能单独推断，由此区分等价现象律下不同的机制承诺。
3. **机制变异构建**：规范机制 $\mathcal{M}^{(0)}$ 经科学可解释突变 $\Delta_s$ 得到变体 $\mathcal{M}^{(s)} = \Delta_s(\mathcal{M}^{(0)})$，兼容突变可组合为 $\mathcal{M}^{(S)} = (\Delta_{s_q} \circ \cdots \circ \Delta_{s_1})(\mathcal{M}^{(0)})$，每家族五个基础突变保持代数封闭与唯一可解。
4. **基准实例生成**：由机制 $\mathcal{M}$ 消去 h 得现象律 $\mathcal{P}$，在可观范围划分 ID（插值）与 OOD（外推）区域，从 ID 区域采样训练集 D，ID/OOD 各 1000 样本用于测试，无观测噪声。
5. **评估协议**：现象律恢复通过符号+数值等价验证；机制恢复要求所有探针关系严格符号等价（$\prod_k \mathbf{1}[\hat{g}_{ik} \equiv g_{ik}]$），探针查询在搜索结束后独立进行以避免泄露。

## 实验与结果
- **数据集**：Core-set（80 实例，8 家族，按突变数分层）与 Full-set（512 实例，16 家族 × 32 变体）。
- **评估基线**：Codex/Claude Code/DeepSeek Harness 共 7 种配置（GPT-5.6-sol、GLM-5.3-flash、DeepSeek-v4-flash-0731、DeepSeek-v4-pro-0813），以及 PySR 与 PySR+Direct-Ask 两阶段基线、Gold-P Direct-Ask 黄金控制。
- **最强结果**：Codex + GPT-5.6-sol 在 Core-set 上 SA(P) = 35.00%、SA(M) = 13.75%，Full-set 上 SA(P) = 16.02%、SA(M) = 7.81%；统计检验显示 GPT-5.6-sol 显著优于两 flash 模型（p < .01）。
- **关键发现**：
  - 条件失败率 $1 - P(M|P)$：GPT-5.6-sol 为 64.29%（Core）/ 57.32%（Full），表明即使现象律正确，超半数机制仍恢复失败。
  - 突变敏感性：Original 实例机制准确率 50%，单突变降至 37.50%，双突变仅 6.25%，≥3 突变归零；Gold-P 控制下 Original 为 87.50%，4 突变骤降至 12.50%。
  - Flash 模型性能接近零，不同 agent harness 无显著差异，科学领域间无显著差异但家族内异质性高。

## 相关工作脉络
1. **LLM 符号回归与科学代理**：LLM-SR、SR-Scientist、KeplerAgent、A-SR 等系统扩展了符号回归能力，但目标始终是恢复可观现象律，而非其内在机制，本文在此基础上提出机制发现这一更强评测维度。
2. **科学定律发现基准**：Feynman、SRBench 等传统基准侧重紧凑方程恢复；LLM-SRBench、NewtonBench、Science-Gym、SciLaws-Bench 增强了陌生度与交互性，但仍以现象律为核心评测对象，MECHBENCH 首次将机制恢复作为一级目标。
3. **机制哲学与科学解释**：Machamer 等人的机制观强调解释需指定内部组件、关系与组织，Kaplan & Craver 提出机制解释的完备性规范，本文将其操作化为可计算的探针评测框架。
4. **溯因推理研究**：Zahavy (2026) 指出 LLM 缺乏从观察到解释前提的"溯因跳跃"，本文通过机制探针提供客观评测，区别于纯模式归纳与演绎。
5. **机制不可区分性**：Hoefer & Rosenberg 提出经验等价与证据欠定问题，本文将其形式化为机制层面问题，通过筛选流程消除歧义实例。

## 局限性与未来方向
1. **适用范围受限**：当前基准仅覆盖可通过符号消元获得闭式现象律的机制，大量科学系统（非线性 PDE、超越方程、数值模拟）无法适用。
2. **未来方向**：可从机制直接仿真生成观测数据（$\mathcal{M} \to D$），绕过显式构造现象律；但需发展新方法处理数值近似下的机制验证、探针评估与机制不可区分性判定。

## 研究启发与可借鉴点
1. **机制探针设计思路可迁移**：将"内部科学量"与"可观现象律"分离评估的思路适用于任何需评估因果结构而非仅拟合输出的科学 AI 任务。
2. **可控突变构建测试集**：通过局部科学语义修改（而非随机扰动）生成测试变体的策略，可有效平衡熟悉度与陌生度，值得借鉴至其他科学基准构建。
3. **不可区分性筛选流程**：构造竞争机制并对比结构复杂度与科学可接受性的流程，为科学发现基准的歧义消除提供了可复用的方法论。
4. **Gold-P 控制实验设计**：隔离机制推理与现象律发现的黄金控制实验，为分解复杂科学推理能力提供了清晰的实验范式。
5. **团队结合机会**：可将机制发现能力评测引入团队现有的符号回归或科学代理工作流，作为区分"拟合能力"与"理解深度"的诊断工具。

## 关键术语表
- **现象律（Phenomenal Law）**：描述可观输入与输出之间关系的数学规律，如 Kepler 第三定律 $T^2 \propto r^3$，不涉及内部因果结构。
- **机制（Mechanism）**：由科学关系构成的结构化集合，包含内部量与可观量的关系，其联合后果蕴含现象律，如牛顿引力+向心力推导开普勒定律。
- **机制探针（Mechanism Probe）**：科学定义的内部量查询，能从参考机制推导但不能从现象律单独推断，用于客观评估机制承诺。
- **机制不可区分性（Mechanistic Indistinguishability）**：不同但均合理的竞争机制产生相同现象律且同享科学可接受性，导致无法从观测证据唯一确定机制。
- **SA(P) / SA(M)**：现象律符号准确率 / 机制符号准确率，后者要求所有探针严格符号等价。
- **Gold-P Direct-Ask**：黄金控制实验，直接提供正确现象律并要求模型推导机制探针，隔离机制推理能力。
- **ID / OOD 测试**：分布内（插值）与分布外（外推）测试，分别评估恢复规律的内插与外推数值一致性。

## 可复现要素
- **数据集**：MECHBench 基准公开，代码、任务实例与数据已开源（https://github.com/tsinghua-fib-lab/MechBench）。
