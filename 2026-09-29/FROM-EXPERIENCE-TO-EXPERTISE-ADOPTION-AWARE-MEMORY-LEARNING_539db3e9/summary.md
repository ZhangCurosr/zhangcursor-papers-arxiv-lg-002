# 论文速读：FROM-EXPERIENCE-TO-EXPERTISE-ADOPTION-AWARE-MEMORY-LEARNING

## 一句话总结
SAGE 是一种面向 NPU 算子内核合成的持久化自改进智能体，通过追踪经验实际被采用的记录（ATU）与基于效用阈值的冷/热内存选择性固化（UGC），使冻结的 LLM 能够在专家数据稀缺的专用硬件上持续积累、评估并复用硬件级优化知识，显著提升内核生成正确率与执行性能。

## 研究问题与动机
- **大模型向数据稀缺 DSA 迁移困难**：GPU 生态拥有海量公开代码与成熟优化范式，而 Ascend NPU 等专用架构缺乏公开代码；GPT-5.2 在 KernelBench L1 任务上从 CUDA 92% 正确率骤降至 Ascend C 的 14%。
- **后训练方法受限于数据与算力**：SFT 与 RL 依赖大量专家数据与高昂训练成本，难以在低资源硬件上快速扩展与持续适应。
- **现有记忆学习信用分配粗糙**：EvoKernel 等方法对检索集合使用统一的验证器奖励目标，导致未被实际采用（adopted）的经验与已采用经验获得相同信用，干扰后续检索排序。
- **高价值经验缺乏持久化上下文**：当学习到的价值仅用于检索时，跨算子通用的经验必须反复检索而无法常驻上下文，增加检索开销并削弱跨任务一致性指导。

## 核心贡献（创新点）
- **提出 SAGE 自改进智能体框架**：在参数完全冻结的 LLM 基础上，通过外部记忆的冷热分层与动态演化实现跨任务持续学习，区别于依赖权重更新的后训练微调路线。
- **Adoption-Traced Utility estimation (ATU)**：首次将经验级的显式采用记录与终态验证器结果结合进行细粒度信用分配，与均匀信用分配相比，避免未采用经验虚高占据检索优先级。
- **Utility-Gated Consolidation (UGC)**：基于正效用与跨算子重复采用证据筛选可复用规则，抽象为有限 token 预算的常驻热内存，与仅依赖检索的价值记忆机制相比实现知识的主动固化与上下文高效利用。
- **系统性基准验证与跨模型迁移**：在 NPUKernelBench 上实现最高 95.5% 执行成功率，并证明演化的记忆知识在无额外训练情况下可跨骨干模型（DeepSeek-V4-Flash、Qwen3-Coder-Next）迁移复用。

## 方法详解
- **冷热分层内存架构**：外部记忆 $\mathcal{M}=(\mathcal{C}, \mathcal{H})$，冷内存 $\mathcal{C}$ 保留原始经验项及其证据统计供检索，热内存 $\mathcal{H}$ 提供常驻上下文，token 预算固定为 $B=10\text{K}$。
- **ATU 信用分配**：记录每条检索经验的采用状态 $a_{m,t} \in \{1,0,\bot\}$ 与理由。终止后计算终端分数 $z$（正确阶段为 0/1，优化阶段为 $1-T_{\text{best}}/T_{\text{first}}$）。已采用经验均分 $z$，未采用但被检索的经验获固定惩罚 $-\beta$。效用 $u_m$ 通过 bandit 风格规则在线更新：$u_m \gets (1-\eta_m)u_m + \eta_m\xi_m$，步长随检索次数衰减并设下限 $\eta_{\min}$，防止历史证据永久主导。
- **效用感知重排序**：检索阶段先基于语义相关性获取候选池，后期重排叠加效用调制 $s(m)=s_{\text{rel}}(m)(1+\gamma u_m)$，$\gamma=0.3$ 保证相关性为主、历史效用为辅，理论分析证明调制因子恒正且不会颠覆显著相关优势。
- **UGC 固化与淘汰**：满足 $u_m>0$、跨算子采用数 $|\mathcal{O}_m|\ge K_{\text{op}}$、总采用数 $n_m^{\text{ado}}\ge K_{\text{ado}}$ 的经验进入验证状态并抽象为精简规则。热内存按单位 token 预期效用 $U(m)=u_m\hat{p}_m/L_m$ 贪心选择；常驻项若持续未使用，其访问频率 $\hat{p}_m$ 按 EMA 衰减（$h_{1/2}\approx 6.6$ 次更新减半），从而实现陈旧知识可控顶替的双向演化。

## 实验与结果
- **数据集与环境**：NPUKernelBench 88 算子子集（覆盖 L1-L3 全类别），所有内核在 Ascend 910C NPU + CANN 8.5.1 环境下编译执行；骨干模型包括 Qwen3-Coder-Next(80B)、DeepSeek-V4-Flash(284B)、GLM-5.2(744B)。
- **主实验结果**：SAGE 在三种骨干上均取得最优。GLM-5.2 配合 SAGE 执行成功率（ER）达 **95.5%**（最强基线 Value Memory 为 84.1%）；L3 难度 ER 从 61.1% 跃升至 88.9%；已解算算子中 **86.9%** 超越 torch_npu 基线（Value Memory 为 75.7%），中位加速比 $S_{\text{self}}$ 达 **4.47×**。
- **复杂算子迁移**：在 16 个 xCCL 融合算子上，GLM-5.2 实现 68.8% ER，81.8% 正确内核超越 torch_npu；升级至 GLM-5.3 后稀疏 flash attention 加速比达 **43.99×**。
- **任务顺序效应**：L2→L3 串行安排显著优于混合或仅 L3，L3 ER 提升 38.9 个百分点，证明低级经验预固化对高级任务的基础支撑作用。
- **跨骨干迁移**：GLM-5.2 演化的记忆可使 DeepSeek-V4-Flash 的 ER 从 64.8% 升至 72.7%，Fast$_{1.0}$ 从 64.9% 升至 71.9%，表明知识具备部分模型无关性。

## 相关工作脉络
- **LLM 内核合成**：对比 Cuda-L1、KernelEvolve 等 GPU 工作，本文聚焦 Ascend C/NKI 数据稀缺场景，解决显著分布偏移导致的零样本性能崩溃。
- **后训练微调路线**：对比 AscendKernelGen (SFT) 与 NKI-Agent，本文不更新骨干权重，以非参数化持续学习规避专家数据与算力瓶颈。
- **EvoKernel / Value Memory**：本文指出其均匀信用分配缺陷，ATU 通过 adoption trace 实现经验级细粒度归因，解决“检索≠采用”的噪声问题。
- **MemRL / MemQ**：这些方法利用结果条件价值或溯源 DAG 传播信用，但未区分检索集合内实际参与代码修订的经验，SAGE 以显式采用记录填补归因空白。
- **冷/热内存架构**：受 MemGPT 启发，本文引入固定 token 预算的热内存固化与 EMA 淘汰机制，与全量上下文扩展或纯检索方案形成差异。

## 局限性与未来方向
- **长 Horizon 合成未覆盖**：当前 30 轮预算未验证 fused kernels 与 megakernels 的长期合成，此类任务需耦合调度、内存布局与同步决策的多样性搜索。
- **多智能体协同挑战**：实际部署中多个开发者可能使用独立沙盒或共享记忆，存在经验专业化、溯源、跨实例迁移与冲突解决的开放问题。
- **架构泛化待验证**：目前仅在 Ascend NPU 生态验证，未来需拓展至其他新兴硬件架构与领域专用语言。
- **热内存替换策略局限**：当前基于贪心效用密度的替换未显式建模经验间的相关性与组合效应，可能错过协同规则。

## 研究启发与可借鉴点
- **Adoption Tracing 归因范式**：可在任何基于检索修正的 Agent 系统中引入显式 adoption 记录与 trace-completeness hook，解决“检索归因噪声”，适用于代码补全、自动化调试等场景。
- **冷热分层 + 固定预算固化**：UGC 的 $U(m)=u_m\hat{p}_m/L_m$ 打分与 EMA 衰减机制可复用至长程 Agent 的上下文管理，防止上下文无限膨胀并保留高价值抽象规则。
- **跨模型记忆可移植性**：实验证明记忆演化具备跨骨干迁移能力，后续可将“记忆蒸馏+共享知识库”作为团队协作或开源社区的标准化交付物。
- **难度序贯学习曲线设计**：L2→L3 的显著提升提示按复杂度递增安排 task schedule 能有效促进知识沉淀，可作为后续 benchmark 与训练流水线的设计参考。
- **硬件原生诊断工具集成**：Agent 直接调用 AscendC 探针、msDebug/msProf 等工具实现硬件级反馈闭环，为其他加速器的自动调优提供可复用的 tool-augmented 范式。

- **ATU (Adoption-Traced Utility estimation)**：经验级信用分配机制，结合显式采用记录与终态验证器结果更新效用值，避免未采用经验虚高。
