# 论文速读：PP-Net-A-Hybrid-Physical-Prior-Neural-Network-for-Scattered

## 一句话总结
本文提出PP-Net，一种面向物联网医疗（IoMT）边缘设备的混合物理先验神经网络，用于生物医学图像散射光去除；通过"去噪前缀+自适应物理先验估计+深度融合细化"的渐进式流水线，在无需配对生物医学真值的情况下，实现低延迟边缘部署的有效散斑去除与去噪联合处理。

## 研究问题与动机
- **配对真值缺失**：真实临床环境中难以获取严格对齐的去散射生物医学真值，限制监督学习方法直接应用。
- **退化耦合复杂**：生物医学散射与弱照明、传感器诱导噪声（混合泊松-高斯噪声）紧密耦合，传统自然场景去雾方法无法直接迁移。
- **固定先验局限**：经典暗通道先验（DCP）采用固定窗口估计，易跨越组织边界导致边缘泄漏和结构性伪影，且易受高频噪声干扰。
- **边缘部署瓶颈**：现有高性能恢复模型计算开销大，难以在带宽受限、算力有限的IoMT边缘设备上实时部署。

## 核心贡献（创新点）
- **退化建模创新**：首次建立噪声感知型生物医学散射退化模型，将退化明确分解为组织散射（乘性）与传感器噪声（加性）两部分，为渐进式恢复提供理论依据。
- **ASAP自适应先验机制**：提出多尺度自适应暗通道估计模块ASAP，通过评估多种窗口尺寸（9种空间构型）自适应选择最优邻域，从根本上避免固定窗口DCP的边缘泄漏问题，在多个去雾基准上取得SOTA性能。
- **网络-先验-网络渐进架构**：设计"DFN-Net → ASAP → GF-Net"的渐进式流水线，前置去噪保障后续先验估计稳定性，物理先验分支提供可解释中间表示，GF-Net融合细化恢复细节，三者形成互补。
- **跨域部署验证**：开发渐进式合成训练与跨域迁移策略，仅依赖合成数据完成两阶段训练后直接迁移至真实W2S生物医学图像推理；在RK3588边缘平台通过RKNN转换与INT8量化，实现~200 ms/512×512图像的端侧推理，验证了IoMT场景的工程可行性。

## 方法详解
**整体框架**：采用"网络-先验-网络"三段式级联架构，输入退化图像 $F(x,y)$，依次输出去噪中间像 $T(x,y)$、散射图 $S(x,y)$、物理先验图 $U_{\text{map}}(x,y)$，最终恢复图像 $\hat{U}(x,y)$。

**退化模型**（公式3）：
$$F(x,y) = \alpha U(x,y)(1-S(x,y)) + S(x,y) + N(x,y)$$
其中 $U$ 为清洁图像，$S$ 为散射图，$\alpha$ 为照明补偿系数，$N$ 为传感器噪声。

**DFN-Net（去噪前端）**：基于FFDNet的轻量全卷积结构，使用膨胀卷积块（膨胀率 $D \in \{1,2,4,8\}$）扩大感受野，残差学习聚焦噪声分量输出 $T(x,y)$。

**ASAP（自适应散射先验）**：
- 对每个目标像素评估多尺度（WinSize=10/20/30）× 9种空间构型的候选窗口集，自适应选择最优窗口 $W_{\text{opt}}(x,y)$；
- 粗散射图估计：$S_0(x,y) = \min_{q \in W_{\text{opt}}} (\min_{c \in \{r,g,b\}} T^c(q))$；
- TV正则化精炼：$\mathcal{E}(S) = \frac{1}{2}\|S - S_0\|_2^2 + \lambda \|\nabla S\|_1$，保留结构不连续性；
- 自适应缩放系数：$\alpha = \max_{x,y} \frac{T(x,y) - S(x,y)}{1 - S(x,y)}$；
- 物理先验图恢复：$U_{\text{map}}(x,y) = \frac{1}{\alpha}\frac{T(x,y) - S(x,y)}{1 - S(x,y)}$。

**GF-Net（引导融合细化）**：
- 将 $T(x,y)$ 与 $U_{\text{map}}(x,y)$ 沿通道拼接后经 $3\times3$ 卷积投影至高维特征空间；
- 核心构建模块为NAFB（非线性激活无关块），集成SimpleGate操作（通过特征通道间逐元素交互引入非线性）与SCA（简化通道注意力，含全局平均池化+轻量 $1\times1$ 卷积）；
- 四级编码器-解码器结构+跳跃连接+全局残差连接，输出 $\hat{U} = U_{\text{map}} + F_{\text{GF}}(T, U_{\text{map}})$。

**渐进式训练策略**：
- 阶段I（纯散射）：仅在RESIDE ITS子集上用Charbonnier损失训练 $\text{PP-Net}_{\text{P}}$（ASAP+GF-Net），建立物理先验引导能力；
- 阶段II（联合噪声-散射）：在ITS图像上注入混合泊松-高斯噪声（$\lambda_p=30$, $\sigma_g=0.05$），训练完整PP-Net（DFN-Net+ASAP+GF-Net）；
- 阶段III（跨域迁移）：直接将两阶段训练好的模型迁移至无真值的真实W2S生物医学图像进行推理评估。

## 实验与结果
**数据集**：
- 先验评估：SOTS、HSTS、I-HAZE、O-HAZE、D-HAZY（五个去雾基准）
- 混合管道评估：RESIDE-ITS、RESIDE-6K（配对合成数据集）
- 联合噪声-散射鲁棒性：噪声ITS、噪声RESIDE-6K
- 跨域真实评估：W2S（四种曝光/平均设置 avg1/avg4/avg16/avg400）

**关键数字**：
- ASAP在五个基准上均取得最优或次优性能：SOTS PSNR=23.21 dB / SSIM=0.9188；HSTS PSNR=22.06 dB / SSIM=0.9165；O-HAZE PSNR=17.58 dB；D-HAZY PSNR=16.16 dB
- PP-Net_P在RESIDE-ITS上PSNR=37.65 dB / SSIM=0.9901，超越所有对比学习去雾方法
- PP-Net在联合噪声-散射设置下，NOISY ITS上PSNR=24.96 dB / SSIM=0.8093，较次优基线MMPF-Net提升PSNR超**10.8 dB**，SSIM提升超**0.62**
- W2S真实生物医学图像上，PP-Net在avg1设置NIQE=5.58（输入15.41→PP-Net 5.58，**降低43.3%**），全面优于DCP/HDCP/QDCP/Dark等先验基线
- 消融验证：完整PP-Net相比仅用GF-Net基线（PSNR 16.66→24.96）增益巨大；渐进训练（PSNR 24.96，NIQE 5.58）优于仅干净预训练（12.37/14.46）和仅噪声训练（22.45/9.56）

**边缘部署**：在RK3588平台经RKNN转换+INT8量化，输入512×512，360张测试图像平均推理延迟约**200 ms/张**；Tenengrad结构可见度较输入提升3.74%~20.84%，RKNN输出与PyTorch FP32输出视觉一致性良好。

## 相关工作脉络
- **自然场景去雾物理先验**（DCP/CAP/MR/CEP等）：本文ASAP继承并扩展暗通道思想，但核心差异在于摒弃固定窗口、引入多尺度自适应邻域选择以适配生物医学复杂组织结构；且DCP类方法未考虑传感器噪声干扰。
- **端到端学习去雾网络**（MSCNN/AOD-Net/GFN/FFA-Net等）：对比基线多为纯数据驱动方法，依赖配对数据、缺乏物理可解释性；PP-Net通过ASAP引入物理约束中间表示，降低对配对数据的依赖并增强泛化能力。
- **生物医学散射去除**（HDCP/QDCP/Dark等）：HDCP（TV引导滤波）与QDCP（量化DCP）虽针对生物医学场景，但均为纯先验方法，无法恢复精细纹理；Dark方法基于暗通道分割，效果不稳定；PP-Net在前者基础上引入深度细化分支。
- **弱监督/无监督图像恢复**：本文与当前趋势呼应，但差异在于不依赖对抗损失或自监督一致性，而是通过"合成数据渐进训练+跨域直接迁移"的路径解决配对数据匮乏问题。
- **边缘设备部署**：对比同类轻量化模型（如TBN/CDVA等），本文在RK3588平台上实测端到端延迟与结构保持能力，填补了生物医学散斑去除领域的边缘部署实证空白。

## 局限性与未来方向
- **域间分布差异**：模型仅在合成雾气数据上训练，未针对真实生物医学图像进行微调；不同显微镜类型、染色方式、设备参数间的域偏移可能影响泛化稳定性。
- **噪声模型简化**：退化模型中传感器噪声以通用加性项 $N(x,y)$ 表示，实际生物医学成像的噪声分布（如EMCCD/PMT读出噪声、闪烁噪声）更为复杂。
- **推理延迟局限**：200 ms/512×512图像虽满足离线分析需求，但尚未达到实时视频流处理要求（>5 FPS）。
- **评估指标单一**：真实生物医学图像缺乏真值，仅依赖NIQE/BRISQUE等无参考指标，缺少下游任务（如细胞分割、病灶检测）的语义性能验证。
- 论文自述未来方向包括：无监督生物医学域自适应、面向临床任务的性能验证、硬件感知加速以实现实时视频增强。

## 研究启发与可借鉴点
- **"网络-先验-网络"渐进架构**可作为低监督生物医学图像恢复的通用范式：先验分支提供可解释中间表示，降低数据依赖；末尾深度网络负责细节恢复，兼顾精度与泛化。此设计模式可迁移至其他医学图像增强任务（如内窥镜去雾、X光去噪）。
- **多尺度自适应先验估计**（ASAP机制）值得借鉴：将传统固定窗口先验扩展为多尺度+多空间构型自适应选择，可有效缓解边界泄漏问题；该方法对具有复杂纹理结构的医学图像（如病理切片、超声图像）同样适用。
- **渐进式合成训练策略**：阶段I建立基础先验能力、阶段II引入噪声鲁棒性，逐步过渡到跨域真实推理，可有效缓解合成-真实域间gap；该策略可直接复用于其他缺乏配对真值的医学影像恢复任务。
- **物理约束与数据驱动深度融合**：ASAP通过TV正则化保留结构不连续性，GF-Net在此基础上进行非线性细化——"结构化先验保形+深度网络补细节"的分工设计，为构建可解释医学AI模型提供了工程参考。
- **端侧部署验证闭环**：从FP32训练→ONNX导出→RKNN转换→INT8量化→Tenengrad结构可见度评估的完整边缘部署链路，为团队后续研究提供了可复用的嵌入式部署评估流程。

## 关键术语表
**PP-Net**：本文提出的混合物理先验神经网络，由DFN-Net（去噪）、ASAP（先验估计）、GF-Net（融合细化）三段级联构成，专用于生物医学图像散射光去除与边缘部署。
**ASAP（Advanced Scattering Adaptive Prior）**：多尺度自适应暗通道先验模块，通过评估多种窗口尺寸与9种空间构型自适应选择最优邻域估计散射图，避免固定窗口带来的边缘泄漏伪影。
**IoMT（Internet of Medical Things）**：物联网医疗，指将内窥镜、显微镜等生物医学成像设备作为前端传感节点接入医疗物联网，支持远程诊断与端侧处理的场景。
**GF-Net（Guided Fusion Network）**：引导融合网络，基于NAFB模块构建的编码器-解码器结构，通过SimpleGate和SCA机制将物理先验图与去噪观测图融合以恢复细节。
**RKNN / RK3588**：瑞芯微RK3588是一款ARM架构边缘SoC；RKNN是其配套的模型转换与推理框架，支持将PyTorch模型转换为INT8量化格式用于端侧部署。
**W2S（Widefield to SIM）**：一种生物医学显微图像数据集，包含宽场显微镜图像与结构光照明显微镜（SIM）图像对，用于联合去噪与超分辨率任务评估，本文用作真实生物医学图像跨域测试基准。
**Charbonnier Loss**：$\mathcal{L} = \sqrt{\|\hat{y}-y\|_2^2+\epsilon^2}$，一种对异常值比L1/L2更鲁棒的回归损失函数，常用于图像恢复任务。
**Tenengrad Score**：基于Sobel梯度幅值的结构锐度度量，经高斯平滑后计算，用于无参考地评估边缘设备输出的结构可见性质量。
