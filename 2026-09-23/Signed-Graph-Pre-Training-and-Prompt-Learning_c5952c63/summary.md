# 论文速读：Signed-Graph-Pre-Training-and-Prompt-Learning

## 一句话总结
本文提出了 **TopoSIGN**，首个针对有符号图的拓扑引导预训练与提示学习框架，通过融合磁有符号拉普拉斯算子编码器与基于Dowker复形的持久同调拓扑分支，实现从链接符号预测预训练到节点聚类下游任务的迁移。

## 研究问题与动机
- 有符号图（含正负边、可能带方向）广泛存在于信任-不信任网络、金融相关系统、生物相互作用图等场景，边极性本身与连通性同等重要
- 现有有符号GNN多为任务特定方法，端到端训练单一监督目标，缺乏可迁移的表示学习能力
- 图预训练/提示学习在无符号图上进展迅速，但有符号图领域几乎空白，仅SGPT存在但目标是将从无符号图学到的知识迁移到有符号任务，而非直接在有符号图上预训练
- 拓扑信号在有符号图表示学习中未被充分利用，持久同调等方法假设无符号图，负边无法直接融入标量过滤设计

## 核心贡献（创新点）
- **首个有符号图拓扑引导预训练+提示学习框架**：将谱图编码器与Dowker复形拓扑分支结合，支持多任务迁移
- **有符号度向量距离过滤设计**：用二维正负度向量替代标量度数定义Dowker过滤，保留正负边信息同时兼容标准一参数持久同调
- **双分支融合+提示适配机制**：结构嵌入与拓扑嵌入拼接后，通过聚类提示库（cluster prompt bank）将预训练知识迁移到节点聚类任务
- **实验验证框架通用性与有效性**：兼容MSGNN/SSSNET等多种有符号GNN骨干，在合成与真实数据集上均取得竞争力结果

## 方法详解
**框架组成**：TopoSIGN包含三大模块：
1. **结构有符号图编码器（SGE）**：可选MSGNN或SSSNET作为骨干
   - MSGNN使用磁有符号拉普拉斯算子：对称化邻接矩阵 $\widetilde{\mathbf{A}}$，定义相位矩阵 $\Theta_{uv}^{(q)} = 2\pi q(A_{uv} - A_{vu})$，构建Hermitian邻接矩阵 $\mathbf{H}^{(q)} = \widetilde{\mathbf{A}} \odot \exp(i\Theta^{(q)})$，通过Chebyshev多项式近似谱卷积
   - 默认电荷参数 $q = 0.25$，复数激活函数采用复数ReLU

2. **有符号拓扑编码器**：
   - **正向子图基线**：仅保留正边，用正度数 $d^+(u)$ 定义标量过滤距离 $\delta_+(\ell, w) = |d^+(\ell) - d^+(w)|$
   - **有符号度向量过滤（本文设计）**：对每个节点 $u$ 定义二维向量 $\mathbf{s}(u) = [d^+(u), d^-(u)]^T$，过滤距离为 $\delta_\pm(\ell, w) = \|\mathbf{s}(\ell) - \mathbf{s}(w)\|_2$，构建Dowker复形 $D_\varepsilon^\pm(L,W)$
   - 使用地标-见证点策略降低计算复杂度，对每个节点的2跳邻域计算 $H_0$（连通性）和 $H_1$（环）持久图，转换为 $d_I \times d_I$ 持久图像（PI），展平为固定长度向量 $\mathbf{z}_T$

3. **提示学习适配**：
   - 融合表示 $\mathbf{Z} = [\mathbf{Z}_\mathcal{G} \parallel \mathbf{Z}_\mathcal{T}]$
   - 预训练任务：链接符号预测（SP），损失为二元交叉熵 $\mathcal{L}_{SP} = -\sum[y_{uv}\log\hat{y}_{uv} + (1-y_{uv})\log(1-\hat{y}_{uv})]$
   - 下游适配：基于METIS聚类的提示库 $\mathbf{P} = \{\mathbf{p}_1, ..., \mathbf{p}_M\}$，构建提示token $\xi_{u,k} = [\mathbf{p}_k^m \parallel \mathbf{z}_u]$，通过任务头 $g_\phi$ 打分，最小化NLL损失

## 实验与结果
**数据集**：
- 合成：SDSBM（4种设置，n=1000，含不同噪声水平γ和符号翻转概率η）
- 真实：Rainfall（306节点，6簇）、SP1500（1193节点，10簇）

**评估指标**：Adjusted Rand Index (ARI)

**主要结果**（Table 1，预训练+提示学习）：
- **SDSBM-1**：TopoSSSNET最佳 ARI = **0.076 ± 0.031**，TopoMSGNN次之 0.032 ± 0.030
- **SDSBM-2**：TopoSSSNET最佳 ARI = **0.125 ± 0.011**
- **SDSBM-3**：TopoSSSNET最佳 ARI = **0.379 ± 0.036**
- **SDSBM-4（无噪声）**：SAMGPT最佳 ARI = 0.477，TopoSIGN表现一般（0.157-0.164）
- **Rainfall**：Gprompt最佳 ARI = 0.160，TopoSIGN竞争力有限（0.062-0.075）
- **SP1500**：GPF最佳 ARI = 0.081 ± 0.011，TopoSIGN为0.000

**半监督聚类结果**（Table 2，直接微调）：
- **SSSNET+Topo** 在多个数据集上表现最佳：SDSBM-1/2/3分别为 **0.923/0.923/0.937**，Rainfall为 **0.481**，SP1500为 **0.298**
- 拓扑分支对SSSNET提升显著，但对DSGC反而略有下降（冗余/噪声）

**结论**：TopoSIGN在**有噪有符号设置**下优势明显，证明拓扑分支在局部有符号邻域被扰动时能帮助捕获更稳定的结构规律；但在无噪声或密集真实图中优势有限。

## 相关工作脉络
- **SGPT** [11]：唯一现有的有符号图预训练工作，但目标是从无符号图学习迁移到有符号任务，与本文直接在有符号图上预训练的本质不同
- **TopoDIG** [18]：针对有向无符号图的拓扑引导预训练框架，本文的核心灵感来源，但直接将TopoDIG移植到 Signed 图效果不佳（TopoDIG在SDSBM-1仅0.030，TopoSIGN达0.076），证明过滤设计和结构编码器需针对性适配
- **GPPT** [9] / **All-in-one** [10] / **GPF** [37] / **GraphPrompt** [36]：无符号图提示学习基线，本文证明它们在有噪有符号图上表现有限
- **MSGNN** [4] / **SSSNET** [2]：有符号GNN骨干，分别基于磁拉普拉斯和分离传播机制，本文验证了与拓扑分支的兼容性
- **DGI** [30] / **GraphCL** [31] / **GraphMAE** [32]：无符号图自监督预训练方法，未考虑有符号结构

## 局限性与未来方向
- **真实数据集表现有限**：在Rainfall和SP1500上提升不明显，可能与预训练任务（链接符号预测）与下游聚类目标不匹配、以及当前过滤仅捕获一种有符号拓扑类型有关
- **过滤设计简化**：当前有符号度向量过滤仅使用总正/负度数，未区分入度/出度，无法捕捉有向场景中的符号不对称性
- **地标选择策略固定**：当前使用度中心性或介数中心性采样地标，可能有更优的动态选择方式
- **未来方向**：更丰富的有符号-有向过滤（分离入/出正负度）、动态图预训练、边特征感知拓扑、可扩展地标选择

## 研究启发与可借鉴点
- **拓扑特征的"解耦预计算"设计**：持久图像作为一次性预处理步骤，训练阶段无额外开销，这一工程策略值得在有符号/带权图上推广
- **有符号度向量过滤的思想**：将标量过滤升级为向量过滤以保留多维度信号，同时保持一参数PH的可计算性，是处理多属性图过滤的有效思路
- **提示库与METIS聚类的结合**：用无标签图结构（METIS簇）引导提示设计，避免了对任务标签的依赖，可迁移到其他少样本图任务
- **骨干网络的即插即用兼容性**：TopoSIGN证明同一拓扑分支可适配MSGNN、SSSNET等不同有符号GNN，为模块化设计提供了范例
- **多任务预训练的权衡**：消融实验显示额外任务（DP/3C/4C/5C）并非总是有益，提示学习框架下单任务预训练有时更稳定，这一发现对预训练目标设计有参考价值

## 关键术语表
- **Signed Graph（有符号图）**：边带有正负号的图，用于建模合作/竞争、信任/不信任等关系
- **Magnetic Signed Laplacian（磁有符号拉普拉斯）**：MSGNN引入的Hermitian拉普拉斯算子，通过相位编码有向边的方向信息
- **Dowker Complex（Dowker复形）**：基于地标-见证点对偶关系构建的单纯复形，比Vietoris-Rips复形计算效率更高
- **Persistent Homology（持久同调）**：TDA工具，追踪 filtration 过程中拓扑特征（连通分量、环等）的出生与消亡
- **Persistence Image（持久图像）**：将持久图转换为固定维度向量的方法，通过高斯核密度估计实现
- **Graph Prompt Learning（图提示学习）**：借鉴NLP提示思想，通过可学习token对齐预训练与下游任务
- **Cluster Prompt（聚类提示）**：为每个目标簇设计的可学习向量，替代分类任务中的类提示
- **SDSBM（Signed Directed Stochastic Block Model）**：生成有符号有向块模型的合成数据集基准

## 可复现要素
- **数据集**：SDSBM为合成数据（代码可生成）；Rainfall和SP1500为公开真实数据集
- **代码**：匿名代码已开源至 https://anonymous.4open.science/r/TopoSIGN/
- **关键超参**：GNN隐藏维度32、拓扑隐藏维度32、Chebyshev阶数K=1、磁电荷q=0.25、PI网格10×10（d_T=100）、地标数80、2跳邻域、像素大小1.0、优化器Adam(lr=0.01)、权重衰减5e-4、dropout 0.5、预训练1000 epoch（patience 400）、微调100 epoch（patience 40）
- **训练种子**：5个随机种子（0, 10, 20, 30, 40），报告均值±标准差
