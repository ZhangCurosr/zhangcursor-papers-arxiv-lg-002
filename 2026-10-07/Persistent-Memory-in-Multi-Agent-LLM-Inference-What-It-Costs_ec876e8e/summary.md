# 论文速读：Persistent-Memory-in-Multi-Agent-LLM-Inference-What-It-Costs

## 一句话总结
本文通过严格对照实验发现，多智能体分解架构可将单轮推理的峰值KV缓存压缩至14.3 MiB（较单_pass_与RAG基线降低近60%），但在标准独立题目基准上，叠加持久化记忆层仅增加约0.37 MiB开销且未带来可检测的准确率提升；作者论证该零结果是基准设计结构性导致的，并给出了验证智能体记忆消融必须满足的四项测量条件。

## 研究问题与动机
- 多智能体长上下文推理系统常通过任务分解绑定单轮KV峰值，并普遍添加持久化记忆层（存储/检索推理轨迹）宣称能进一步降本增效，但缺乏系统级的开销量化与严谨消融。
- 现有论文多以“关闭记忆层后准确率下降”作为支撑论据，却未控制服务端/客户端开关差异、同种子自召回污染、执行顺序与时序漂移等混杂因素，易将测量伪影误读为性能收益。
- 标准多跳QA/长文档QA基准按独立题目设计，正确性评估强制要求条件间重置记忆状态；在此设定下跨题目检索召回机制要么触发同质化自匹配，要么因清空而无法命中，本质上无法被有效测试。
- 学术界常将检索增强（RAG）与Agent分解视为解决长上下文的等价手段，但二者对峰值KV的影响机制截然不同，亟需明确区分以指导边缘部署的资源规划。

## 核心贡献（创新点）
1. **首次实测并量化多智能体分解架构的峰值KV边界**：证明任务拆分可使单查询峰值KV降至14.3 MiB，较FLAT与RAG基线下降约59.7%–59.9%，而RAG仅优化单轮输入证据并不压缩峰值。
2. **揭示独立题目基准上持久化记忆层的结构性零效应**：在八个数据集对的严格控制消融中，开启L3记忆检索仅增加+0.368 MiB峰值开销，准确率变化为+0.015（95% CI [-0.011, +0.046]），区间包含零且与噪声不可分。
3. **形式化智能体-记忆消融的四项测量条件（C1–C4）并给出通用检测程序**：涵盖组件真实执行断言、运行独立性保障（防自召回）、单一变量隔离与效应量超越测量底噪，不依赖特定缺陷类型即可识别伪收益。
4. **开源完整测量协议与审计工具链**：公开配对消融脚本、隔离探针、每题执行日志与统计代码，使“测量底噪”本身成为可核查对象，推动社区建立可复现的Agent评测范式。

## 方法详解
- **三層架构（COA-PKV）**：L1为每次调用独立的临时KV窗口；L2为Redis键值存储，负责智能体间传递类型化Communication Units（蒸馏态）；L3为Qdrant向量库，承担前置语义证据过滤与后置$(q, k, v)$轨迹持久化/跨查询检索双重职责。
- **消融臂设计**：COA-PKV为全功能版；COA-NOKV仅关闭L3的`search_outputs`与`store_qkv`两条路径，L1、L2、证据池、reasoner/critic/synthesiser节点完全一致，确保单变量对照。
- **峰值KV度量口径**：不测设备总显存，仅记录单次最大调用（prompt+generated）的注意力缓存 footprint，统一按服务模型几何系数 10,240 B/token 换算，保证跨架构横向可比。
- **统计推断策略**：采用逐题配对差分（per-question paired delta）消除题目难度方差；单cell区间使用百分位bootstrap（$B=10^4$）；跨cell区间采用两阶段cluster bootstrap（先重采样cell，再在cell内重采样题目）。
- **四重测量修正**：C1强制服务端字段切换并计数验证组件真实执行；C2实验前预查询向量库防止同种子自召回；C3 diff序列化请求确保单字段差异并对称平衡执行顺序；C4基于复制组估计真实重复波动带（±0.09–0.10）替代单次bootstrap低估的采样误差。

## 实验与结果
- **数据集与基线**：覆盖8个数据集对（HotpotQA, GPQA, MMLU-Pro, LB-HotpotQA, LB-2WikiMultihopQA, LB-MuSiQue, NarrativeQA, Qasper）；基线为FLAT（closed-book单_pass_）与RAG [Lewis et al., 2020]（共享相同reasoner/critic/证据池）。
- **硬件与模型**：边缘部署，NVIDIA Jetson Orin Nano Super (8GB) 运行 llama.cpp + Qwen3.5-2B，NVIDIA DGX Spark 运行 vLLM + Qwen3.5-35B-A3B-FP8（混合注意力，仅10/40层完整KV缓存）。
- **峰值KV与延迟**：COA-PKV峰值KV 14.3 MiB（CI [13.0, 15.4]），较FLAT（35.5 MiB）降59.9%，较RAG（35.3 MiB）降59.7%；延迟29s，较FLAT降56.7%，较RAG降44.2%。累积KV流量约为单_pass_的1.6倍，以更高总流量换取更低峰值。
- **记忆消融结果**：开启记忆使峰值KV增加+0.368 MiB（CI [+0.167, +0.590]）；准确率变化+0.015（CI [-0.011, +0.046]）。在可召回子集（n=138）内效应为-0.012（CI [-0.073, +0.046]），不可召回控制组为+0.009，均与零无显著差异。
- **最强结果**：COA-PKV在多数据集单_query_峰值压缩上表现最优（降至基线约40%）；记忆层点估计最高出现在GPQA（+0.090），但伴随最严重的失败不对称（1 vs 11 orchestrator give-ups），作者判定为潜在测量伪影而非真实收益。

## 相关工作脉络
- **Agent decomposition [Zhang et al., 2024]**：本文明确将其与RAG在KV边界效应上解耦，指出既往工作多以准确率动机论证分解，本文补充系统级峰值KV测量视角。
- **Retrieval-augmented generation [Lewis et al., 2020]**：作为记忆层的经典对照，本文证明其并未像分解架构那样压缩单轮峰值KV（RAG与FLAT峰值区间重叠），澄清“检索增强即降内存峰值”的常见误解。
