# 论文速读：SanSi-A-Looped-Typed-Decision-Model-for-System-1-5-Thinking

## 一句话总结
本文提出 SanSi，一种**循环型类型化决策模型**，通过在预训练循环语言模型骨干（Ouro-1.4B）上附加轻量级 LoRA 与每轮独立读出头，以**循环迭代**替代 token 生成，在相同数据与配方下显著提升至多步推理、长文档、知识类任务的准确率与证据缺失感知能力。

## 研究问题与动机
- 现有决策模型分两类：单轮前向（System 1，速度快但推理深度不足）与生成式推理（System 2，深度强但计算昂贵）。本文填补中间地带——**System 1.5**：循环应用同一组网络层多次后再读取概率，不生成 token 即可深化推理。
- 已有类型化决策模型（Jev、Kev）依赖特定预训练或未显式循环迭代，泛化性与深度控制能力有限。
- 后加循环（如 SmolLM2 强行附加）在实践中往往无效，论文需揭示**预训练引入循环**的必要性及其机制。
- 决策模型的**校准**与**不确定性感知**（如证据缺失检测）仍是开放问题，循环迭代是否改善此类能力尚未系统验证。

## 核心贡献（创新点）
- **提出 System 1.5 循环推理框架**：同一组网络层递归应用 T 轮后读取决策，用计算时间替代 token 生成实现隐式推理；与生成式 System 2 的本质区别是**不扩展上下文、不生成文本**。
- **设计轻量级 SanSi 微调架构**：仅新增 61M 参数（LoRA rank-64 + 每轮 rank-16 读头），骨干冻结；与既有类型化模型（如 Jev/Kev）的区别在于**多轮独立读头 + 多预算一体化服务**。
- **揭示循环增益的非单调性与收敛规律**：loop 2–3 获得主要精度提升，loop 4 后趋于稳定（90% 答案已收敛）；ECE 呈 U 型（loop 3 最优 0.082），**答案稳定性与正确率强相关**（loop 1 稳定答案正确率 82.2%）。
- **证明预训练循环必要性**：在预训练未引入循环的 SmolLM2-1.7B 上加循环无效；Ouro 预训练已学习循环的骨干才能充分受益——这一发现直接挑战"后加循环"路线。
- **展示循环决策模型可作为高效 RL 验证器**：GRPO on 2WikiMultiHopQA 将生成器 F1 从 39.5 提升至 47.3（+7.7），且 4 循环与 8 循环无显著差异，表明循环决策可替代生成式验证。

## 方法详解
- **骨干模型**：Ouro-1.4B（24 层 transformer，预训练时已学习循环，T=4 轮）。
- **参数高效微调**：冻结骨干，追加 LoRA（rank-64，60.6M 参数）+ 每轮独立读出头（0.27M）；读头公式为 $\ell_t = (W + U_t V_t)z_t / \tau_t$，其中 $U_t V_t$ 为 rank-16 修正项。
- **训练设置**：1,000 步，每步 16 样本，3 个随机种子；损失函数为交叉熵 + Brier 分数之和，加权 $1/T$ 对每轮求平均。
- **多预算一体**：一个模型可服务 1~8 轮的任意计算预算，推理时按需停止循环。
- **概率平均校准技巧**：将 8 圈的概率取平均，ECE 从 0.093 降至 0.044，无需额外训练。
- **RL 替代监督损失**：用 REINFORCE + 组均值基线替代交叉熵+Brier，loop 8 准确率保持相当，ECE 降至 0.076，但证据区分能力略降。

## 实验与结果
- **数据集**：59 个来源共 10,027 测试项，分为 6 类题型（A 分类、B 多步推理、C 不确定证据、D 长文档、E 句子对、F 知识）。
- **评估基线**：SmolLM2-1.7B、Qwen3.5-2B/4B、Kev-4B、Jev API（商用）。
- **主要结果**：
  - SanSi（loop 8）：**72.0%**，vs SmolLM2-1.7B +13.5pt，vs Qwen3.5-2B +5.3pt，仅低于 Qwen3.5-4B 1.8pt。
  - SanSi-2.6B（loop 8）：**75.8%**，超过 Kev-4B 1.5pt，参数仅为 Qwen3.5-4B 的 63%。
  - 各题型增益：知识 +17.6pt、长文档 +16.7pt、多步推理 +15.1pt、句子对 +14.2pt。
  - 证据缺失检测：Evidence AUROC 从 0.835 升至 **0.935**（+0.099），接近 Qwen3.5-4B 的 0.948。
  - 深度任务（liar chains）：SanSi loop 8 达 **72.6%**，Qwen3.5-4B 仅 50.0%（随机水平）。
- **成本**：8 轮推理耗时为 1 轮的 7.7 倍；3 轮即达 70.4%（88% 增益）。
- **RL 验证器实验**（2WikiMultiHopQA）：Loop 8 F1 47.3±1.1（较训练前 +7.7），EM 32.2%，含金标准比例 49.7%。

## 相关工作脉络
- **Jev / Kev**（TypeSafe AI, Palmer 2026）：商用/开源类型化决策模型，依赖特定预训练或未显式循环迭代；本文定位差异在于**多轮独立读头 + 预训练循环必要性证明**。
- **Ouro**（Zhu et al., 2025）：预训练循环语言模型，SanSi 骨干来源；本文在此基础上进一步微调并系统评估循环深度效应。
- **Universal Transformer / Looped Transformers**（Dehghani et al., 2019; Giannou et al., 2023）：循环计算理论基础，但未针对决策任务优化；本文填补该空白。
- **Latent Reasoning**（Geiping et al., 2025; Zhu et al., 2025）：通过循环进行隐式推理，与本文思路相近但应用目标不同（生成 vs 决策）。
- **Retrofitted Recurrence / LoopUS / Training-Free Looped Transformers**：后加循环方法；本文证明其在 SmolLM2 上无效，强调**预训练阶段引入循环**的关键作用。

## 局限性与未来方向
- **依赖特定预训练骨干**：仅在 Ouro 系列上验证，通用性待考察；强行后加循环（如 SmolLM2）无效。
- **测试集语言单一**：全为英语，跨语言泛化未验证。
- **循环深度上限**：超出训练深度（>8 圈）不进一步提升，甚至损害性能；16 圈与 8 圈持平。
- **校准非单调**：ECE 在 loop 3 最优后回升，高置信度错误仍存在（19.7% 错误置信度≥0.9）。
- **未探索更长循环预算**：loop 4 后增益饱和，但计算成本线性增长，实际部署需权衡。

## 研究启发与可借鉴点
- **循环迭代作为隐式思考机制**：可为代码生成、数学推理等任务提供低开销深度推理范式，无需生成 token 即可深化推理。
- **多圈概率平均改善校准**：无需额外训练即可将 ECE 减半（0.093→0.044），极具实用价值，可迁移至其他决策模型。
- **RL 替代监督损失**：REINFORCE + 组均值基线保持准确率同时改善校准，为决策模型训练提供新方向。
- **答案稳定性作为置信度代理**：早期稳定答案正确率 82.2%，可作轻量级置信度估计指标，减少额外校准开销。
- **深度可控任务评估**：liar chains / object swaps 可作为模型推理深度上限的诊断工具，建议纳入后续工作 benchmark。

## 关键术语表
- **System 1.5**：介于 System 1（单轮前向）与 System 2（生成式推理）之间的循环推理范式，通过重复应用网络层深化隐式推理。
- **SanSi**：A Looped-Typed-Decision Model，循环型类型化决策模型，核心架构。
- **Ouro**：预训练循环语言模型骨干（24 层，1.4B 参数），SanSi 的基础。
- **读头（Readout Head）**：每轮循环后独立输出的线性层，形式为 $W + U_t V_t$（rank-16 修正），用于从隐状态映射到选项概率。
- **ECE（Expected Calibration Error）**：期望校准误差，衡量预测置信度与准确率的一致性，值越低校准越好。
- **Evidence AUROC**：检测证据缺失的二分类 AUROC，衡量模型不确定性感知能力，值越高区分能力越强。
- **Liar Chains**：真假话链式推理任务（二选一），用于测试模型深度控制能力与链式推理上限。
- **GRPO（Group Relative Policy Optimization）**：组相对策略优化，用于训练生成器的强化学习算法，本文用作循环决策模型的验证器。
