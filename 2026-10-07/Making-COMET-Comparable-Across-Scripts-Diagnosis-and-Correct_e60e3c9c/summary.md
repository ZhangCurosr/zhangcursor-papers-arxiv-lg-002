# 论文速读：Making COMET Comparable Across Scripts: Diagnosis and Correction of Tokeniser-Induced Script Bias in Indic MT Evaluation

## 一句话总结
该论文在 IndicMT Eval 上对 COMET 评测指标进行了首次受控因果检验，证明“脚本身份”会独立解释 22.9% 的 COMET 分数方差，并将脚本偏置拆解为**校准故障**（跨脚本分数范围不兼容）与**敏感性损失**（单脚本内排序失真）两类，最后提出无需人工标注的 COMET-QN 分位数归一化方法将跨脚本聚合一致性从 0.300 提升至 0.399。

## 研究问题与动机
- **跨脚本可比性假设存疑**：COMET 作为单标量被广泛用于不同目标脚本的语言间排名，隐含“脚本不变性”前提，但子词词表由拉丁语料主导，导致非拉丁脚本遭遇更碎片化分词与信息衰减，现有研究未将脚本作为受控因果变量进行检验。
- **缺乏推理期诊断手段**：当前文献仅量化了分词层面对语言的表征负担，却未给出能在不重训模型、不依赖人工评分的情况下量化脚本-induced 失真的推理时诊断工具。
- **现有校正方向错位**：此前的分布校正主要沿语言轴而非脚本轴展开，且任何保序变换均无法修复敏感性损失，亟需区分并分别处理两类故障。
- **实践报告标准缺失**：直接发布原始 COMET 分数会将混淆引入系统排名，全盘罗马化则会带来 1.75–5.57× 额外编码器开销并进一步降低与人工标注的一致性，因此需要一种可在不改变文本形式的前提下校正分数范围的方案。

## 核心贡献（创新点）
- **首次受控因果检验脚本不变性**：在源文本、参考内容与 MQM 人工评分完全固定的条件下仅改变正字形，证实脚本身份可解释 22.9% 的 COMET 方差，与既往仅在单一脚本内扰动或按语言族归因的工作形成对照。
- **将脚本偏置分解为可解耦的校准与敏感性双故障**：证明两者经验独立（如 Marathi 平均分数上升但敏感性显著下降），并给出秩不变性命题严格界定保序后处理的极限，区别于仅关注均值偏移的先前做法。
- **提出三个无标签推理诊断指标**：SBI、IPI、Computational Tax 仅依赖分词计数与外部语言模型信息度量，能在任何人工评分接入前预警脚本负担，弥补了此前 TP/IP 单独使用不足且无法直接映射到分数失真的缺陷。
- **引入跨脚本分位数归一化 COMET-QN**：借用量子生物学消除技术批效应的思路，将每个 (语言, 脚本) 单元映射至共享参考分布，精确消除校准故障且不破坏单元内排序，区别于以往沿语言轴的仿射标准化。
- **构建基于奇偶特征的敏感性恢复回归器**：在留一语言验证下回收 17.1% 的敏感性损失，且无需接触目标语言人工标签，与仅依赖标量后处理的修正方法本质不同。

## 方法详解
- **受控罗马化实验设计**：使用确定性神经转写系统 IndicXlit 对五组英语→印度语对的目标文本进行罗马化，保持语音、形态与语义不变；源文本、参考内容与 MQM 严重度注解随之迁移，任何 COMET 变动均可归因于脚本变化。
- **三个无标签诊断指标**：
  - **Tokenization Parity (TP)**：目标语言每词子词数与英语每词子词数之比，衡量碎片化程度。
  - **Information Parity (IP)**：目标语言与英语在 BLOOM-560m 下的平均对数似然比，衡量单token信息密度。
  - **Script Bias Index (SBI)** = $\mathbb{E}_i[\mathrm{TP}_i / \mathrm{IP}_i]$，表示每单位信息所需付出的子词片数，工作阈值为 3.0。
  - **IP Parity Index (IPI)** = $|\mathrm{IP} - 1.0|$，划分 Parity (<0.35)、Burden (0.35–0.70)、Paradox (>0.70) 三个区域。
  - **Computational Tax** = LP × EP，其中 LP 为罗马化前后平均每词 token 数之比，EP 为罗马化前后每 token 信息量之比，量化额外编码开销。
- **校准与敏感性双故障分解**：P1（校准）指不同 (语言, 脚本) 单元占据不兼容数值范围，如 GUJ 原生脚本较罗马化高 15.09 分而 MAR 低 1.02 分；P2（敏感性）指单元内 COMET 与 MQM 的 Spearman 排序一致性下降，如 MAR 从 0.487 降至 0.278。
- **秩不变性命题**：对任意严格递增函数 $f$，有 $\rho_S(f(s), h) = \rho_S(s, h)$，因此任何保序后处理（均值平移、仿射缩放、分位数映射、单调回归）均无法改善敏感性，校正必须超出标量变换。
- **COMET-QN 分位数归一化**：以所有语言原生脚本 COMET  pooled 分布为参考 $R$，对单元格内分数 $s_i$ 令
  $$
  s'_i = Q_R\!\left(\frac{\operatorname{rank}(s_i)}{n+1}\right)
  $$
  仅依赖秩而不触碰原始排序，使各单元共享统一数值范围，跨脚本平均绝对差距归零。
- **奇偶特征敏感性回归器**：输入包含 $\mathrm{COMET}_{rom}$、$\mathrm{TP}_{nat/rom}$、$\mathrm{IP}_{nat/rom}$ 及其差值，采用梯度提升树回归预测 $\mathrm{COMET}_{nat}$；训练采用留一语言交叉验证，无需目标语言人工评分，因罗马化版本与原生版本构成自由监督对。

## 实验与结果
- **数据集**：IndicMT Eval（五对英→印度语：GUJ、TAM、MAL、MAR、HIN，每语言 1,400 段 MQM 标注）；WMT24 的 ENG-SPA 与 ENG-DEU 作为拉丁脚本对照。
- **基线方法**：COMET wmt22-comet-da 原生与罗马化分数；对比 BLEURT、BERTScore、BLEU、ChrF、TER；四种后处理校正器（均值平移、仿射/z、分位数映射、单调回归）用于验证秩不变性。
- **核心结果**：
  - 脚本解释 22.9% COMET 方差（原生），罗马化后降至 1.5%；HIN–GUJ 差距从 13.95 分缩至 2.29 分。
  - 所有五语言 Romanisation 后 COMET–MQM Spearman 一致性均下降（$|\Delta\rho| = 0.19$–0.39），其中 TAM 从 0.629 跌至 0.240。
  - 罗马化使 TP 上升 15.2%–77.9%，IP 下降 34.0%–68.0%；五种语言 IPI 全部进入 Paradox 区。
  - COMET-QN 将跨脚本聚合 Spearman 从 0.300 提升至 0.399、Pearson 从 0.324 提升至 0.400，单元内排序保留至四位小数不变。
  - 奇偶特征回归器在留一语言设置下平均恢复 17.1% 的敏感性损失（GUJ +38.6%、TAM +13.0%、MAL +33.5%、HIN +20.8%，MAR -20.3%）。
- **最强结果与提升**：COMET-QN 在保留排序的前提下消除校准偏差，聚合一致性提升约 33%（0.300 → 0.399）；回归器在 GUJ 上恢复 38.6% 损失敏感性。

## 相关工作脉络
- **Petrov 等 (2023)、Ahia 等 (2023)**：揭示子词词表在不同语言间计费与延迟差异，本文将其从工程成本延伸至自动化评测失真，并引入 IP 补足 TP 单维度的不足。
- **Tsvetkov & Kipnis (2024)**：提出信息奇偶 IP，本文在此基础上构造 SBI 与 IPI，首次将奇偶度量用于度量侧脚本偏置诊断与阈值分区。
- **Ghosh & Jyothi (2026)**：证明模型对非常规分词的鲁棒性随语言碎片化程度下降，本文把该结论逆向映射至“评估指标本身也会因分词负担而失真”的维度。
- **Sai 等 (2023) IndicMT Eval 原论文**：观察到跨语言 COMET 差异并归因于语言家族，本文进一步剥离出脚本为独立因果因子，证明同一语言家族内脚本仍可导致显著方差。
- **COMET 家族现有失败模式研究（Zouhar 等 2024; Karpinska 等 2022）**：关注语言不匹配、译质风格化与单脚本扰动，未将正字形作为受控变量，本文填补该实验空白。
- **分布校正与批量效应消除（Bolstad 等 2003; Franks 等 2018）**：原本用于基因表达数据的跨平台归一化，本文首次将其移植到跨脚本学习度量校准场景，并给出理论极限证明。

## 局限性与未来方向
- **指标与词表范围受限**：实证仅覆盖 XLM-R SentencePiece 词表的 COMET 系列变体，其他词表设计（如字节级、WordPiece、英语中心化）的响应尚未验证。
- **书写系统外推未知**：研究对象为五类印度语 abugida，表意文字（中、日、韩）及混合语码场景尚缺匹配源的多脚本 MQM 评测集，COMET-QN 在其中的表现未经验证。
- **基础分布假设的边界**：COMET-QN 假设单元格间潜在质量分布可比，若真实系统池质量不同会被一并抹除；参考分布的选择对聚合一致性增益的影响未做敏感性测量。
- **转写噪声控制依赖间接证据**：罗马化质量基于 Dakshina 基准的反向精度评估，本文未直接在本语料上采集罗马化输出的人工评分，残差噪声的影响通过编码器依赖性排序与 Marathi 反例间接论证。
- **未来方向**：扩展至 MetricX、mT5 等非 XLM-R 词表指标；在非 abugida 脚本上测试诊断工具；收集罗马化输出的直接人工评分；探索更均匀的跨脚本编码器容量分配。

## 研究启发与可借鉴点
- **脚本可作为受控因果变量**：通过保持源文本、参考内容与人工评分固定而仅改变正字形，可干净识别度量系统的正字形偏置，该设计可直接迁移至其他多脚本评测场景。
- **诊断与校正分层解耦**：将偏置拆分为“校准”与“敏感性”并分别证明可治与不可治边界，避免盲目尝试单调后处理；任何新度量的脚本稳健性评估均应同步报告这两项。
- **无标签奇偶诊断的临床价值**：SBI、IPI、Tax 完全无需人工评分即可在推理前预警，建议纳入自动化评测流水线作为发布门槛指标。
- **生物信息学归一化方法的跨域移植**：分位数归一化用于消除跨脚本技术批效应是一个可复用的范式，未来可扩展至跨方言、跨领域或跨平台的度量对齐。
- **自由监督对的结构设计**：利用罗马化前后成对样本构建回归器，在零人工标签条件下恢复部分敏感性，这种“文本变换配对+外部分词/信息特征”的框架可推广到其他度量失真校正任务。

## 关键术语表
- **Script Invariance (SI)**：假设 COMET 对同一内容不同书写系统的输出给出相同分数的原则，本文通过罗马化实验证明该假设在印度语场景下不成立。
- **Fragmentation (碎片化)**：子词词表对非拉丁脚本词汇切分过度，导致相同语义内容被拆成更多低信息 token 的现象。
- **Script Bias Index (SBI)**：$\mathbb{E}[\mathrm{TP}/\mathrm{IP}]$，综合衡量分词碎片化与信息密度负担的诊断指数，≥3.0 时原始 COMET 分数不可直接信任。
- **IP Parity Index (IPI)**：$|\mathrm{IP}-1.0|$，刻画目标语言相对英语的信息奇偶偏离程度，用于划分 Parity/Burden/Paradox 三区报告策略。
- **Computational Tax**：罗马化带来的编码器额外开销，等于长度惩罚 LP 与信息惩罚 EP 的乘积，罗马化使开销达 1.75–5.57×。
- **Calibration vs. Sensitivity**：校准指跨脚本分数范围的可比性，敏感性指单脚本内 COMET 对翻译质量排序的区分能力；前者可由 COMET-QN 精确修复，后者不能通过保序变换恢复。
- **COMET-QN**：基于 pooled 原生脚本分布的分位数归一化后处理，消除校准故障同时严格保留单元内排序。
- **Rank Invariance Proposition**：任何严格递增函数不改变 Spearman 秩相关，证明单调后处理无法修复敏感性损失的理论下限。

## 可复现要素
- **数据集**：IndicMT Eval（公开）、WMT24 评测包（公开）；罗马化由 IndicXlit 完成。
- **代码/权重**：论文声明已发布代码（MIT 许可），使用 Unbabel/wmt22-comet-da 检查点与 unbabel-comet v2.2.6；TP 基于 XLM-R SentencePiece 词表，IP 基于 BLOOM-560m。
- **关键超参**：SBI 工作阈值 3.0；IPI 分区边界 0.35 / 0.70；COMET-QN 参考分布为 pooled 原生脚本 COMET；回归器为 300 棵梯度提升树、深度 3、学习率 0.05、seed 0；分词与信息度量均在 1,400 段/语言规模上稳定。
