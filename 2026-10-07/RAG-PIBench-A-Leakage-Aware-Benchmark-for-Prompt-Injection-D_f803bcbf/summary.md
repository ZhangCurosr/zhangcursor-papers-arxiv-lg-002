# 论文速读：RAG-PIBench-A-Leakage-Aware-Benchmark-for-Prompt-Injection-D

## 一句话总结
本文提出 **RAG-PIBench**，一个专为 RAG 系统设计的泄露感知型提示注入检测基准，包含 4,876 条上下文示例，采用严格冻结式训练/验证/受保护测试协议，系统对比了关键词规则、语义参考、TF-IDF 稀疏特征及 Transformer 编码器等多种检测器。

## 研究问题与动机
- RAG 系统中检索到的外部内容可能嵌入恶意提示注入指令，使模型偏离原定任务目标，而现有检测方法在真实上下文中难以区分"合法指令性内容"与"恶意覆盖指令"。
- 已有评测存在评估协议不一致、训练/测试数据间潜在泄露、缺少轻量强基线对比等问题，导致性能估计偏高。
- 现有基准（如 BIPIA、PromptShield）缺乏泄露感知设计和受保护测试协议，无法公平比较不同类别的检测器。
- 需要一种可复现、审计透明的基准，以支持启发式、语义、稀疏特征和 Transformer 四类检测器的系统对比。

## 核心贡献（创新点）
- **RAG-PIBench 基准构建**：构建包含 4,876 条样本（2,936 训练 / 962 验证 / 978 受保护测试）的平衡二分类基准；与已有工作相比，本文强调"泄露感知"而非仅测量攻击成功率或单一检测器族表现。
- **泄露感知构建流水线**：引入来源注册、溯源追踪、风格匹配渲染、快捷方式审计及冻结分割等流程，本质区别在于通过审计减少捷径学习（shortcut learning），提升可审计性。
- **严格受保护测试评估协议**：将训练、验证与最终评估完全隔离，诊断套件独立于模型选择；区别于以往工作混用诊断结果的做法，本协议保证最终结果不受后验调优污染。
- **系统性多类检测器对比**：首次在同一冻结协议下对比关键词规则、MiniLM 语义参考、TF-IDF（LR/SVM/RF）和 DistilBERT/DeBERTa-v3 七种检测器，揭示 Transformer 增益与稀疏基线的竞争关系。
- **透明报告成功与失败结果**：公开所有模型的混淆矩阵及失败模式（如 DeBERTa-v3 退化为全正预测），强调负面结果的报告价值以提升 RAG 安全评估的可信度。

## 方法详解
- **威胁模型**：攻击者控制/影响可被检索的外部文本，但不控制用户查询或系统提示；检测器在生成前对渲染后的 RAG 输入做二元分类（benign=0, malicious=1）。
- **任务定义**：将 RAG 风格上下文中的提示注入检测建模为二分类问题 $f(x_i) \rightarrow y_i$，目标是在检测恶意注入的同时控制对合法指令性内容的误报。
- **构建流水线（四阶段）**：
  1. **来源注册与溯源**：采集宿主文档（3,500 篇）和载荷父源（各 192 个），记录 schema、语义标签与来源信息。
  2. **候选审核与质量控制**：混合人机审核，检查重复、不一致、短路边距等内容，排除有问题的样本。
  3. **RAG 风格上下文渲染与泄露审计**：将宿主上下文与嵌入内容段组合成真实 RAG 式输入，审计格式artifact、模板重复、来源特定标记等快捷线索。
  4. **冻结分割生成**：固定三分割比例（3:1:1），受保护测试集在模型开发全程不可访问。
- **评估协议**：训练/验证/受保护测试严格分离；模型仅在训练集拟合、验证集选超参，受保护测试集仅用于最终一次推理。
- **评估指标**：Accuracy、Precision、Recall、$F_1$、PR-AUC、ROC-AUC 及混淆矩阵；以 $F_1$ 为主要排序指标（类平衡），PR-AUC/ROC-AUC 衡量排名质量。
- **七类检测器**：
  - **Keyword**：确定性词法规则
  - **MiniLM Ref.**：最大语义相似度到恶意参考库
  - **TF-IDF LR/SVM/RF**：词级+字符级 TF-IDF 特征 + 逻辑回归/SVM/随机森林
  - **DistilBERT**：序列长度 256，fine-tune encoder classifier
  - **DeBERTa-v3**：序列长度 192，保守数值稳定性配置

## 实验与结果
- **数据集**：RAG-PIBench，共 4,876 条样本，每分割良性/恶意各半，受保护测试集 978 条（489 良性 + 489 恶意）。
- **评估基线**：Keyword、MiniLM Ref.、TF-IDF LR、TF-IDF SVM、TF-IDF RF、DistilBERT、DeBERTa-v3。
- **主要结果（受保护测试集）**：
  - **DistilBERT 最优**：$F_1 = 0.896$，PR-AUC = 0.968，ROC-AUC = 0.967，Accuracy = 0.899（TP=425, FP=35, FN=64, TN=454）
  - **TF-IDF SVM 最强稀疏基线**：$F_1 = 0.871$，PR-AUC = 0.950，ROC-AUC = 0.949（TP=435, FP=75, FN=54, TN=414）
  - **TF-IDF LR 次之**：$F_1 = 0.867$，PR-AUC = 0.950，Recall=0.916（更高召回但误报更多）
  - **TF-IDF RF**：$F_1 = 0.850$
  - **MiniLM Ref.**：Recall=0.969 但 Precision 仅 0.508，大量误报（FP=459）
  - **Keyword**：Precision=0.981 但 Recall 仅 0.104，漏检严重（FN=438）
  - **DeBERTa-v3 退化**：全正预测，Recall=1.0 但 Precision=0.5，无真正例（TP=489, FP=489）
- **关键结论**：DistilBERT 相比 TF-IDF SVM 提升约 2.5% $F_1$（0.896 vs 0.871）；稀疏模型仍高度有竞争力；Transformer 增益有限但确实存在；高召回不等于有效检测。

## 相关工作脉络
- **BIPIA [22]**：间接提示注入 RAG 基准，侧重漏洞与防御评估，但未强调泄露感知协议和强轻量基线对比；RAG-PIBench 聚焦泄露感知评测框架和系统化基线对比。
- **PromptShield [8]**：实用提示注入检测基准，关注低误报约束；定位差异在于 RAG-PIBench 采用严格受保护测试协议并排除捷径学习。
- **PromptSleuth [20]**：语义不变性视角的检测方法；本文相比其在泄漏控制和失败模式透明度方面更严格。
- **INJECAGENT [23]**：面向工具集成 agent 环境的间接注入基准；本文聚焦 RAG 风格上下文检测而非 agent 行动链评估。
- **WAInjectBench [14]**：Web-agent 提示注入基准；本文在 RAG 上下文分类任务上提供更强基线和更严格的评估隔离。
- **TrustRAG [24] / SeCon-RAG [19]**：可信 RAG 防御框架；本文提供独立的检测器评估基准，而非防御架构本身。

## 局限性与未来方向
- 仅评估二元检测任务，不涉及下游缓解策略（隔离、净化、忽略、转介等）的联合评估。
- 尽管进行了审计，仍无法消除全部分布性 artifact，结果应理解为"在该基准上的性能"而非普适鲁棒性。
- Transformer 评估仅限两种编码器模型，未覆盖更大编码器、decoder-only 模型、指令微调分类器或检索感知架构。
- 受保护测试集类平衡，与实际部署中类别先验显著不同的场景有差距，校准和阈值选择需额外验证。
- 仅限英语文本输入，未涵盖多语言、跨领域迁移、对抗生成内容及多模态场景。

## 研究启发与可借鉴点
- **泄露感知基准设计范式**：溯源追踪、快捷方式审计、冻结分割三步法可迁移到其他安全评测场景（如数据泄露检测、对抗样本鲁棒性评测）。
- **强稀疏基线的重要性**：本文证明 TF-IDF SVM 可与 DistilBERT 差距仅 2.5% $F_1$，提示在 LLM 安全评测中必须将稀疏模型作为必要基线，避免过度依赖 Transformer。
- **失败结果的透明报告**：DeBERTa-v3 全正退化的案例说明应将负面结果纳入评估标准流程，这对后续研究者识别训练不稳定问题具有参考价值。
- **评估协议的可复用模板**：严格分离训练/验证/受保护测试、诊断套件独立化的工作流可作为其他安全基准的评估框架模板。
- **Precision-Recall 权衡的工程启示**：TF-IDF SVM 偏好精准率、TF-IDF LR 偏好召回率，为不同部署场景（高误报成本 vs 高漏检成本）提供了选择依据。

## 关键术语表
- **Prompt Injection（提示注入）**：攻击者通过嵌入指令性文本使 LLM 偏离原定行为目标的攻击手段。
- **Indirect Prompt Injection（间接提示注入）**：攻击者不直接操控用户输入，而是在检索内容中嵌入恶意指令的变体。
- **RAG（Retrieval-Augmented Generation，检索增强生成）**：通过检索外部文档并将结果注入上下文来增强 LLM 生成质量的架构。
- **Leakage-Aware（泄露感知）**：指在基准构建中主动识别并阻断训练/测试间数据泄露、捷径线索等评估偏置的设计原则。
- **Protected-Test Split（受保护测试分割）**：在模型开发和调优全程保持不可访问，仅用于最终评估的一次性数据子集。
- **Shortcut Learning（捷径学习）**：模型利用数据中的非语义线索（如模板重复、格式标记）而非真实语义进行预测的现象。
- **PR-AUC（Precision-Recall Area Under Curve）**：在不同阈值下精确率-召回率曲线的面积，衡量正类排名质量。
- **RAG-PIBench**：本文提出的泄露感知型 RAG 提示注入检测基准，含 4,876 条示例和严格评估协议。
